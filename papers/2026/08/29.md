### 3. 同等排序质量，不同决策：训练顺序一致的LLM评分器
| 属性 | 内容 |
|------|------|
| **英文标题** | Equal Ranking Quality, Different Decisions: Training Order-Consistent LLM Scorers |
| **分类** | 可解释性 |
| **评分** | 5.5/10 ⭐⭐ |
| **作者** | Markus Frohmann, Mahdiyar Alavi, Elizabeth Lingg et al. |
| **作者单位** | Thomson Reuters |
| **arXiv** | [2608.26762](http://arxiv.org/abs/2608.26762v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.26762v1) |

重排序器、奖励模型和多文档问答评分器在单个LLM提示中评分候选文档或响应，导致分数依赖顺序。尽管排序质量相似，但决策可能不同：在段落重排序中，五个训练评分器的nDCG@10差异在0.010内，但保留集重叠仅0.66-0.84。现有重排序器保留集F1最高，重叠仍仅0.667。提示级修改无法消除顺序依赖，而提出的顺序一致SFT（OC-SFT）在权重中缓解该问题，保持排序质量并提升所有决策稳定性指标，如翻转读者答案的比例从0.149-0.164降至0.125。OC-SFT在12个基础模型上比顺序平均蒸馏更稳定，且单次排列的保留集重叠超过十次平均现成排列。因此，评估应报告阈值保留和读者答案，而非仅排序质量。代码已开源。


**核心贡献**：

- 揭示LLM评分器排序质量相同但决策不一致的问题，量化了保留集重叠仅0.66-0.84。

- 提出OC-SFT训练方法，在保持排序质量的同时，将决策稳定性提升至最优，如读者答案翻转率降至0.125。

- 在12个基础模型上验证OC-SFT优于顺序平均蒸馏，且单次排列稳定性超过十次平均现成排列。



> 💡 该论文揭示了LLM评分器排序质量与决策一致性之间的关键差距，并提供了有效的解决方案，值得推荐系统研究者关注。

### 10. 查询扩展不仅是生成：通过更好的集成提升稠密检索
| 属性 | 内容 |
|------|------|
| **英文标题** | Query Expansion Is More Than Generation: Improving Dense Retrieval through Better Integration |
| **分类** | 召回与排序 |
| **评分** | 5.3/10 ⭐⭐ |
| **作者** | Siyuan Sun, Mihai Surdeanu |
| **作者单位** | — |
| **arXiv** | [2608.25521](http://arxiv.org/abs/2608.25521v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.25521v1) |

大型语言模型（LLMs）无需任务特定训练即可生成查询扩展，但相同的扩展往往使冻结的稠密检索器性能下降。本文发现，性能下降常源于集成方法而非生成文本。为此，提出AnchorQE，一种无需训练的方法，分别编码原始查询和扩展，再通过无监督在线策略估计插值因子进行融合。该策略仅在未标记测试流的小部分上运行，根据扩展的检索强度及其与原始查询检索证据的一致性动态分配信任。在TREC-DL、LoTTE和BEIR基准上，AnchorQE相比仅扩展或文本级拼接基线，检索效果提升最高达12.89%；其在线估计策略相比开发集调优的固定权重，提升最高达3.81%。


**核心贡献**：

- 揭示查询扩展集成方式对稠密检索性能的关键影响，而非仅关注生成文本。

- 提出AnchorQE，无需训练的插值集成方法，在TREC-DL、LoTTE和BEIR上相比基线提升最高12.89%。

- 设计无监督在线插值因子估计策略，相比固定权重提升最高3.81%。



> 💡 本文系统性地解决了查询扩展在稠密检索中的集成问题，提出简单有效的AnchorQE方法，显著提升检索效果，值得所有从事稠密检索和LLM应用的研究者阅读。
