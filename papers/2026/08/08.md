### 1. 字段感知的智能体技能检索
| 属性 | 内容 |
|------|------|
| **英文标题** | Field Aware Agent Skill Retrieval |
| **分类** | 召回与排序 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Paimon Goulart, Liang Wu, Kelly Wan et al. |
| **作者单位** | — |
| **arXiv** | [2608.02880](http://arxiv.org/abs/2608.02880v2) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.02880v2) |

随着终身学习智能体积累不断增长的技能库，正确检索技能成为关键瓶颈。现有方法将技能视为扁平文档，拼接名称、描述和正文等字段。本文提出保留技能的多字段结构，对每个字段独立计算稀疏和稠密相似度，形成张量化的字段感知表示，并通过均匀权重或小型MLP融合字段级分数。在SkillRet和SRA-Bench两个基准上，字段感知MLP分别达到77.95和83.78的Recall@10，优于拼接基线，且技能库越大优势越明显。结果表明保留技能结构可显著提升检索性能。


**核心贡献**：

- 提出字段感知的技能表示方法，将技能拆分为独立字段并分别计算相似度，形成张量化表示，避免信息混淆。

- 在SkillRet和SRA-Bench上，字段感知MLP的Recall@10分别达77.95和83.78，超越拼接式学习基线。

- 发现技能库规模增大时字段感知优势更显著，表明其在困难检索场景下更具价值。



> 💡 该论文揭示了技能检索中保留字段结构的重要性，为智能体技能管理提供了简单有效的改进方案，值得关注。

### 2. 基于混合机器学习框架的放牧系统牛群生长模式与增重预测
| 属性 | 内容 |
|------|------|
| **英文标题** | Hybrid Machine Learning Framework for Herd-Level Cattle Growth Pattern and Weight Gain Forecasting in Grazing-Based Production Systems |
| **分类** | 召回与排序 |
| **评分** | 5.5/10 ⭐⭐ |
| **作者** | Muhammad Riaz Hasib Hossain, Rafiqul Islam, Shawn R. McGrath et al. |
| **作者单位** | — |
| **arXiv** | [2608.06001](http://arxiv.org/abs/2608.06001v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.06001v1) |

针对商业化放牧系统中牲畜观测数据不规则、影响生长预测的挑战，本研究利用2022-2024年澳大利亚东南部的自动传感观测数据，开发了一种牛群水平体重预测的混合机器学习框架。通过整合周活体重、人口统计变量和滞后环境预测因子构建结构化数据集，采用时间聚合生成牛群级预测轨迹。评估了残差、堆叠、级联和集成辅助四种混合架构，以ARIMA、LSTM和GRU为基线。独立测试表明，级联GB-RF-NN架构性能最优，测试R²为0.889，RMSE为21.319 kg，MAE为15.462 kg。混合架构在稀疏观测下鲁棒性优于循环序列模型，误差随预测期延长而增加。特征重要性分析显示动物年龄、降雨量和温度是主要预测因子。该框架可支持饲料分配、放牧管理和牲畜营销决策。


**核心贡献**：

- 提出级联GB-RF-NN混合架构，在牛群体重预测中达到R²=0.889，RMSE=21.319 kg，优于单一模型基线

- 混合架构在稀疏观测条件下比LSTM/GRU等循环模型具有更高鲁棒性，适应不规则数据场景

- 通过特征重要性分析识别年龄、降雨和温度为关键预测因子，提升模型可解释性



> 💡 该论文提出了一种针对放牧系统牛群体重预测的混合机器学习框架，在稀疏数据下表现优异，为农业时序预测提供了可借鉴的架构设计思路。
