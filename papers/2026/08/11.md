### 1. MetaStrategy：基于可执行大语言模型策略的生成式排序
| 属性 | 内容 |
|------|------|
| **英文标题** | MetaStrategy: Generative Ranking with Executable LLM Strategies |
| **分类** | 召回与排序 |
| **评分** | 6.9/10 ⭐⭐⭐ |
| **作者** | Chengyu Lai, Jiuning Lin, Zhibo Xiao et al. |
| **作者单位** | Alibaba Group |
| **arXiv** | [2608.09440](http://arxiv.org/abs/2608.09440v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.09440v1) |

工业推荐系统需在用户、业务、商业和体验等多重目标下对异构内容排序。现有生成式排序方法直接生成物品序列，难以与成熟预测模型、运营规则和字段级护栏集成。本文提出MetaStrategy框架，利用大语言模型（LLM）生成结构化、可执行的排序策略（JSON格式），控制目标权重、内容偏好、体验约束和位置策略，并通过确定性验证器和编译器在生成器-评估器（GE）架构中与现有模型竞争。策略在生产路径回放环境中训练，结合选择、相对排名和基线提升奖励，以及自竞争课程和评估器路由的奖励增强蒸馏（将4B教师模型蒸馏至0.8B学生模型）。在淘宝首页“猜你喜欢”部署后，七天在线A/B测试显示点击PV提升2.11%，IPV提升3.12%，交易额提升2.83%，且无RT增加。


**核心贡献**：

- 提出生成可执行排序策略而非直接生成物品序列，实现与现有预测模型和规则的无缝集成

- 设计生产路径回放训练环境，结合多奖励信号和自竞争课程，提升策略泛化能力

- 通过蒸馏将4B教师模型压缩至0.8B学生模型，保持性能同时降低推理成本

- 在线A/B测试中点击PV提升2.11%，IPV提升3.12%，交易额提升2.83%，且无RT增加



> 💡 该论文提出了一种新颖的生成式排序范式，通过LLM生成可执行策略而非物品序列，在工业场景中显著提升多目标指标，兼具创新性和实用性。

### 2. DREAM技术报告：基于智能体方法的推荐引擎自主优化控制架构
| 属性 | 内容 |
|------|------|
| **英文标题** | DREAM Technical Report |
| **分类** | 强化学习推荐 |
| **评分** | 6.9/10 ⭐⭐⭐ |
| **作者** | Bin Zhang, Bowen Zheng, Chao Yi et al. |
| **作者单位** | Alibaba Group |
| **arXiv** | [2608.09408](http://arxiv.org/abs/2608.09408v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.09408v1) |

工业推荐系统常采用级联的召回、排序和重排流程，但存在信息碎片化、目标割裂、规则僵化及对实时意图感知不足等问题。本文提出DREAM（Developing Recommender Engine with Agentic Methods），一种在不替换现有管道的前提下，增加感知、可编排、可审计的策略层的自主优化控制架构。其核心包括：三层意图引擎（Intent Engine）融合设备端信号生成L0/L1/L2意图表示，边缘-云触发链将上报量降至约8.7%；元引擎（Meta Engine）通过MetaModel进行分层推理（M1-M2-M3），结合策略记忆生成参数，并通过统一出口安全下发。奖励双环（Reward Dual Loop）结合离线模拟与在线反馈持续优化。淘宝首页信息流大规模A/B测试显示，仅重排控制即可提升IPV 2.06%、核心IPV 2.39%、GMV 0.88%；扩展至精排控制后，分别提升2.71%、3.06%和1.31%，PV持续提升超1%，且不影响服务稳定性。


**核心贡献**：

- 提出DREAM架构，在不替换现有管道模型的前提下，通过智能体元控制层实现推荐系统的自主优化，提升IPV 2.71%、核心IPV 3.06%、GMV 1.31%。

- 设计三层意图引擎，融合设备端信号生成结构化意图表示，边缘-云触发链将上报量降至约8.7%，兼顾实时性与成本。

- 构建奖励双环机制，结合离线模拟与在线反馈，实现策略空间探索与结果校准的闭环优化，保障服务稳定性。



> 💡 该论文提出了一种可插拔的智能体元控制架构，为工业推荐系统提供了一种低风险、高收益的优化范式，值得推荐系统从业者深入研读。

### 3. IntHQ：面向生成式推荐的双流表示任务交互层次查询
| 属性 | 内容 |
|------|------|
| **英文标题** | IntHQ: Task-Interactive Hierarchical Query on Dual-Stream Representations for Generative Recommendation |
| **分类** | 多模态推荐 |
| **评分** | 6.7/10 ⭐⭐⭐ |
| **作者** | Junjie Sun, Longfei Xu, Huimin Yan et al. |
| **作者单位** | Alibaba Group |
| **arXiv** | [2608.09634](http://arxiv.org/abs/2608.09634v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.09634v1) |

本文提出IntHQ，一种多任务生成式推荐模型，解决现有方法中任务无关表示导致的三重崩溃：源崩溃（任务信号注入晚且被稀释）、关系崩溃（任务依赖隐式或静态固定）、层次崩溃（任务依赖多尺度特征且随训练变化）。IntHQ包含三个组件：双流解耦（DSD）早期注入任务身份并分离共享与任务特定流；任务交互建模（TIM）用显式跨任务交互替代预定义漏斗，自适应学习任务间依赖；层次查询（HQ）让任务在不同训练阶段跨层聚合多尺度信息。离线评估中，IntHQ在四种任务头配置下均优于强基线；在高德地图生产环境部署后，UVCTR相对提升1.60%。


**核心贡献**：

- 提出双流解耦（DSD）机制，早期注入任务身份，缓解任务信号稀释，离线评估中优于多种编码器骨干。

- 任务交互建模（TIM）用自适应跨任务交互替代固定漏斗，提升任务依赖建模的灵活性。

- 层次查询（HQ）支持任务在不同训练阶段跨层聚合多尺度信息，进一步缓解层次崩溃。

- 在高德地图生产环境部署，服务数亿用户，UVCTR相对提升1.60%。



> 💡 该论文首次系统性地解决多任务学习在生成式推荐中的三重崩溃问题，并通过大规模生产部署验证了其有效性，值得推荐系统研究者深入阅读。

### 5. 法律RAG中的时间错位：法国税法版本化语料库基准

| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Rose Cymbler, Daniel Guez, Laurent Fabre |
| **作者单位** | — |
| **arXiv** | [2608.09393](http://arxiv.org/abs/2608.09393v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.09393v1) |

本文首次识别并量化了法律检索增强生成（RAG）中的“时间错位”问题：系统检索并引用法律条款的当前有效版本，而实际应适用的是历史或未来版本。作者提出法律问答本质上是时间索引检索问题，并构建了FiscalQA Pro基准，包含32,436个法国税法条款版本（覆盖1938-2031年）及209个需时间推理的专家审核问题。实验表明，11个模型在参数化知识上的平均严格准确率仅3.0%，静态RAG为2.7%，且静态RAG检索到适用版本的概率为0%。提出的多版本索引端到端检索器达到98.3%的严格准确率，消融实验显示残差主要来自第一阶段召回。


**核心贡献**：

- 首次提出并量化法律RAG中的时间错位问题，静态RAG检索到适用版本的概率为0%

- 构建FiscalQA Pro基准，包含32,436个版本化条款和209个时间推理问题，支持确定性评分

- 多版本索引检索器实现98.3%严格准确率，较静态RAG（2.7%）提升显著

- 发布69,208条版本感知判例引用链接及完整代码，促进后续研究



> 💡 该论文揭示了法律RAG中一个被忽视的关键缺陷，并提供了可复现的解决方案，对法律科技领域具有重要价值。

本研究分析2010年《多德-弗兰克法案》第1502条对卢旺达钨出口价格响应的影响。利用UN Comtrade镜像贸易数据、汇率及世界平均价格，采用进口商固定效应模型，将2009-2023年样本分为四个时期。结果显示价格响应存在显著时变特征：时期1负响应显著（η=-20.814, p<0.01），时期2消失（η=1.814, p>0.10），时期3重现（η=-5.277, p<0.01），时期4再次消失（η=0.440, p>0.10）。系数差异检验证实时期间变化显著。研究表明监管影响并非单一轨迹，而是随制度与市场环境动态演变。
