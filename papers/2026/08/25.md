### 1. HAWKEYE：看得更深一层——用于时序链接预测的凝聚感知结构通道
| 属性 | 内容 |
|------|------|
| **英文标题** | HAWKEYE: Seeing One Layer Deeper -- A Cohesion-Aware Structural Channel for Temporal Link Prediction |
| **分类** | 召回与排序 |
| **评分** | 7.2/10 ⭐⭐⭐ |
| **作者** | Jiacheng Ding, Xiaofei Zhang |
| **作者单位** | — |
| **arXiv** | [2608.22727](http://arxiv.org/abs/2608.22727v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.22727v1) |

时序链接预测（TLP）模型通常整合交互历史、时间编码和结构三个通道，但现有结构通道（如DyGFormer的邻居共现计数）在稀疏图上判别力弱（AUC≈0.50）。本文发现2跳凝聚桥信号更具判别力（discAUC 0.73-0.98），提出HAWKEYE结构通道，增量维护k-core/k-truss等凝聚指标并生成2跳桥特征。作为即插即用模块，替换DyGFormer原生结构通道后，在六个数据集上AP/MRR提升0.6-10.8点；在tgbl-subreddit上MRR从0.103提升至0.204，且流式处理67M边仅需5分钟。


**核心贡献**：

- 发现稀疏时序图中1跳共同邻居信号近随机（AUC≈0.50），而2跳凝聚桥信号判别力强（discAUC 0.73-0.98），为结构通道设计提供新视角。

- 提出HAWKEYE凝聚感知结构通道，可即插即用替换现有TLP模型的结构通道，在六个数据集上提升AP/MRR 0.6-10.8点。

- 在tgbl-subreddit基准上，仅用结构通道的消融实验使MRR从0.103提升至0.204（+10.1点），且流式处理67M边仅需5分钟。

- 揭示了增益与训练无关的2跳discAUC相关，在退化或饱和图上增益消失，提供了可预测的适用边界。



> 💡 本文通过揭示2跳凝聚桥信号在稀疏时序图中的关键作用，提出高效即插即用的结构通道，显著提升链接预测性能，值得所有从事时序图学习的研究者阅读。

### 5. 长运行AI智能体记忆中的压缩悬崖问题
| 属性 | 内容 |
|------|------|
| **英文标题** | The Compaction Cliff in Long-Running AI Agent Memory |
| **分类** | 大模型推荐 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Saber Zerhoudi, Jelena Mitrovic, Michael Granitzer |
| **作者单位** | — |
| **arXiv** | [2608.22752](http://arxiv.org/abs/2608.22752v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.22752v1) |

在AI智能体的上下文中，安全规则与事件日志竞争同一令牌预算。当溢出时，两者被同等压缩，但规则需精确措辞才能保持可执行性。在20个生产配置中，Sonnet 4.6的/compact提示词在单轮压缩后仅保留53%的安全规则，五轮后降至10%，称为“压缩悬崖”。我们提出知识分流框架，按类型分类知识库行并实施差异化保留策略，包含三个确定性操作：TypeCompact按类型保真度重写、TypeDecompose分区大主题并复制规则、TypeRetrieve从外部存储获取并固定规则。在五个公共语料库上，TypeCompact在每压缩比下比最强单次LLM压缩器多保留2-4倍安全规则，五轮召回率达96%；TypeDecompose实现0%局部性违规（对比93%）；TypeRetrieve在召回@50上达100%（对比73%）。在三个下游行为基准上，医疗合规性、零售任务通过率、航空领域均显著优于基线。


**核心贡献**：

- 提出知识分流框架，通过三个确定性操作（TypeCompact、TypeDecompose、TypeRetrieve）实现差异化压缩，在五轮压缩后安全规则召回率达96%，相比最强单次LLM压缩器提升2-4倍。

- TypeDecompose在分区时复制范围内安全规则，实现0%局部性违规，而均匀分区为93%违规。

- TypeRetrieve通过固定范围内规则优先于相关性，达到100%召回@50，优于最佳单次LLM检索器的73%。

- 在医疗合规、零售任务和航空领域三个下游基准上显著优于生产级压缩器，医疗合规p<10^-8，零售p<0.01，航空p=0.024。



> 💡 该论文首次系统揭示长运行AI智能体记忆压缩中的安全规则丢失问题，并提出高效的知识分流框架，对智能体可靠性有重要价值。
