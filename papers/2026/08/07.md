### 1. 技能知晓其邻居：面向技能检索的簇对比能力页
| 属性 | 内容 |
|------|------|
| **英文标题** | Skills Know Their Neighbors: Cluster-Contrastive Capability Pages for Skill Retrieval |
| **分类** | 召回与排序 |
| **评分** | 7.2/10 ⭐⭐⭐ |
| **作者** | Zifei Wang, Wei Wen, Qiang Ji et al. |
| **作者单位** | — |
| **arXiv** | [2608.04482](http://arxiv.org/abs/2608.04482v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.04482v1) |

针对技能库中候选技能共享主题和词汇但能力不同导致的检索错误，本文提出能力页（Capability Pages）——一种簇对比技能表示，包含正触发器、负边界和判别性主体。离线编译器通过比较相邻技能生成这些字段，在线推理时利用正触发器和主体进行候选召回，负边界用于拒绝混淆项。在含26,262个技能和5,400个问题的SRA-Bench上，能力页使五种检索器的Recall@10平均提升2.94点，端到端任务成功率平均提升3.62点；在中文SSL-SkillDiscovery上MRR@50达73.07%。该方法无需修改在线模型，仅重写离线技能库即可改进路由。


**核心贡献**：

- 提出能力页概念，将技能文档视为可执行区域的损失观测，揭示文档导致的检索误差，并通过簇对比表示缓解该问题。

- 在SRA-Bench上，能力页使五种检索器的Recall@10平均提升2.94点，端到端任务成功率平均提升3.62点。

- 在中文SSL-SkillDiscovery上，使用相同编码器跨条件达到73.07% MRR@50，验证了跨语言泛化性。

- 无需修改在线模型，仅通过离线重写技能库即可提升路由性能，实用性强。



> 💡 本文通过簇对比能力页有效提升技能检索准确率，为大型语言模型智能体的技能路由提供了新思路，值得阅读。

### 2. Gryphon-v2：以单一模型替代级联架构——基于Rollout蒸馏的生成-排序推荐器
| 属性 | 内容 |
|------|------|
| **英文标题** | Gryphon-v2: One Model in Place of a Cascade - Generate-and-Rank Recommender with Rollout Distillation |

| **arXiv** | [2608.06213](http://arxiv.org/abs/2608.06213v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.06213v1) |

工业推荐系统通常采用多阶段级联架构，包含候选生成、预排序和最终排序。本文提出Gryphon-v2，一种统一的生成-排序端到端推荐架构。该模型仅编码一次用户历史，通过自回归解码器生成Semantic-ID候选，解析为目录项，并利用复用共享编码器状态的物品级排序模块进行排序。为在不增加额外服务模型的情况下迁移生产级排序偏好，作者将高容量、仅训练用的教师排序器蒸馏进排序模块，并采用Rollout蒸馏：教师分数作为唯一排序监督，在两种互补候选分布上收集——当前解码器的Rollout和日志曝光。在Yandex Music的大规模在线A/B实验中，单个Gryphon-v2模型替代了包含15+候选生成器、预排序和最终排序的生产级联，活跃用户数提升1.41%，服务延迟与级联相当，验证了其作为端到端替代方案的实际可行性。


**核心贡献**：

- 提出统一的生成-排序架构，单模型替代多阶段级联，在线A/B实验中活跃用户数提升1.41%，延迟与级联相当。

- 创新性地采用Rollout蒸馏，将教师排序器的细粒度偏好迁移至排序模块，无需额外服务模型，且利用两种互补候选分布提升泛化。

- 在Yandex Music大规模推荐场景中验证，替代了包含15+候选生成器的生产级联，展示了生成式检索在工业界的实际可行性。



> 💡 该论文展示了生成式检索与蒸馏排序的巧妙结合，以单一模型替代复杂级联，为工业推荐系统提供了一种高效端到端新范式，值得关注。

### 4. 损失函数不感知基，但Adam感知
| 属性 | 内容 |
|------|------|
| **英文标题** | The Loss Does Not See the Basis, but Adam Does |
| **分类** | 协同过滤 |
| **评分** | 6.3/10 ⭐⭐⭐ |
| **作者** | Devender Singh |
| **作者单位** | — |
| **arXiv** | [2608.05136](http://arxiv.org/abs/2608.05136v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.05136v1) |

本文研究了因子化模型W=UV^T中梯度下降与Adam在低秩归纳偏置上的差异。梯度下降隐式偏向低秩解，而Adam不具备此性质。作者将差异归因于损失函数的规范对称性，提出优化器需满足规范等变性才能继承梯度流的低秩机制。通过结构定理刻画了无记忆等变规则，并实验验证：在欠定矩阵感知中，共享标量预条件可恢复低秩偏置；在Transformer中，Adam使等价初始化在首步分离，最终头不变量相对Frobenius距离相差56%；在两类高光谱数据集上，梯度下降在最低采样密度下将留出误差降低43-44%。


**核心贡献**：

- 揭示Adam与梯度下降在低秩偏置上的本质差异，归因于规范等变性的缺失

- 提出结构定理，刻画无记忆等变规则为Gram决定的左预条件

- 实验证明共享标量预条件可单调恢复低秩偏置，隔离各向异性为原因

- 在Transformer中，Adam导致等价初始化分离，头不变量相对距离差56%



> 💡 本文深刻揭示了优化器对称性对低秩归纳偏置的影响，为理解深度学习优化行为提供了新视角。

### 5. 个性化模态加权是否真正个性化？多模态推荐中逐用户加权声明的受控审计

| **评分** | 6.3/10 ⭐⭐⭐ |
| **作者** | Jingyuan Zheng, Xin Zhang, Yang Gu et al. |
| **作者单位** | — |
| **arXiv** | [2608.05655](http://arxiv.org/abs/2608.05655v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.05655v1) |

本文针对多模态推荐系统中广泛使用的逐用户模态加权方法（如用户模态强度向量、注意力门控、元权重超网络等）进行受控审计。通过双对比审计原则，将六种实现统一到共享协同骨干上，测量与全局模态权重的效用差距（real-GM）及与用户权重绑定置换的识别差距（real-shuf）。在三个短视频语料上，全局权重已获得几乎全部内容增益（+1.9/+3.6/+3.5pp），逐用户加权无一致增益，少数正差距≤0.9pp且不稳定。置换控制显示real-shuf可达内容增益的128%，但解耦门控输入可消除此膨胀。剂量反应实验验证了检测能力，并在电商语料上复现。建议将real-GM与real-shuf作为个性化声明的最低证据标准。


**核心贡献**：

- 提出双对比审计原则（real-GM和real-shuf），系统评估六种逐用户模态加权实现，发现全局权重已捕获大部分内容增益（+1.9/+3.6/+3.5pp），逐用户加权无一致优势。

- 揭示置换控制（real-shuf）的必要性但不充分性：门控读取共享嵌入导致识别差距膨胀至内容增益的128%，解耦后降至近零。

- 通过剂量反应实验（AUROC从0.57升至0.89，另一场景从0.64升至1.00）验证了审计框架的检测能力，并在跨域电商语料上复现所有发现。



> 💡 该论文通过严谨的受控审计揭示了多模态推荐中个性化模态加权的实际效果有限，为个性化声明提供了重要的方法论标准，值得所有推荐系统研究者阅读。
