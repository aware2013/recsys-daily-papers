### 1. 超越Top-K：用可解释的智能体操作替代黑盒检索
| 属性 | 内容 |
|------|------|
| **英文标题** | Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations |
| **分类** | 召回与排序 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Sagar Tamang, Ayush Vyas, Tabarakul Hazarika |
| **作者单位** | — |
| **arXiv** | [2608.06305](http://arxiv.org/abs/2608.06305v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.06305v1) |

针对长文档检索增强生成中，传统分块嵌入加Top-K检索在财务报表等结构化文档上的结构性缺陷，本文提出READ（可靠的无嵌入智能体文档搜索）方法。READ通过三个确定性操作（归一化词法搜索、结构导航、受限跨度读取）让智能体直接读取原始文档，并通过Model Context Protocol暴露轨迹，实现可审计的检索过程。在780页政府财务报告上，READ在51个验证问题上的准确率达58.8%，远超稠密检索的15.7%（p_Holm=2×10^-5），且优于使用Top-K工具的智能体（27.5%）。实验还表明BM25与READ无显著差异，说明增益来自无嵌入接口而非迭代本身。


**核心贡献**：

- 提出READ框架，用确定性操作替代黑盒嵌入检索，实现可解释、可回放的检索轨迹

- 在51个验证问题上，READ准确率58.8%，比稠密检索高43.1个百分点（p_Holm=2×10^-5）

- 对比实验显示，使用Top-K工具的智能体仅达27.5%，证明接口设计比迭代更重要

- 发现BM25与READ无统计显著差异，表明增益源于无嵌入检索而非智能体迭代



> 💡 该论文挑战了检索系统的黑盒范式，提出可解释的智能体操作接口，为结构化文档检索提供了新思路，值得关注。

### 2. Surv-IPTB：基于注意力机制的个体治疗获益概率估计模型（生存数据场景）

| **arXiv** | [2608.06288](http://arxiv.org/abs/2608.06288v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.06288v1) |

本文提出Surv-IPTB，一种基于注意力机制的框架，用于在生存分析中估计个体治疗获益概率（IPTB）。该模型将IPTB估计转化为二分类问题，利用治疗组与对照组间的成对比较，并通过不精确概率表示处理右删失数据，以区间值概率刻画不确定的治疗效应。注意力机制通过可学习的查询-键变换实现数据驱动的成对比较聚合，同时为删失样本学习软类别概率。在包含螺旋、钟形、圆形等复杂非线性结构的合成数据集上，实验表明该方法在不同删失率和治疗效应强度下均保持稳健性能，一致优于基于随机生存森林、Cox比例风险及Beran估计器的T-learner和S-learner基线，尤其在传统方法显著退化的非线性场景中优势明显。代码已公开。


**核心贡献**：

- 首次将注意力机制引入生存数据下的个体治疗获益概率估计，通过成对比较和区间概率处理右删失，实现端到端学习。

- 在复杂非线性合成数据集（螺旋、钟形、圆形）上，Surv-IPTB在不同删失率和效应强度下均优于T-learner和S-learner基线，尤其在高非线性场景中性能提升显著。

- 模型可扩展性强，且代码公开，便于复现和实际应用。



> 💡 该论文提出了一种新颖的注意力框架，为生存数据中的个体治疗获益估计提供了可扩展且统计稳健的解决方案，值得关注。

### 7. 稠密检索模型中性别敏感性的机制分析
| 属性 | 内容 |
|------|------|
| **英文标题** | A Mechanistic Analysis of Gender Sensitivity in Dense Retrieval Models |
| **分类** | 公平性与去偏 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Catherine Chen, Maarten de Rijke, Carsten Eickhoff |
| **作者单位** | — |
| **arXiv** | [2608.05467](http://arxiv.org/abs/2608.05467v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.05467v1) |

本文对双编码器稠密检索模型中的性别偏差进行了机制性分析，发现性别信号源于输入嵌入，并通过少量晚期注意力头传播，这些注意力头同时携带性别和词匹配信号。基于此，作者在嵌入层和注意力层实施干预，结果显示嵌入层干预非特异性地中和分数差异，而注意力层干预产生方向性偏移。研究为针对性去偏提供了机制基础，并揭示了在共享组件中分离性别与相关性信号的挑战。


**核心贡献**：

- 定位性别敏感性来源：通过机制分析发现性别信号起源于输入嵌入，并通过少量晚期注意力头传播，这些头同时编码性别和词匹配信息。

- 干预效果差异：嵌入层干预非特异性地中和分数差异，而注意力层干预产生方向性偏移，表明不同干预点的效果不同。

- 揭示去偏挑战：性别与相关性信号在共享组件中纠缠，增加了针对性去偏的难度，为未来研究提供了方向。



> 💡 本文首次从机制层面剖析稠密检索模型中的性别偏差，为精准去偏提供了理论依据和干预策略，值得推荐系统公平性研究者阅读。
