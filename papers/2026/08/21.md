### 1. 潘多拉的AI模型路由盒：基于昂贵价值估计的高效分配
| 属性 | 内容 |
|------|------|
| **英文标题** | Pandora's AI Model Routing Box: Efficient Allocation with Costly Value Estimation |
| **分类** | 召回与排序 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Adam Fisch, Shubhendu Trivedi, Fantine Huot et al. |
| **作者单位** | — |
| **arXiv** | [2608.20316](http://arxiv.org/abs/2608.20316v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.20316v1) |

异构AI系统通过将查询路由至最有效且成本最低的专家模型来提升质量与效率，但价值估计本身有成本。本文将该权衡形式化为潘多拉盒子问题，在高斯信号模型下推导出信息价值的闭式表达式，据此决定是否值得细化估计。提出的集中式策略Pandora's Router在三个领域（多LLM基准、检索增强专家、可变推理时长的LLM）中，以远低于穷举估计的昂贵估计查询次数，达到相同路由质量；分散式策略Pandora's Bidder在估计准确时提升分配效率，但估计噪声大时可能损害他人效用。


**核心贡献**：

- 将模型路由中的价值估计成本问题形式化为潘多拉盒子问题，提出信息价值闭式解，指导估计细化决策。

- Pandora's Router在三个领域实验中，以显著更少的昂贵估计调用次数匹配穷举估计的路由质量。

- 分散式Pandora's Bidder在估计准确时提升分配效率，但噪声估计下可能增加策略性专家效用而损害整体。



> 💡 该论文为AI模型路由中的成本-质量权衡提供了优雅的理论框架和实用算法，值得推荐系统研究者借鉴。

- 动态Bellman价值定价后继能力类，证明固定额外资源增量在饱和时消失，持久正后继价值可主导该增量

### 5. 将BrowseComp-Plus投影至ClimbMix：迈向更真实的智能体搜索语料库

|------|------|
| **英文标题** | Projecting BrowseComp-Plus onto ClimbMix: Toward More Realistic Corpora for Agentic Search |
| **分类** | 召回与排序 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Sahel Sharifymoghaddam, Lingwei Gu, Yijun Ge et al. |
| **作者单位** | — |
| **arXiv** | [2608.20317](http://arxiv.org/abs/2608.20317v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.20317v1) |

BrowseComp-Plus基准通过固定语料库分离了智能体与检索器的评估，但其语料仅约10万文档且按查询构建。本文提出BrowseComp-Plus_CM，将问题证据迁移至NVIDIA发布的ClimbMix（400B token，5.53亿文档）中。主要贡献是投影流水线：将问题分解为原子推理跳，并在新语料中逐跳验证，仅当自动验证、独立智能体和人工审核均通过时保留问题。应用于830个测试问题，得到57个完全可落地的问题。投影使检索难度显著增加：最强智能体答案准确率下降5点，证据召回率从84.3%降至21.4%，搜索调用增加63%。


**核心贡献**：

- 提出数据集无关的投影流水线，将基准问题分解为原子推理跳并在新语料中逐跳验证，适用于任何可分解为可验证事实的基准。

- 构建BrowseComp-Plus_CM基准，将830个问题投影至ClimbMix，得到57个完全可落地的问题及问题级相关性判断。

- 实验表明投影显著增加检索难度：最强智能体证据召回率从84.3%降至21.4%，搜索调用增加63%，答案准确率下降5点。

- 开源流水线、基准和分析代码，支持后续研究（https://github.com/castorini/cmass）。



> 💡 该论文通过创新的投影流水线构建了更真实的智能体搜索基准，揭示了检索难度对智能体性能的关键影响，值得关注。

### 7. FinRCA-Bench：面向金融AI系统的证据检索与推理基准测试
| 属性 | 内容 |
|------|------|
| **英文标题** | FinRCA-Bench: Benchmarking Evidence Retrieval and Reasoning for Financial AI Systems |
| **分类** | 召回与排序 |
| **评分** | 6.4/10 ⭐⭐⭐ |
| **作者** | Pratik Ghawate |
| **作者单位** | — |
| **arXiv** | [2608.18534](http://arxiv.org/abs/2608.18534v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.18534v1) |

大型语言模型在金融运营中的推理性能高度依赖所获取的证据。针对财务对账场景，本文提出FinRCA-Bench，一个包含2,250个应付账款到银行对账案例的确定性合成基准，覆盖14张运营表、1,500个注入故障（15类因果）及750个合法/难负样本。根因标签和记录级证据契约对模型隐藏，可独立评估检索与答案正确性。实验表明，在固定推理模型和提示下，仅改变检索方式，宏平均必需记录召回率从0.83%提升至77.70%，精确16类准确率从2.05%提升至72.44%。结构检索失败（95次）远多于充足检索下的推理失败（15次），且严格证据契约准确率仅5.72%，表明检索架构显著影响AI系统性能，正确根因标签不能保证可审计诊断。


**核心贡献**：

- 构建了首个面向金融对账的确定性合成基准FinRCA-Bench，包含2,250个案例和15类因果故障，支持检索与推理的独立评估。

- 提出Typed Provenance Graph Retrieval (TPGR)方法，仅利用事务关系进行类型化遍历，在固定推理模型下将必需记录召回率从0.83%提升至77.70%，精确16类准确率从2.05%提升至72.44%。

- 揭示结构检索失败（95次）远多于推理失败（15次），且严格证据契约准确率仅5.72%，证明检索架构是金融AI系统性能的关键瓶颈。



> 💡 该基准精准拆解了金融AI中证据检索与推理的耦合问题，为构建可审计的金融智能系统提供了重要评测工具和检索范式。

### 8. 顺序推荐基准测试真的需要高阶序列建模吗？
| 属性 | 内容 |

| **分类** | 序列推荐 |
| **评分** | 6.3/10 ⭐⭐⭐ |
| **作者** | Aleksandr V. Petrov, Praveen Chandar, Paul N. Bennett et al. |
| **作者单位** | — |
| **arXiv** | [2608.19833](http://arxiv.org/abs/2608.19833v1) |

本文质疑广泛使用的顺序推荐基准是否真正需要高阶序列建模能力。作者提出两种简单的、基于近因加权的成对探针模型：SeqRules和概率协同转移模型（PCTM），它们不学习高阶序列表示。在eSASRec评估协议下，至少一种探针在三个Amazon数据集上超过复现的eSASRec达15-38%，在MovieLens-1M上超过4.4%，但在MovieLens-20M上落后27.3%。在其余四个数据集上，探针也优于采样softmax的SASRec复现9-28%，表明现有基准难以衡量高阶序列建模的增益。作者建议用Transformer模型与强近因加权探针对比，作为检验基准有效性的具体方法。


**核心贡献**：

- 提出两种无需高阶序列表示的近因加权探针模型SeqRules和PCTM，作为基准能力测试工具

- 在eSASRec协议下，探针在3个Amazon数据集上超越复现模型15-38%，在MovieLens-1M上超越4.4%

- 在4个数据集上探针超越SASRec复现9-28%，证明现有基准无法有效区分高阶建模增益

- 在MovieLens-20M上探针落后27.3%，揭示不同基准对高阶建模的敏感度差异



> 💡 本文通过巧妙的探针实验揭示了现有顺序推荐基准的局限性，为评估高阶序列建模价值提供了可复用的方法论。
