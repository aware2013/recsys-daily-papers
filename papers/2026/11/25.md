### 1. OmniEVIE：证据向量引导的多模态检索嵌入模型
| 属性 | 内容 |
|------|------|
| **英文标题** | OmniEVIE: Evidence-Vector-Informed Embedding for Multi-modal Retrieval |
| **分类** | 多模态推荐 |
| **评分** | 7.2/10 ⭐⭐⭐ |
| **作者** | Zifei Wang, Wei Wen, Qiang Ji et al. |
| **作者单位** | Tencent |
| **arXiv** | [2611.32203](http://arxiv.org/abs/2611.32203v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.32203v1) |

针对多模态检索中单向量嵌入丢失局部证据、交叉编码器在线重读代价高、未压缩后交互索引过大的问题，提出4.5B参数多向量嵌入模型OmniEVIE，统一覆盖文本、图像、视觉文档、视频与工具。每条记录最多存储128个64维int8向量（每百万条8.82GiB），同时提供均值向量、1-bit符号与int8多向量以支持粗、中、细三级检索，并将命中定位到页面区域或视频片段。训练、合并、索引与检索协同设计：统一检索格式、三级证据校验去假阴性、按基线-教师差距动态采样、训练中用ST-HAC压缩以对齐索引、按参数块合并专家模型、显著性门控加噪声下限精化打分。在MMEB-V3（190任务）上得60.68（全d=2048）与60.06（K128×d64 int8索引），MMEB-V2得77.96，ViDoRe V3得62.96；100万与500万记录下单线程查询54.2ms与120.2ms，分别比精确4096维单向量搜索快11.1倍与25.3倍，比全int8 MaxSim快236倍与532倍。视频直接由帧编码，QVHighlights上78.0%查询峰值落在标注片段内，返回片段（占视频18%）与标注交集达94.3%（随机为44.9%）。


**核心贡献**：

- 提出4.5B参数统一多向量嵌入模型，用单一压缩索引覆盖文本、图像、视觉文档、视频与工具五类模态。

- 每条记录仅9,472字节（每百万条8.82GiB），在MMEB-V3 190任务上达60.06，兼顾效果与存储效率。

- 100万/500万记录下单线程查询54.2ms/120.2ms，比精确4096维单向量搜索快11.1倍/25.3倍，比全int8 MaxSim快236倍/532倍。

- 视频无需解析模型直接由帧编码，QVHighlights上78.0%查询峰值落入标注片段，返回片段交集94.3%（随机44.9%）。



> 💡 该工作用一套压缩多向量索引同时解决多模态检索的效果、存储与延迟三角难题，并给出可复现的权重与代码，对构建大规模多模态召回系统具有直接参考价值。

### 2. 面向基于语义ID的生成式推荐的推测解码
| 属性 | 内容 |
|------|------|
| **英文标题** | Speculative Decoding for Semantic-ID-Based Generative Recommendations |
| **分类** | 召回与排序 |
| **评分** | 7.1/10 ⭐⭐⭐ |
| **作者** | Harshal A. Chaudhari |
| **作者单位** | — |
| **arXiv** | [2611.32855](http://arxiv.org/abs/2611.32855v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.32855v1) |

针对基于语义ID（SID）的生成式推荐中束搜索需固定L次串行模型调用且无法保证精确top-K的问题，提出SIDECAR：利用近似草稿候选与树注意力单次调用为整棵草稿树打分，对未探索SID前缀给出概率上界，若草稿含精确top-K则可认证；否则用分支定界回退，仅扩展仍可能改变输出的前缀，最多L次调用内完成认证。在每次M个token、Y次调用的预算下（Y=L时与宽度M的束搜索资源相当），SIDECAR可给出各排名精确的1+δ因子保证；依模型锐度不同，以部分调用或内存即可返回精确top-K，预算不足时也能报告该因子以支持提前停止。


**核心贡献**：

- 提出树注意力单次调用为整棵草稿树打分，并给出未探索SID前缀的概率上界，可在草稿含精确top-K时完成认证。

- 设计分支定界回退机制，仅扩展可能改变输出的前缀，任意草稿下最多L次调用即可完成认证。

- 在M token/次、Y次调用预算下（Y=L时与宽度M束搜索资源相当）给出各排名精确的1+δ因子保证，并支持预算不足时报告该因子以提前停止。

- 依模型锐度不同，以束搜索部分调用或内存即可返回精确top-K，且能逐请求检测检索质量退化。



> 💡 该文将推测解码与分支定界引入生成式推荐的SID检索，在保持束搜索级资源的同时提供精确top-K认证与可控误差界，对工业级召回系统的质量监控与延迟优化有直接价值。

**核心贡献**：

- 提出免训练的系统一辅助重排序框架SOARS，单次调用完成段落筛选与候选重排序，联合建模原始问题与子查询。

- 在BrowseComp-Plus上跨六个LLM骨干一致提升答案准确率与证据召回率，同时降低搜索调用次数与端到端延迟。

- 将GPT-5.4 Mini的准确率从73.9%提升至84.7%，搜索调用从23次降至14次，显著降低推理成本。



> 💡 该文提出免训练的系统一重排序框架，在保持搜索智能体准确率提升的同时显著降低检索调用与延迟，为高效深度搜索提供了实用新思路。

### 7. 面向语义反转感知检索的小型学习投影与谱加速：四领域实证研究

针对稠密检索中语义反转陷阱（近副本文档因微小编辑而排名靠前）问题，提出小型学习投影W: R^1024→R^d（d=11或32），在声明案例集上训练以抑制陷阱。在四个独立领域（法律、医疗、专利、金融）和高达10万文档池的12种设置下，HN@10=0.0000，正确释义保留率93-99%。进一步提出边界条件加速器（SpectRAG），用边值求解替代稠密特征分解，在10万规模下保持HN@10=0.0000，约300查询检索耗时0.6-1.1秒（平均每查询2-4毫秒）。投影后索引缩小约90倍且维度成比例加速，支持按领域/租户构建多个小型专用索引。

- 设计边界条件谱加速器SpectRAG，以边值求解替代稠密特征分解，在10万规模下保持HN@10=0.0000，平均每查询检索耗时2-4毫秒。

- 投影后存储表示仅需每文档几个浮点数，专用索引比全嵌入小约90倍且维度成比例加速，使多小型声明索引成为大规模向量库的实用替代方案。

- 完整报告投影跨领域迁移仅部分有效，并开源配方、透镜、陷阱集与评估框架（AGPL-3.0），所有HN指标在精确搜索下可复现。



> 💡 该论文针对稠密检索中容易被语义反转陷阱攻击的脆弱性问题，提出了一种轻量级学习投影与谱加速方案，在四个领域实现了零陷阱命中且检索速度达毫秒级，为构建高效鲁棒的专用检索索引提供了新思路。
