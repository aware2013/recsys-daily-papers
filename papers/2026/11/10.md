### 1. 当贪心即排序：新颖性指标的精确且可认证的理想排序
| 属性 | 内容 |
|------|------|
| **英文标题** | When Greedy Is Sorting: Exact and Certified Ideal Rankings for Novelty Metrics |
| **分类** | 召回与排序 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Kehan Liu, Zhaoyun Chen, Xianquan Yan |
| **作者单位** | — |
| **arXiv** | [2611.10576](http://arxiv.org/abs/2611.10576v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.10576v1) |

针对新颖性指标归一化所需的理想排序在一般情况下为NP难问题，本文发现当每篇文档至多被一个意图正向判定时，α-DCG与ERR-IA可归约为固定预算在递减边际收益链上的经典分配问题，提出ChainMerge方法：先做指标特定的虚拟分数变换再多路归并，以O(G+K log G)或O(n+K log G)时间精确返回全局最优top-K排序，远优于贪心规则的Θ(nK)。当意图重叠时，证明标准对数折扣下α=0.5的精确优化仍为NP难，并提出多项式规模LP上界与最优性间隙认证。在TREC Web 2009-2012上，LP将198个贪心分母中的189个认证为全局最优；在MIND-small的65,238个候选上，ChainMerge比贪心快17-1,011倍且目标值完全一致。


**核心贡献**：

- 证明当每篇文档至多服务一个意图时，α-DCG与ERR-IA的理想排序可精确归约为预算分配问题，ChainMerge以O(G+K log G)时间求得全局最优top-K，替代贪心规则的Θ(nK)。

- 证明意图重叠下标准对数折扣α=0.5的精确α-DCG优化仍为NP难（即使每文档仅三个意图、每意图仅出现于两文档），并给出多项式规模LP上界与最优性间隙认证。

- 在TREC Web 2009-2012上，LP将198个贪心分母中的189个认证为全局最优，所得分数区间在全部8个匹配比较组中保持胜者不变。

- 在MIND-small的65,238个候选上，ChainMerge与贪心目标值完全一致，速度快17-1,011倍。



> 💡 该文首次厘清新颖性指标理想排序的精确可解边界与意图重叠导致的NP难本质，并给出可认证的快速精确算法与LP间隙证书，对排序评估器的正确性与效率均有直接价值。

### 2. 检索模型中的答案搜索偏差
| 属性 | 内容 |
|------|------|
| **英文标题** | Search-by-Answer Bias in Retrieval Models |
| **分类** | 召回与排序 |
| **评分** | 6.3/10 ⭐⭐⭐ |
| **作者** | Adiel Avigad, Shauli Ravfogel, Yoav Goldberg |
| **作者单位** | — |
| **arXiv** | [2611.11396](http://arxiv.org/abs/2611.11396v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.11396v1) |

论文揭示稠密检索器存在“答案搜索偏差”：模型偏好包含其已知答案对象的段落，而非支持有效替代答案的段落。基于LAMA/TREx构建受控事实对比，用token预测头测量模型对规范对象与替代对象的打分差，并检验该分数是否预测段落排序。在DPR、Spider变体、Contriever、E5、Qwen3-Embedding等八个检索器上，token预测分数越高，对应段落检索分数越高；即使段落仅答案对象不同，或高分对象段落表达错误关系时仍成立。表明稠密检索在段落选择阶段存在答案搜索偏差，影响证据检索。


**核心贡献**：

- 提出并验证稠密检索器的“答案搜索偏差”：模型已知答案对象会系统性提升含该对象段落的检索分数。

- 在8个检索器（DPR、Spider变体、Contriever、E5、Qwen3-Embedding等）上一致观察到token预测分数与段落检索分数的正相关。

- 偏差在段落仅答案对象不同、甚至高分对象段落表达错误关系时依然存在，说明偏差独立于语义匹配正确性。



> 💡 该文首次系统揭示稠密检索器会因模型内部知识偏好而偏向含已知答案的段落，对检索公平性与证据多样性有重要警示。

### 7. Lightfoot：支持精确无模型文档删除的图检索增强生成

### 8. 闭合与排序：循环秩二偏好下的精确最大似然聚合
| 属性 | 内容 |
|------|------|
| **英文标题** | Close and Sort: Exact Maximum-Likelihood Aggregation of Cyclic Rank-Two Preferences |
| **分类** | 召回与排序 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Kehan Liu, Zhaoyun Chen, Xianquan Yan |
| **作者单位** | — |
| **arXiv** | [2611.10538](http://arxiv.org/abs/2611.10538v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.10538v1) |

论文研究将成对比较概率聚合为最大似然排序的问题，该问题等价于加权Kemeny问题且一般NP难。作者发现当反对称对数几率矩阵W_ij=log(p_ij/p_ji)为秩二时（即使偏好存在循环），可通过W_ij=det(h_i,h_j)并引入闭合向量h_0=-Σh_i，将目标转化为闭合多边形的有向面积二倍。据此提出CloseSort算法：对n+1个边向量极角排序、在h_0后切分，即可在O(nlogn)时间内从因子得到全局最大似然序。该几何还给出亚军识别与稳定性证书：闭合角循环中相邻边最小行列式δ恰为最优与亚军的对数似然差；对W=W_0+E，CloseSort在W上的遗憾不超过Σ|E_ij|，且当该和小于δ时保持最优（最坏情况紧）。实验上，5,120次determinant-logit模拟中每对观测从4增至64时，秩二投影优于经验插值最优的比例由68.6%升至85.7%；在63个系统、10个评委的3,600个Arena-Hard LLM评审画像上，主导秩二分量占对数几率能量89.2%；在含多数三角的画像上，CloseSort较Borda降低归一化遗憾44%，并在八个基线中均值归一化目标最优；提供因子时比18项排序的精确动态规划快8,407倍。


**核心贡献**：

- 证明秩二对数几率矩阵下加权Kemeny问题可精确求解，CloseSort以O(nlogn)时间给出全局最大似然序，较精确动态规划快8,407倍（18项）。

- 给出稳定性证书：相邻边最小行列式δ等于最优-亚军对数似然差，扰动遗憾上界为Σ|E_ij|且阈值最坏情况紧。

- 模拟中每对观测从4增至64，秩二投影优于经验插值最优的比例从68.6%升至85.7%。

- 在3,600个Arena-Hard LLM评审画像上主导秩二分量占对数几率能量89.2%，含多数三角时较Borda降低归一化遗憾44%。



> 💡 它把成对概率排序这一NP难问题在秩二结构下变成可精确、可证明、可极速求解的几何问题，并给出可落地的稳定性保证，值得研究排序聚合与LLM评审的读者精读。
