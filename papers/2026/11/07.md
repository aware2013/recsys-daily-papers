### 1. 越流行越流行：生成式搜索中的品牌偏见审计
| 属性 | 内容 |
|------|------|
| **英文标题** | The Popular Get More Popular: Auditing Brand Bias in Generative Search |
| **分类** | 公平性与去偏 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Giorgio Monaco, Jacopo Lenti, Francesco Pierri |
| **作者单位** | — |
| **arXiv** | [2611.07614](http://arxiv.org/abs/2611.07614v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.07614v1) |

本文审计生成式搜索引擎中的品牌偏见，从品牌流行度偏见（偏好市场主导品牌）和品牌熟悉度偏见（LLM参数记忆中实体排名优势）两个维度展开。对主要引擎的商业查询评估发现，在1176个头部品牌样本中，前五分位主导品牌的引用频率是平均品牌的1.4至2.8倍，且该偏见已存在于参数记忆中，外部网络检索无法缓解。控制上下文实验表明，将真实品牌签名替换为不熟悉品牌会显著降低推荐排名，而保留事实的内容改写带来的排名提升可忽略不计。


**核心贡献**：

- 在1176个头部品牌样本中，前五分位主导品牌的引用频率是平均品牌的1.4至2.8倍，揭示持续存在的品牌流行度偏见

- 发现该偏见已内嵌于LLM参数记忆中，外部网络检索无法缓解，形成参数化进入壁垒

- 控制实验表明替换为不熟悉品牌签名会显著降低推荐排名，而保留事实的内容改写排名提升可忽略不计

- 揭示生成式搜索引擎通过偏好市场领导者强化“富者愈富”动态



> 💡 该研究首次系统审计生成式搜索中的品牌偏见，揭示LLM参数记忆如何固化“富者愈富”格局，对理解生成式推荐公平性具有重要价值。

### 4. 决策模型作为检索门控：防御注入与污染攻击
| 属性 | 内容 |
|------|------|
| **英文标题** | Decision Models as Retrieval Gates Against Injection and Pollution |
| **分类** | 大模型推荐 |
| **评分** | 6.4/10 ⭐⭐⭐ |
| **作者** | Mahdi Ghadamyari, Reza Habibi |
| **作者单位** | — |
| **arXiv** | [2611.08325](http://arxiv.org/abs/2611.08325v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.08325v1) |

该论文测试开源权重决策模型（无需生成token即可回答文本类型化问题）能否筛查检索段落以防御指令注入和合成污染。在1000个含隐藏注入指令的论坛网页基准上，Kev-4B门控读取HTML，攻击成功率从无防御的27.9%降至已发布缓解措施的13.6%，加入门控后进一步降至5.7%；每段耗时76ms，186个良性页面中误报4个，干净查询响应率保持在85.6%-86.2%。在200查询污染测试台中，过滤候选池使虚假页面暴露率仅0.5%，准确率保持83%（无过滤为28%）。大型LLM作为评判者排序攻击更优（AUROC 0.99 vs 0.94）但成本高十倍。


**核心贡献**：

- 提出基于开源决策模型的检索门控，在1000题注入基准上将攻击成功率从27.9%降至5.7%，每段仅76ms。

- 在200查询污染测试台中，候选池预过滤使虚假页面暴露率降至0.5%，准确率保持83%（无过滤仅28%）。

- 门控读取HTML比纯文本捕获更多攻击，且干净查询响应率仅下降不到1个百分点（85.6%→86.2%）。

- 大型LLM评判者AUROC达0.99优于门控的0.94，但成本高十倍，门控在性价比上更优。



> 💡 该论文提出轻量级决策模型门控，以极低延迟和成本有效防御检索增强生成中的注入与污染攻击，对构建安全的推荐与营销系统具有重要参考价值。
