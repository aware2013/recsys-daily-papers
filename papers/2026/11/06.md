论文识别出生成式推荐中RQ-VAE语义ID量化与解码器之间的语义量化鸿沟（SQG），表现为锚定鸿沟、邻域鸿沟和难度鸿沟。提出BRIDGE框架，包含码本锚定的潜在推理（注入冻结量化器质心作为语义锚点）、特权EMA自蒸馏（从教师向在线学生迁移邻域感知知识以缓解曝光偏差）、难度感知循环（按层级难度分配计算量）。在三个Amazon基准上，Recall@10和NDCG@10平均提升10.9%和9.7%（最高12.6%和10.7%）；在5%流量的大规模电商广告平台一周在线A/B实验中，eCPM提升0.65%。


**核心贡献**：

- 提出码本锚定的潜在推理，将冻结量化器质心作为语义锚点注入解码器，弥补目标侧信息不足

### 2. 对抗性多重性：精选模型与披露的局限
| 属性 | 内容 |
|------|------|
| **英文标题** | Adversarial Multiplicity: Cherry-Picked Models and the Limits of Disclosure |
| **分类** | 公平性与去偏 |
| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Cassandra C. Chou, Benjamin Q. Huynh, Allison Koenecke et al. |
| **作者单位** | — |
| **arXiv** | [2611.07378](http://arxiv.org/abs/2611.07378v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.07378v1) |

论文研究预测多重性（即精度相近的模型对个体预测存在分歧）在对抗场景下被利用的风险。区分软操纵（超参数调优、特征工程等无害模型选择）与硬操纵（直接扰动模型参数），发现足够灵活的模型可在预测性能几乎不变且通过黑盒审计的情况下反转任意个体预测，使硬操纵在多数监管环境中可行；软操纵效果较小但能通过白盒审计。甚至聚合估计（如气候变化对野火的影响）也可被完全反转。Reconcile算法通常能解决多数模型分歧，但当对立模型被对抗性选择时，结果更偏向操纵者。论文梳理了可通过现有监管与披露政策的操纵类型，并提出预注册、模型训练证明、敏感性分析、多指标评估及承诺版本化公开模型等缓解措施。


**核心贡献**：

- 提出对抗性多重性框架，区分软操纵与硬操纵，揭示灵活模型可在预测性能几乎不变且通过黑盒审计下反转任意个体预测

- 证明聚合估计（如气候变化对野火的影响）可被硬编辑与软搜索完全反转，暴露现有披露政策的局限

- 发现Reconcile算法虽能解决多数模型分歧，但在对抗性选择对立模型时更常偏向操纵者

- 提出预注册、模型训练证明、敏感性分析、多指标评估与版本化公开模型等缓解建议



> 💡 该论文系统揭示了预测多重性在对抗场景下被操纵的风险，对理解自动化决策的监管与披露局限具有重要警示价值。

### 8. 从浪费到发现：淘宝信息流推荐中高分未曝光候选的回收利用
| 属性 | 内容 |
|------|------|
| **英文标题** | From Waste to Discovery: Recycling High-Scored Unexposed Candidates in Taobao Feed Recommendation |
| **分类** | 召回与排序 |
| **评分** | 6.2/10 ⭐⭐⭐ |
| **作者** | Ge Fan, Kai Meng, Huiping Chu et al. |
| **作者单位** | Alibaba Group |
| **arXiv** | [2611.05997](http://arxiv.org/abs/2611.05997v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.05997v1) |

针对工业推荐系统中提升探索内容曝光常适得其反的问题，提出免训练的召回阶段系统URED。其核心洞察是：高分但从未曝光的物品兼具相关性与可预测性，而冷启动物品信息贫乏易被排序模型高估。URED在30天窗口内聚合此类候选，通过离线存储、分布式聚合与低延迟在线服务（单次O(1)查询，延迟增加<1%，无需重训模型）重新注入召回。淘宝线上A/B测试（服务数千万日活用户超六个月）显示：发现类目数+3.47%，内容丰富度+8.47%，完播视频观看+2.62%，总观看+0.36%（不显著），互动持平。消融表明一天窗口使发现增益降至+0.55%（不显著），随机注入无增益且互动-0.17%。URED发现率达平台平均13.9倍（最强近线基线6.3倍），互动质量与平台平均相当。


**核心贡献**：

- 提出免训练召回阶段系统URED，回收高分未曝光候选，线上A/B测试发现类目数+3.47%、内容丰富度+8.47%，完播观看+2.62%且互动不降。

- 揭示朴素提升探索内容曝光失效的机制：冷启动物品信息贫乏被排序模型系统性高估，而高分未曝光物品兼具相关性与可预测性。

- 系统仅增加<1%延迟（单次O(1)查询），无需模型重训，在淘宝服务数千万日活用户超六个月，发现率达平台平均13.9倍。

- 消融实验验证设计支柱必要性：一天窗口使发现增益降至+0.55%（不显著），随机注入无增益且互动-0.17%。



> 💡 该论文以反直觉的“回收高分未曝光候选”思路，在淘宝大规模线上验证了免训练、低延迟的探索方案，为工业推荐系统平衡探索与利用提供了可复用的工程范式。
