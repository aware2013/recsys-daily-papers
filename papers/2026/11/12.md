### 1. 一条曲线，不同权重：AUC、Brier分数、决策加权AUC与策略Youden指数
| 属性 | 内容 |
|------|------|
| **英文标题** | One Curve, Different Weights: AUC, the Brier Score, Decision-Weighted AUC, and the Policy Youden Index |
| **分类** | CTR预估 |
| **评分** | 6.4/10 ⭐⭐⭐ |
| **作者** | Yegor Baranovski |
| **作者单位** | — |
| **arXiv** | [2611.14465](http://arxiv.org/abs/2611.14465v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.14465v1) |

论文指出AUC与Brier分数对模型排序可能不一致，提出加权AUC（AUC_π），按决策者行动概率π对样本对加权。核心发现：三者均基于Youden指数曲线J(t)=TPR(t)-FPR(t)的加权平均，仅权重不同——AUC按分数分布加权，Brier按真实概率E[Y|S]加权，AUC_π按决策者行动概率加权；AUC_π归一化后等价于将Brier技能分数的权重移至决策者关注的截断点。进一步证明按|π(s)-π(s')|加权是唯一使成对加权AUC成为Youden曲线平均的预设权重。提出策略Youden指数（AUC_π分子）以统一策略评判所有模型，避免AUC因模型而异加权阈值的问题。


**核心贡献**：

- 证明AUC、Brier分数与所提AUC_π均为Youden指数J(t)=TPR(t)-FPR(t)的加权平均，仅截断点权重不同

- 提出AUC_π，按决策者行动概率π对样本对加权，归一化后等价于权重迁移的Brier技能分数

- 证明|π(s)-π(s')|是唯一使成对加权AUC成为Youden曲线平均的预设成对权重

- 提出策略Youden指数（AUC_π分子），以统一策略评判所有模型，规避AUC的模型依赖阈值加权问题



> 💡 该文统一了AUC与Brier分数的曲线加权视角，并给出面向决策的策略加权指标，对风险评分评估与业务决策对齐具有直接指导价值。

| **作者** | Tomer Solberg |
| **作者单位** | moonmath-ai |
| **arXiv** | [2611.14083](http://arxiv.org/abs/2611.14083v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.14083v1) |

Sable提出一种论证系统与单GPU证明器，用于证明一个承诺的整数量化Transformer从给定提示逐位生成指定token序列。它定义无浮点步骤的整数函数F_O，用约束系统证明其关系不会在31位KoalaBear素数下回绕，并将零检验与LogUp-GKR查找批处理为每域一次Sumcheck，通过Reed-Solomon码、BLAKE3 Merkle树和混合长度BaseFold打开对所有见证张量与权重做一次多线性承诺。证明器在单张RTX PRO 6000 Blackwell上逐层流式处理，92.5秒证明Qwen2.5-32B全部64层（4096 token），16384 token为398秒；覆盖Qwen3-32B与MoE模型Qwen3-30B-A3B。证明开销为服务时间的41-50倍，每4096 token请求约6.4美分，每参数每token时间比zkLLM少40-64倍。F_O贪心token在WikiText-2上与BF16模型86.3%位置一致，Qwen3上MMLU差1.6点、GSM8K差1.7点。单CPU核验证19-56秒，随机预言模型下逐轮可靠性误差2^-103。


**核心贡献**：

- 提出无浮点步骤的整数函数F_O与31位KoalaBear素数约束系统，实现大语言模型逐位精确推理的可验证证明。

- 每参数每token证明时间比zkLLM减少40-64倍，单CPU核验证仅需19-56秒。

- F_O贪心token在WikiText-2上与BF16模型86.3%位置一致，Qwen3上MMLU与GSM8K分别仅差1.6与1.7点。



> 💡 该文首次实现大语言模型位精确推理的高效可验证证明，为开放权重模型的推理审计与可信部署提供了实用工具。

### 4. 比特还是排列？在小规模本地语言模型中将固定推理预算用于权重精度还是选项顺序平均
| 属性 | 内容 |
|------|------|
| **英文标题** | Bits or permutations? Spending a fixed inference budget on weight precision or on option-order averaging in small local language models |
| **分类** | 大模型推荐 |
| **评分** | 6.2/10 ⭐⭐⭐ |
| **作者** | Mohammed Nayeem Khan, Logesh L, Aliyas Ahmad Misri |
| **作者单位** | — |
| **arXiv** | [2611.14413](http://arxiv.org/abs/2611.14413v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.14413v1) |

论文研究小规模本地语言模型在固定推理预算下，应优先将预算用于提高权重量化精度还是用于选项顺序平均。在Qwen3-0.6B和1.7B上模拟8/6/4/3比特权重量化，在ARC-Easy、ARC-Challenge、MMLU和HellaSwag各300题上评估。发现6比特不损失精度甚至略优，4比特时答案槽位偏斜显著上升（0.6B从0.15升至0.53）。以权重读取字节数×推理遍数为统一成本单位，成本匹配比较表明：仅当权重≥6比特时，增加顺序平均才优于增加比特；最优策略为使用6比特权重并将剩余预算用于最多四次循环顺序平均（各一遍）。


**核心贡献**：

- 6比特量化在四个基准上不损失精度，甚至比fp16高1.8和0.9个百分点；8比特反而略降0.7和0.4个百分点。

- 4比特量化使答案槽位偏斜从0.15升至0.53（0.6B）和从0.07升至0.12（1.7B），但等功率高斯噪声对照无法确认舍入额外引入偏斜。

- 在成本匹配下，仅当权重≥6比特时增加顺序平均才优于增加比特；最优策略为6比特权重加最多四次循环顺序平均（各一遍）。

- 4比特下平均四个循环顺序在0.6B上恢复+12.6个百分点（fp16下+5.3）。



> 💡 该文首次系统量化了权重量化与选项顺序平均在固定推理预算下的权衡，为本地小模型部署提供了可操作的决策表。

### 5. 超越交互分数：基于独立复现的特征交互选择
| 属性 | 内容 |
|------|------|
| **英文标题** | Beyond Interaction Scores: Selecting Feature Interactions via Independent Replication |
| **分类** | 可解释性 |
| **评分** | 6.2/10 ⭐⭐⭐ |
| **作者** | Jincheng Gao, Shuo Sun |
| **作者单位** | — |
| **arXiv** | [2611.13765](http://arxiv.org/abs/2611.13765v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.13765v1) |

论文提出LENS框架，通过独立复现选择特征交互，解决高交互分数可能拟合噪声的问题。LENS在不相交数据上训练两个相同算法模型，仅通过预测访问；对每对特征，从联合效应面移除主效应以分离交互模式，按强度排序，并检验第二模型是否在显著强度上复现。单次多重检验校正决定保留哪些特征对，仅需两次模型拟合。理论证明复现比率单独可保留任意弱模式，而强度下限恢复选择一致性，并刻画了Friedman H²归一化反转排序的条件。在16个合成设计上，LENS匹配TreeSHAP等领先方法，恢复91%实质交互（DIAMOND仅45%）且无假阳性；在1225候选对无交互时假发现更少。法国车险数据上识别出精算文献记录的交互，恢复全部对90%的偏差增益；两个信用数据集上选择少量对且保持或略优于加性基线。


**核心贡献**：

- 提出LENS模型无关框架，仅需两次模型拟合即可选择特征交互，计算高效。

- 在16个合成设计上恢复91%实质交互，远超DIAMOND的45%，且无假阳性选择。

- 在法国车险数据上恢复使用全部对90%的偏差增益，并识别出文献记录的交互。

- 理论证明强度下限确保选择一致性，并揭示Friedman H²归一化可能反转交互排序。



> 💡 LENS提供了一种模型无关、仅需两次拟合的特征交互选择方法，在合成和真实数据上显著优于现有方法，值得关注可解释建模与特征工程的读者阅读。
