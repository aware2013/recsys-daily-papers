- AIO的准确性与陈述溯源质量无关，表明高准确性并不保证来源可靠性。



> 💡 该研究首次系统量化了谷歌AI概览在医疗信息场景下的来源选择偏差、溯源缺陷与医生评分准确性，对理解大模型生成式搜索的可靠性与风险具有重要参考价值。

### 2. GistRank：基于大语言模型的要点压缩列表排序
| 属性 | 内容 |
|------|------|
| **英文标题** | GistRank: Gist-Compressed Listwise Ranking with Large Language Models |
| **分类** | 召回与排序 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Guo Chen, Wenhan Liu, Reed Li et al. |
| **作者单位** | — |
| **arXiv** | [2610.39610](http://arxiv.org/abs/2610.39610v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.39610v1) |

针对大语言模型列表排序中逐字序列化候选文档导致推理成本随文档数量和长度线性增长的问题，本文系统研究了软压缩方案，发现朴素要点表示因因果编码削弱信息吸收且缺乏相对偏好结构训练而不适合排序。提出GistRank三阶段训练框架：在半双向注意力下学习忠实的要点token、通过成对训练注入判别性比较能力、适配列表排序目标。每篇文档仅压缩为4个要点token，相比一次性全文排序获得14倍加速，在TREC DL19/20及五个BEIR子集上平均nDCG@10达59.17，与最强全上下文基线差距仅0.89。


**核心贡献**：

- 提出GistRank三阶段训练框架，将每篇文档压缩为仅4个要点token，实现14倍推理加速

- 在半双向注意力机制下学习忠实的要点表示，并通过成对训练注入判别性比较能力

- 在TREC DL19/20和五个BEIR子集上平均nDCG@10达59.17，与最强全上下文基线差距仅0.89

- 系统揭示了朴素要点表示不适合排序的两大原因：因果编码削弱信息吸收与缺乏相对偏好结构训练



> 💡 该论文提出了一种高效的要点压缩列表排序框架，在大幅降低LLM排序推理成本的同时保持了接近全上下文基线的排序质量，对实际搜索系统部署具有重要参考价值。

### 7. 规模代价：主动记忆召回中的多重检验问题
| 属性 | 内容 |
|------|------|
| **英文标题** | The Price of Scale in Proactive Memory Recall |
| **分类** | 大模型推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Yichuan Chen, Xin Wang |
| **作者单位** | — |
| **arXiv** | [2610.34507](http://arxiv.org/abs/2610.34507v2) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.34507v2) |

论文将长期助手主动召回记忆的决策建模为随存储规模N增长的多重检验问题。在LongMemEval流式回放中，按N=8时5%误报率调优的相似度阈值，在N=2048时误报率升至84-100%，LoCoMo与LLM评判亦复现该现象。作者证明对N个无关分数取最大值的门控，其单项误报率约为-ln(1-alpha)/N，使命中率被钉在单比较ROC曲线最左端；有限池形式对留出问题命中率预测误差在6.1个百分点内。提出线索交换保形门控，在可交换性下具有限样本误报保证，以用户未过滤历史为背景时LongMemEval误报率3-6%，时序回放中仅6-8%会话开启轮发言（部署门控为57%），单CPU线程约50ms/决策。


**核心贡献**：

- 揭示主动记忆召回的规模代价：N=8时5%误报率的阈值在N=2048时误报率达84-100%，跨嵌入模型与线索类型一致

- 证明取N个无关分数最大值的门控单项误报率约为-ln(1-alpha)/N，有限池形式对留出集命中率预测误差在6.1个百分点内

- 提出线索交换保形门控，在LongMemEval上以标签调优阈值的命中率将误报率控制在3-6%，时序回放中发言率仅6-8%（对比57%）

- 相同误报率下部署分数比原始余弦相似度多召回14-26个百分点，交叉编码器重排同样承受规模代价



> 💡 该文首次从多重检验视角严格刻画了长期记忆助手主动召回中的规模代价，并给出有有限样本保证的保形门控方案，对构建低打扰的主动式推荐与助手系统具有直接指导价值。
