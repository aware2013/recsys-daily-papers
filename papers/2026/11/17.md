### 1. PMR：基于共享原型与拥堵定价的MoE路由方法

针对稀疏专家混合模型中线性路由器将输入匹配与专家分配耦合的问题，提出原型中介路由（PMR）。PMR采用两阶段路由：先计算每个token在共享原型上的分布，再依据全概率公式混合原型条件化的专家分布，从而分离输入匹配与专家分配，并显式建模原型-专家的多对多关联。短期状态汇总前序token以适配原型，拥堵价格依据调度反馈更新以实现无损负载均衡。采用两遍分块近似加速短期状态处理，训练吞吐量提升20倍以上且路由决策高度一致。在0.43B、1.18B、0.48B三种预训练配置下，七项基准零样本平均准确率较线性路由基线分别提升1.54、2.65、1.45个百分点，ARC-Easy上分别提升6.71、5.80、3.92个百分点；在7B-8B骨干参数高效微调中较MixLoRA平均准确率最高提升1.76个百分点。


**核心贡献**：

- 在0.43B/1.18B/0.48B预训练配置下七项基准零样本平均准确率分别提升1.54/2.65/1.45个百分点，ARC-Easy提升达6.71个百分点



> 💡 该论文为MoE大模型提供了一种解耦匹配与分配、兼顾负载均衡与训练效率的新型路由范式，对大规模推荐与营销模型的高效扩展具有直接参考价值。

### 2. EchoSpec：训练搜索智能体在回声之上权衡证据
| 属性 | 内容 |
|------|------|
| **英文标题** | EchoSpec: Training Search Agents to Weigh Evidence Above Echoes |
| **分类** | 强化学习推荐 |
| **评分** | 6.3/10 ⭐⭐⭐ |
| **作者** | Shihao Yang, Can Zeng, Xinzhe Li |
| **作者单位** | — |
| **arXiv** | [2611.20034](http://arxiv.org/abs/2611.20034v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.20034v1) |

论文揭示强化学习训练的搜索智能体存在"回声偏误"：在多跳维基问答中，8条改写虚假声明回声可使58-73%原本正确的答案被推翻，且删除证据后的弃答率降至15%以下。分析表明失败源于证据获取阶段——回声占据检索排名前列并导致过早停止搜索。作者提出EchoSpec，采用两阶段训练：验证热启动学习跨越回声的多跳桥接实体恢复，随后用组RL优化证据门控λ奖励，含与结果无关的获取奖励和保持最优规则λ/(1+λ)的尺度保持优势。在Qwen2.5-3B/7B和Llama-3.1-8B上，EchoSpec将8回声顺从率降低30-44个百分点（Qwen2.5-7B降至29-31%），8回声触达率提升近4倍至26-27%，并零样本迁移至BGE与BM25检索器，独立QA精确率提升至47-55%。


**核心贡献**：

- 揭示RL搜索智能体的回声偏误：8条改写虚假声明回声可推翻58-73%的正确答案，删除证据后弃答率低于15%。

- 定位失败根因为证据获取阶段：回声占据检索排名前列并导致过早停止搜索，增大预算或强制搜索轮次均无法恢复被 displaced 的证据。

- 提出EchoSpec两阶段训练框架，在Qwen2.5-7B上将8回声顺从率降低30-44个百分点至29-31%，8回声触达率提升近4倍至26-27%。

- 实现零样本迁移至未见BGE与BM25检索器，独立QA精确率提升至47-55%。



> 💡 该论文首次系统揭示并量化了RL搜索智能体的回声偏误，提出的EchoSpec训练框架在多个基座模型上显著提升证据权衡能力且具备检索器零样本迁移性，对构建可信搜索智能体具有重要参考价值。

论文提出StaleBench基准，基于892条真实更新事实（Wikidata有效期标签）隔离智能体记忆中的陈旧检索失败。核心发现：检索指标可能反向排序记忆策略——保留策略与全保留控制在无日期展示时对每个查询返回相同rank-1陈述，但阅读器准确率相差29.5和65.6分；新指标Contamination@5能正确排序。移除词法锚点使部署键控机制新鲜度下降数十点，写入与查询双侧实体解析可恢复大部分损失。评测Mem0、Graphiti、LangMem及ERASE重实现，发现无统一评分约定，并发布数据、冻结评测器与基线。


**核心贡献**：

- 构建StaleBench基准，含892条真实更新事实及来源货币标签，隔离陈旧检索失败

- 揭示检索指标可反向排序记忆策略：保留策略与全保留控制rank-1返回相同陈述，但阅读器准确率相差29.5和65.6分

- 提出Contamination@5指标，在current@1/current@5失效时正确排序策略

- 评测三个部署系统与ERASE重实现，发现无单一评分约定可描述四者，并发布数据与冻结评测器



> 💡 该文首次系统隔离并量化智能体记忆中的陈旧检索问题，揭示常用检索指标的排序陷阱，对构建可靠记忆系统具有直接指导价值。

### 5. 强化学习在生成式推荐模型中的探索
| 属性 | 内容 |
|------|------|
| **英文标题** | Exploration of Reinforcement Learning in Generative Recommendation Models |
| **分类** | 强化学习推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Pengfei Zheng, Wuchao Li, Shiyao Wang et al. |
| **作者单位** | — |
| **arXiv** | [2611.19742](http://arxiv.org/abs/2611.19742v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.19742v1) |

针对生成式推荐中直接应用强化学习（RL）导致优化不稳定和推荐质量下降的问题，本文从统一的logit梯度视角重新审视GRPO等基于比率的目标函数，识别出三个问题：裁剪代理产生死梯度区域、负优势更新随重要性比率增长而趋于无界、基于比率的控制对绝对策略置信度不敏感。据此提出梯度有界策略优化（GBPO），采用停止梯度归一化，实现全梯度活跃、正负更新符号对称有界、并显式按当前策略概率加权，使π→1的正样本和π→0的负样本更新优雅消失。实验表明GBPO在推荐性能上具有竞争力且训练更稳定。


**核心贡献**：

- 从统一logit梯度视角诊断出GRPO等比率型RL目标在生成式推荐中的三个梯度缺陷：死梯度区域、负优势无界更新、缺乏置信度敏感性。

- 提出GBPO目标，通过停止梯度归一化实现全梯度活跃、正负对称有界且显式置信度加权，使极端概率样本更新自然消失。

- 在多个评估设置下，GBPO取得有竞争力的推荐性能，同时训练稳定性优于对比RL方法。



> 💡 该文精准诊断了生成式推荐中RL目标函数的梯度缺陷，并给出简洁有效的GBPO修正方案，对提升RL训练稳定性具有直接参考价值。

### 6. 从突变到用药：临床大模型在基因组耐药性遵循上的失败特征分析
| 属性 | 内容 |
|------|------|
| **英文标题** | From Mutation to Medication: Characterizing Failures of Clinical LLMs to Respect Genomic Resistance |
| **分类** | 大模型推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Negin Ashrafi, Roxana Daneshjou |
| **作者单位** | — |
| **arXiv** | [2611.19339](http://arxiv.org/abs/2611.19339v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.19339v1) |

论文评估十个语言模型在1,464个基因组耐药案例上的表现（共58,910次判断），发现模型对耐药疗法的认可率为21.8%-81.4%，但原始比率可能反映的是顺从倾向而非辨别能力（某开源模型对耐药与敏感对照的认可率分别为81.4%和82.3%）。在基因与证据等级匹配组内比较显示，失败程度强烈依赖参考知识库与证据强度：当第二来源独立确认耐药时，三个厂商的四个模型认可率不超过2.4%；弱证据层级下无法测得辨别力。模型有时承认耐药仍推荐该疗法；重复模型自身耐药结论可将认可率降至0.0%-3.5%，而错误归因相反结论会使所有七个托管模型的认可率高于基线（GPT-4o达95.2%）。提供正确策展证据可将无保留强推荐降至0.3%-3.5%。


**核心贡献**：

- 构建了覆盖五个肿瘤学知识库、1,464个耐药案例、58,910次判断的临床LLM耐药性遵循评估基准，揭示模型对耐药疗法的认可率高达21.8%-81.4%。

- 发现原始认可率存在顺从偏差：某开源模型对耐药案例与敏感对照的认可率几乎相同（81.4% vs 82.3%），匹配基因与证据等级后辨别力显著下降。

- 证据强度与来源决定失败程度：第二来源独立确认耐药时四个模型认可率≤2.4%，而错误归因相反结论可使GPT-4o认可率升至95.2%。

- 重复模型自身耐药结论可将认可率降至0.0%-3.5%，提供正确策展证据可将无保留强推荐降至0.3%-3.5%，表明模型具备证据利用潜力但易受归因框架影响。



> 💡 该文系统揭示了临床大模型在基因组耐药证据面前仍推荐耐药疗法的失败模式及其对证据强度与归因框架的敏感性，为医疗LLM的安全评估与提示设计提供了可复用的量化基准。

### 7. LLM交易智能体赚取的是贝塔而非阿尔法：一项无前视偏差的基准测试
| 属性 | 内容 |
|------|------|
| **英文标题** | LLM Trading Agents Earn Beta, Not Alpha: A Look-Ahead-Free Benchmark |
| **分类** | 大模型推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Jackson Wang |
| **作者单位** | — |
| **arXiv** | [2611.19530](http://arxiv.org/abs/2611.19530v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.19530v1) |

论文提出rta-bench-1基准，覆盖美国三个市场（牛市、熊市、崩盘），严格按新闻发布分钟回放、盲测并检测前视偏差，将收益分解为因子暴露与阿尔法，并以同日同行业随机选股为对照。在四家厂商六个模型的91次运行中，无一阿尔法显著，市场与风格暴露中位数占收益78%，选股不优于随机；智能体倾向买入最正面新闻股票，但消融实验显示去掉新闻收益不变；提示中单条现金规则可使GPT类智能体持股比例下降30.3个百分点。


**核心贡献**：

- 构建rta-bench-1无前视偏差基准，按新闻发布分钟回放并逐次检测前视，覆盖牛市、熊市与崩盘三类美国市场。

- 91次运行中六个LLM交易智能体均无显著阿尔法，市场与风格暴露中位数解释78%的收益，选股表现不优于同日同行业随机选择。

- 消融实验表明智能体虽偏好正面新闻股票，但去除新闻后收益无显著变化，说明其收益主要来自贝塔暴露而非信息优势。

- 提示中加入单条现金规则可使GPT类智能体持股比例在全部六组配对中下降30.3个百分点，显示其规则遵循能力可靠。



> 💡 该文以严谨的无前视基准揭示LLM交易智能体的收益主要来自市场贝塔而非阿尔法，为评估LLM智能体的真实能力提供了方法论范本。

### 8. 学习顺序能解释遗忘吗？李括号作为无旧数据灾难性遗忘的早期预警信号

| **英文标题** | Does Learning Order Explain Forgetting? The Lie Bracket as an Early-Warning Signal for Catastrophic Forgetting Without Old Data |
| **分类** | 可解释性 |
| **评分** | 5.8/10 ⭐⭐ |
| **作者** | Ephraim Kofi Ayi Kwapong |
| **作者单位** | — |
| **arXiv** | [2611.20087](http://arxiv.org/abs/2611.20087v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2611.20087v1) |

论文实证检验Dherin(2023)的猜想：两个任务梯度场的李括号非零可能与灾难性遗忘相关。在Split MNIST、Split Fashion-MNIST和Split CIFAR-10上，任务A的遗忘几乎等于两种训练顺序下A损失的差异（Spearman ρ=0.96-1.00）。仅用任务A结束时存储的梯度及前20个Hessian特征对，李括号可在任务B训练早期、无A数据条件下预测遗忘：任务增量场景下排序ρ=0.70-0.81，优于EWC惩罚（0.33-0.58）且匹配或超过重评A数据；域增量场景下存储摘要失效，EWC更优；旧任务仅半学习时李括号完全失效，归因于A上残差梯度大一个数量级使一阶损伤主导。


**核心贡献**：

- 实证验证李括号与遗忘的强关联：两种训练顺序下任务A的损失差与遗忘的Spearman相关系数达0.96-1.00。

- 仅用任务A结束时存储的梯度和前20个Hessian特征对，李括号在任务增量场景下以ρ=0.70-0.81排序遗忘，优于EWC惩罚（0.33-0.58）。

- 揭示李括号预警的明确边界条件：域增量场景下存储摘要失效、EWC更优；旧任务仅半学习时李括号完全失效，因残差梯度大一个数量级使一阶损伤主导。



> 💡 该文为'无旧数据下早期预警灾难性遗忘'提供了首个基于李括号的实证信号与清晰的适用边界，对持续学习与模型更新策略设计有直接参考价值。
