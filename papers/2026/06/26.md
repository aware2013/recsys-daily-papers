| **PDF** | [下载](https://arxiv.org/pdf/2606.25487v1) |

本文系统评估了用于LLM越狱攻击成功率（ASR）评分的两类自动裁判：专用安全分类器和通用大语言模型裁判。基于HarmBench分类器验证集的596个人工标注样本，发现两类裁判存在相反缺陷：专用分类器过度标记（精确率0.835，召回率0.974），而三种LLM裁判精确率高（0.81-0.94）但召回率波动大（0.06-0.65）。在鲁棒性上，仅添加良性框架的包装攻击可使LLM裁判翻转57%-100%，单个拒绝句即可造成39%-88%翻转；专用分类器抵抗表面攻击（≤6.7%），但白盒GCG攻击可翻转70%的高置信度真阳性。两标注者审计确认攻击后有害内容未变。建议论文报告裁判精确率与召回率、校正ASR并包含对抗性检查。


**核心贡献**：

- 揭示专用分类器与LLM裁判在ASR评分上的系统性偏差：专用分类器召回率0.974但精确率仅0.835，LLM裁判精确率0.81-0.94但召回率低至0.06-0.65。

- 发现简单包装攻击可使LLM裁判翻转57%-100%的判定，单个拒绝句即可造成39%-88%翻转，而专用分类器抵抗此类攻击（≤6.7%）。

- 白盒GCG攻击在极小优化预算下即可翻转专用分类器70%的高置信度真阳性（21/30，95% CI 54-86%），且审计确认有害内容未变。



> 💡 本文首次系统揭示了自动化ASR裁判的校准缺陷与对抗脆弱性，为LLM安全评估提供了关键方法论修正。

### 4. 信念的成本几何：有限资源下的噪声观测推断
| 属性 | 内容 |
|------|------|
| **英文标题** | The Cost Geometry of Belief: finite-resource inference under noisy observation |
| **分类** | 大模型推荐 |
| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Laurent Caraffa |
| **作者单位** | — |
| **arXiv** | [2606.21585](http://arxiv.org/abs/2606.21585v3) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.21585v3) |

本文提出信念-成本几何框架，将有限智能体在噪声观测下的贝叶斯后验更新成本建模为Wasserstein空间上的最优传输度量，并由Fisher信息（精度价格）进行共形加权，度量形式为$\tilde g_{e,U}=2(e+U)\,g_{W_2}$。基于两个公设（修订成本为传输标量价格、诚实性即每纳特成本处处相等），推导出三个结果：当缓解项主导Fisher信息时，确定性推断的成本距离发散（形成“墙”）；诚实族等价于$U=cJ$的Fisher族；刚性结果表明这些几何是双曲的，且高斯分布是最双曲的位置-尺度信念（$e=0$时Stam界为-1/4）。热力学将成本单位固定为$k_BT$每纳特。


**核心贡献**：

- 提出信念-成本几何框架，将有限资源下的贝叶斯推断成本建模为Fisher信息加权的Wasserstein最优传输度量。

- 证明当缓解项主导Fisher信息时，确定性推断的成本距离发散，形成不可达的“墙”。

- 揭示该几何是双曲的，且高斯分布是位置-尺度族中最双曲的信念（$e=0$时Stam界为-1/4）。



> 💡 本文为有限资源推断提供了优雅的几何基础，对理解大模型推理成本与精度权衡具有重要理论价值。

### 5. 合成数据增强何时能改善基于评分的非平衡分类？
| 属性 | 内容 |
|------|------|

| **分类** | 公平性与去偏 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Zhengchi Ma, Pengfei Lyu, Anru R. Zhang |
| **作者单位** | — |
| **arXiv** | [2606.26053](http://arxiv.org/abs/2606.26053v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.26053v1) |

本文构建了一个理论框架，分析合成数据增强对基于评分的非平衡分类指标（如AUROC、AUPRC、最佳阈值平衡准确率和F1分数）的影响。将增强效果分解为有效类别权重的变化与合成分布误差。在模型设定正确时，原始估计器已接近总体最优，增强仅能提供有限样本方差缩减，且可能引入偏差；在模型设定错误时，增强可通过改变类别平衡修正排序错误。实验验证了理论结论。


**核心贡献**：

- 在模型设定正确时，合成数据增强无法带来总体层面的性能提升，仅可能通过有限样本方差缩减带来微小改进。

- 在模型设定错误时，增强通过改变有效类别平衡修正排序错误，并给出了包含近似误差、估计误差和合成分布误差的改进上界。

- 模拟实验表明，设定正确时增强收益有限，设定错误时存在非单调但显著的改进。



> 💡 本文为合成数据增强在非平衡分类中的有效性提供了严谨的理论边界，对推荐系统中的长尾物品优化具有重要指导意义。
