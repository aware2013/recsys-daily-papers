| **PDF** | [下载](https://arxiv.org/pdf/2606.19960v1) |

Stellar提出一种可扩展的多模态文档检索框架，解决多向量表示在检索时内存开销大的问题。核心包括：(i)基于词汇表示的过滤（LRF），微调多模态大语言模型作为稀疏编码器生成高质量词汇表示，高效缩小候选集；(ii)高效的磁盘支持后期交互（DLI），通过平衡聚类算法设计磁盘存储布局，并利用成本模型动态加载必要嵌入。在四个真实基准和一个新的大规模数据集上，Stellar相比现有方法将内存开销和查询延迟降低1-2个数量级，且不损失检索效果。


**核心贡献**：

- 设计DLI机制，通过平衡聚类和成本模型将文档嵌入存储在磁盘上并动态加载，相比现有方法降低内存开销和查询延迟1-2个数量级。

- 在四个真实基准和新的大规模数据集上验证，Stellar在保持检索效果的同时实现数量级级的可扩展性提升。

- 在MRBench基准上取得13.1%的显著提升，并在多个标准检索基准上达到SOTA。

### 7. 流式工具使用何时有效？——流式检索增强生成中的工具意图稳定化特征分析
| 属性 | 内容 |
|------|------|
| **英文标题** | When Does Streaming Tool Use Help? Characterizing Tool-Intent Stabilization in Streaming Retrieval-Augmented Generation |
| **分类** | 召回与排序 |
| **评分** | 6.4/10 ⭐⭐⭐ |
| **作者** | Elroy Galbraith |
| **作者单位** | — |
| **arXiv** | [2606.20113](http://arxiv.org/abs/2606.20113v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.20113v1) |

本文研究流式RAG中投机性工具查询的收益条件，提出“工具意图稳定化”概念，即输入流中投机查询的检索结果收敛到正确答案的时刻。在CRAG基准（1371个验证问题）上，测量了稳定化分布，推导出模型无关的上界H（可隐藏的工具延迟比例，与工具延迟L和输入节奏δ相关），并通过实际流式管线验证节省达到或超过该上界。实验表明，在典型参数（L=600ms, δ=3w/s, θ=0.8）下，73.9%的查询可实现显著延迟隐藏；其中21.3%的查询（金标准证据逐字存在且BM25可检索）的流式比例高达95.2%。研究无需模型训练，在普通CPU上运行。


**核心贡献**：

- 首次定义并量化了流式RAG中工具意图稳定化点，发现73.9%的查询在典型参数下可实现显著延迟隐藏。

- 推导出模型无关的延迟隐藏上界H，并验证实际管线节省达到或超过该界。

- 识别出查询类型对稳定化早晚有显著影响（Kruskal-Wallis p=0.017, epsilon^2=0.04），为学习型投机触发器的成本效益提供依据。



> 💡 本文通过精细的稳定化分析揭示了流式RAG中投机查询的收益条件与边界，为延迟优化提供了可量化的理论指导。

### 8. 标量交互作用的表征极限：一种干预分解方法
| 属性 | 内容 |
|------|------|
| **英文标题** | The Representational Limit of Scalar Interactions: An Interventional Decomposition |
| **分类** | 可解释性 |
| **评分** | 6.4/10 ⭐⭐⭐ |
| **作者** | Potito Aghilar, Sabino Roccotelli, Stanislao Fidanza et al. |
| **作者单位** | — |
| **arXiv** | [2606.19410](http://arxiv.org/abs/2606.19410v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.19410v1) |

本文证明标量成对交互分数从根本上混淆了唯一性（U）、冗余性（R）和协同性（S）三种机制，并以3-way XOR结构因果模型为例给出理论证明。提出Stochastic Hi-Fi，一种无需重新训练的事后可预测性分解方法，通过干预掩码推理估计每个特征的U/R/S分布。该方法提供精确的干预语义、有限样本蒙特卡洛界、耦合菱形采样带来的严格方差缩减以及均匀有限词汇收敛性。在表格SCM上，Stochastic Hi-Fi恢复结构的能力比标量基线高出411倍（交互幅度恢复比）。在GPT-2 IOI电路中分离了冗余和协同注意力头。在NIH ChestX-ray14上，Stochastic Hi-Fi在Pointing Game上与GradCAM持平，并在Deletion AUC上显著提升。


**核心贡献**：

- 理论证明标量成对交互分数（如Shapley-Taylor、Shapley Interaction）在3-way XOR模型上无法区分唯一性、冗余性和协同性，导致机制混淆。

- 提出Stochastic Hi-Fi方法，通过干预掩码推理实现无需重新训练的U/R/S分解，在表格SCM上交互幅度恢复比最高提升411倍。

- 在GPT-2 IOI电路中成功分离冗余和协同注意力头，并在NIH ChestX-ray14医学影像上Deletion AUC显著优于基线。



> 💡 本文揭示了标量交互分数的根本局限，并提出一种高效的干预分解方法，为理解复杂模型中的特征交互提供了全新视角。
