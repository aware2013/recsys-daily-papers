### 1. ConvMemory v3：通过目标条件关系验证实现对话记忆的有效性上下文层
| 属性 | 内容 |
|------|------|
| **英文标题** | ConvMemory v3: A Validity Context Layer for Conversational Memory via Target-Conditioned Relation Verification |
| **分类** | 序列推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Taiheng Pan |
| **作者单位** | — |
| **arXiv** | [2606.26753](http://arxiv.org/abs/2606.26753v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.26753v1) |

本文提出ConvMemory v3，在对话记忆检索后增加有效性上下文层，通过目标条件关系验证检测记忆是否被后续对话更新或取代。核心机制是双证据门控，结合MiniLM和DeBERTa-v3的槽头对（目标，源）对进行关系评分，并由保守事件/操作证据门控。在合成多跳有效性基准上达到90.12%±1.73准确率；通过真实数据反馈循环（仅用合成对训练），在Memora角色绑定任务上零目标标签达到98.8%±0.9组全正确。部署后，上下文模式保留原始检索排序，查询条件降级模式将当前活跃H@1从45.1%提升至95.7%±1.2，同时保护非取代记忆召回率达99.4%。


**核心贡献**：

- 提出双证据门控机制，结合MiniLM和DeBERTa-v3进行目标条件关系验证，在合成基准上达到90.12%准确率。

- 通过真实数据反馈循环（仅用合成对训练），零目标标签下在Memora角色绑定任务上实现98.8%组全正确。

- 查询条件降级模式将当前活跃H@1从45.1%提升至95.7%，同时非取代记忆召回率保持99.4%。



> 💡 本文为对话记忆引入有效性验证层，显著提升当前状态检索精度，对序列推荐中的时效性建模具有重要参考价值。
