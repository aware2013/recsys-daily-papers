### 2. FoundCause：基于观测数据且存在潜在混杂因子的因果发现方法
| 属性 | 内容 |
|------|------|
| **英文标题** | FoundCause: Causal Discovery with Latent Confounders from Observational Data |
| **分类** | 图神经网络 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Patrick Blöbaum, Krishnakumar Balasubramanian, Shiva Prasad Kasiviswanathan |
| **作者单位** | — |
| **arXiv** | [2606.17516](http://arxiv.org/abs/2606.17516v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.17516v1) |

FoundCause是一种端到端学习的因果发现模型，完全在合成数据上训练，通过单次前向传播将观测数据集直接映射为因果图。模型采用置换不变Transformer编码器，交替对样本和变量进行注意力计算，并注入基于经典非对称性度量的统计特征。其解码器分离边存在性与方向性，通过三角精炼模块推理高阶因果结构（如链、对撞），并利用可学习潜在令牌显式建模隐藏混杂因子。在15个真实数据集上，FoundCause相比11种非摊销方法和4种摊销方法，F1提升9.6%，AUROC提升1.2%，结构汉明距离降低18.9%。


**核心贡献**：

- 首次提出显式建模潜在混杂因子的摊销式因果发现方法，通过可学习潜在令牌捕获隐藏共同原因。

- 在15个真实数据集上，F1比最强非摊销方法提升9.6%，AUROC提升1.2%，结构汉明距离降低18.9%，且推理仅需单次前向传播。



> 💡 该论文将因果发现从多轮优化推进到单次前向传播，并首次显式处理潜在混杂，兼具理论创新与实用效率。

### 3. 基于两阶段回归的快速非参数条件独立性检验
| 属性 | 内容 |
|------|------|

| **分类** | 图神经网络 |
| **评分** | 6.4/10 ⭐⭐⭐ |
| **作者** | Eric V. Strobl |
| **作者单位** | — |
| **arXiv** | [2606.18011](http://arxiv.org/abs/2606.18011v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.18011v1) |

本文提出BLITZ方法，用于约束因果发现中的快速非参数条件独立性检验。该方法首先通过低阶多项式回归去除对条件集的宽泛平滑依赖，然后利用浅层树回归对非线性特征映射进行残差化，最后检验残差交叉协方差，并采用矩匹配卡方近似零分布。理论分析表明两阶段设计降低了树回归的有效复杂度，从而控制条件均值偏差并避免过拟合。实验显示，BLITZ在零校准上优于快速核方法、随机特征和基于回归的竞争者，同时保持最快速度之一；在合成图和流式细胞术数据的因果发现中，BLITZ提供了更可靠的端点定向和竞争性的结构恢复能力。


**核心贡献**：

- 提出BLITZ两阶段残差化方法，在亚秒级运行时间内实现非参数条件独立性检验的准确校准。

- 理论证明两阶段设计降低树回归的有效复杂度，使浅层树能控制条件均值偏差并避免过拟合。

- 在合成图和流式细胞术数据上，BLITZ比快速核方法、随机特征和回归基线方法提供更好的零校准和更可靠的因果定向。



> 💡 BLITZ通过巧妙的宽到局部残差化策略，在保持速度的同时显著提升了非参数条件独立性检验的校准性，是因果发现领域的重要进展。

本文研究LLM推荐中的品牌动态，以护肤品为实验品类，测试GPT-4o-mini、Claude Sonnet、Gemini 3 Flash三个商业模型。发现：(1)当产品规格相同时，知名品牌获得100%推荐（IAI=10.0），但竞争对手仅需+0.1星优势即可打破垄断；(2)权威式营销语言（含虚构临床证据）以+0.17评分点的偏差剩余价值打破垄断，各模型反应不同；(3)多品牌GEO竞争中，所有品牌采用相同优化策略时，个体收益从+0.802降至+0.007，未参与品牌获零推荐。结果表明GEO不仅是安全风险，更是塑造市场竞争的新兴营销实践。

> 💡 本文首次系统揭示LLM在生成式推荐中的记忆行为缺陷，并提出有效的训练策略来缓解该问题，对提升推荐泛化能力具有重要参考价值。

本研究通过预注册的随机选择联合实验，审计了12种开源和商业大语言模型（LLM）在酒店推荐中的决策机制。实验独立随机化酒店评分、评论量、回复率、连锁品牌、价格、生态认证和列表位置等信号，估计各信号对推荐概率的平均边际成分效应。结果显示：评分和价格主导推荐（高评分提升31.6个百分点，高价格降低30.0个百分点），生态认证被过度加权，管理回复被忽略；列表位置（无内容特征）产生因果影响，等价于每晚12美元的价格效应。研究为生成式引擎优化和AI中介问责提供了因果证据。
