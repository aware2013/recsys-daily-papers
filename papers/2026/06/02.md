本文提出量子隧穿感知机器学习（QTAML），利用WKB近似从第一性原理推导出部署时的权重误差分布，发现其具有仿射均值漂移、按位方差层次（最高有效位主导）及逐层依赖结构。基于此设计隧穿感知补偿（TAC）算法，结合闭式均值校正与WKB方差分解的层自适应比特预算分配。在四种卷积架构（p_flip=0.10）和Transformer编码器（p_flip=0.05）上，TAC达到95%干净准确率，且ECC开销比Uniform-MSP基线低3.4倍至33.6倍。无需重训练、标签或推理时开销。


**核心贡献**：

- 首次从WKB量子隧穿物理推导出部署时权重误差的精确结构（仿射均值漂移、MSB主导方差层次、逐层依赖），优于通用高斯噪声模型。

- 提出TAC算法，在p_flip=0.10时达到95%干净准确率，ECC开销比Uniform-MSP基线降低3.4×至33.6×。

- 闭式饱和比ρ*可提前预测增益，在异构架构上WKB评分优于基于幅度的分配，小预算时提升达24个百分点。

### 10. 超越访问：引导式大语言模型支架在本科统计学自主学习中的应用

|------|------|
| **英文标题** | Beyond Access: Guided LLM Scaffolding for Independent Learning in Undergraduate Statistics |
| **分类** | 大模型推荐 |
| **评分** | 6.3/10 ⭐⭐⭐ |
| **作者** | Mohammad Amanlou, Yasaman Amou-Jafari, Mehrad Livian et al. |
| **作者单位** | — |
| **arXiv** | [2606.01375](http://arxiv.org/abs/2606.01375v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.01375v1) |

本研究通过一项为期四周的准实验，比较了无LLM访问、无限制LLM访问和引导式LLM访问三种条件下本科生在概率统计课程中的学习效果。引导组学生接受了明确训练和规则，强调以推理为中心的求助、逐步提示、验证和伦理使用。所有测验和期末考试均不允许使用LLM或外部帮助。结果表明，引导式LLM使用比无限制访问更能促进以学习为导向的交互模式（优先推理而非答案），引导组在干预阶段的独立测验表现更强，而无限制访问更有助于完成辅助练习而非持续提升独立表现。时间测量不支持简单时长解释，引导组自我评估校准更好。结论：仅提供LLM访问是不完整的教育干预，关键在于设计支架引导学生将LLM用作推理伙伴而非答案工具。


**核心贡献**：

- 引导式LLM使用相比无限制访问，显著提升了学生优先推理而非答案的交互模式（定性分析）。

- 引导组在干预阶段的独立测验（无辅助）表现显著优于无限制访问组（定量结果）。

- 无限制LLM访问更有助于辅助练习完成，但未能持续改善独立学习表现，表明仅提供访问不足以支持自主学习。
