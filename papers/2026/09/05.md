### 1. DoPR：可复用压缩文档前缀用于高效大模型重排序
| 属性 | 内容 |
|------|------|
| **英文标题** | DoPR: Reusable Compressed Document Prefixes for Efficient LLM Reranking |
| **分类** | 召回与排序 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Beiya Dai, Yifan Wei, Guang Yang et al. |
| **作者单位** | — |
| **arXiv** | [2609.03311](http://arxiv.org/abs/2609.03311v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.03311v1) |

大语言模型（LLM）作为重排序器效果显著，但逐点重排序在不同查询下重复处理相同文档，导致大量冗余的文档侧计算。本文提出DoPR框架，将文档处理与在线重排序解耦：离线选择与查询无关的文档表示并转换为压缩前缀状态，在线重排序时仅处理查询和评分token，复用预计算的文档前缀。在TREC DL、BEIR和BRIGHT数据集上，使用Qwen3（0.6B-8B）模型，DoPR实现了最高8.0倍的文档侧内存减少和8.04倍的延迟加速，同时保持全文档重排序器平均NDCG@10的97.1%-99.5%。


**核心贡献**：

- 提出离线文档压缩前缀与在线查询处理解耦的框架，实现跨查询前缀复用，减少冗余计算。

- 在TREC DL、BEIR和BRIGHT上，使用Qwen3模型，达到8.0倍内存减少和8.04倍延迟加速。

- 在保持97.1%-99.5%的NDCG@10性能下，显著提升重排序效率，且模型规模从0.6B到8B均有效。



> 💡 该论文提出一种高效的LLM重排序方法，通过离线压缩文档前缀实现跨查询复用，大幅降低在线计算成本，是检索系统性能优化的关键进展。

### 2. CORE：通过重排序器蒸馏提升多模态大模型嵌入的组合推理能力
| 属性 | 内容 |
|------|------|
| **英文标题** | CORE: Improving Compositional Reasoning in MLLM Embedding via Reranker Distillation |
| **分类** | 多模态推荐 |
| **评分** | 6.7/10 ⭐⭐⭐ |
| **作者** | Tingyu Song, Mingxin Li, Yanzhao Zhang et al. |
| **作者单位** | — |
| **arXiv** | [2609.04083](http://arxiv.org/abs/2609.04083v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.04083v1) |

多模态大模型（MLLM）嵌入模型在组合检索中表现有限，难以区分包含相同概念但属性-对象绑定不同的场景。然而，同一骨干网络在交叉注意力重排序器中能解决此类区分，因此本文提出CORE，通过蒸馏重排序器的组合判断到嵌入模型。CORE合成覆盖五个组合匹配级别的候选列表，并引入Rank-KL目标，使嵌入模型复现重排序器的细粒度排序。在相同数据和调优预算下，对比对比学习、成对CoSENT和列表式Rank-KL，发现CoSENT和Rank-KL更有效，Rank-KL性能最优。在COLA、SUGARCREPE++、NEGBENCH三个基准上，CORE-RERANKER-8B总平均82.7%，超过Jina-Reranker 10.7个百分点；CORE-EMBED-8B在嵌入模型中总平均最佳（0.666），且改进可迁移至MCMR基准，不牺牲COCO和Flickr30K的检索性能。


**核心贡献**：

- 提出CORE框架，通过重排序器蒸馏提升MLLM嵌入模型的组合推理能力，合成五级组合匹配候选列表。

- 引入Rank-KL列表式蒸馏目标，优于对比学习和成对CoSENT，在相同预算下取得最佳性能。

- CORE-RERANKER-8B在三个组合推理基准上总平均82.7%，超过Jina-Reranker 10.7个百分点；CORE-EMBED-8B在嵌入模型中总平均最佳（0.666）。

- 改进可迁移至MCMR基准，且不牺牲COCO和Flickr30K的检索性能。



> 💡 该论文通过蒸馏重排序器的组合推理能力到嵌入模型，显著提升多模态组合检索性能，是值得阅读的重要进展。

### 6. SPAR：通过真实世界空间感知增强工业级生成式兴趣点推荐

|------|------|
| **英文标题** | SPAR: Enhancing Industrial-Scale Generative POI Recommendation via Real-World Spatial Perception |
| **分类** | 大模型推荐 |
| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Fangye Wang, Yunjin Gu, Haowen Lin et al. |
| **作者单位** | — |
| **arXiv** | [2609.02062](http://arxiv.org/abs/2609.02062v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.02062v1) |

针对生成式兴趣点（POI）推荐中地理信息仅作为文本属性、缺乏显式空间建模的问题，提出SPAR统一框架。该框架包含三阶段：在分词层，通过空间固有SID（SI-SID）将经纬度编码为正弦地理嵌入并与语义嵌入融合，经RQ-Kmeans生成语义与地理一致的标识符；在认知层，通过多粒度地理连续预训练（MG-CPT）在25个地理数据集上持续预训练基础LLM，使POI形成连通城市空间；在适配层，通过任务向量锚定微调（TV-SFT）冻结空间知识参数，防止行为微调时灾难性遗忘。在两个公共和四个工业数据集上的实验表明SPAR显著优于基线。


**核心贡献**：

- 提出SI-SID将经纬度坐标编码为地理嵌入并与语义嵌入融合，使生成的POI标识符同时具备语义和地理一致性

- 设计MG-CPT在25个地理数据集上分三层次持续预训练，使散乱POI形成连通城市空间知识

- 采用TV-SFT将空间知识作为冻结任务向量锚定，避免行为微调时遗忘，实现两个空间的有效融合

- 在2个公共和4个工业规模数据集上验证有效性，显著提升推荐的地理可达性与准确性



> 💡 该论文首次系统性地将真实世界空间感知注入生成式POI推荐，通过三阶段框架解决了地理信息缺失问题，兼具理论创新与工业实用价值。

> 💡 该论文通过表示与密码协议协同设计，首次在百万级文档规模下实现亚秒级私有检索，是隐私保护向量检索领域的重要进展。
