### 1. ICEGR：面向电商搜索的意图一致端到端生成式检索框架
| 属性 | 内容 |
|------|------|
| **英文标题** | ICEGR: An Intent-Coherent End-to-End Generative Retrieval Framework for E-commerce Search |
| **分类** | 召回与排序 |
| **评分** | 6.9/10 ⭐⭐⭐ |
| **作者** | Jiayi Tuo, Hehan Li, Dongjun Fu et al. |
| **作者单位** | Baidu |
| **arXiv** | [2608.29652](http://arxiv.org/abs/2608.29652v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.29652v1) |

生成式检索（GR）在电商搜索中具有潜力，但现有方法在训练流程中难以保持查询意图一致性。本文提出ICEGR框架，包含三个组件：意图感知的语义ID构建（将查询意图信号融入SID）、合成查询增强的统一监督微调（通过合成查询补充低曝光产品的意图监督）、以及相关性校准的偏好优化（在偏好目标中融合相关性和业务信号）。离线实验显示，ICEGR在Recall@20和NDCG@20上分别提升21.7%和26.6%；在百度电商搜索的A/B测试中，CTR、订单量和GMV分别相对提升3.52%、15.96%和7.53%。


**核心贡献**：

- 提出意图感知的语义ID构建方法，将查询意图信号融入SID，提升SID对搜索意图的编码能力。

- 设计合成查询增强的统一SFT，通过合成查询补充低曝光产品的监督信号，缓解数据稀疏问题。

- 引入相关性校准的偏好优化，平衡业务信号与查询-产品相关性，避免偏好优化偏离意图。

- 离线实验显示Recall@20提升21.7%，NDCG@20提升26.6%；在线A/B测试中CTR提升3.52%，订单量提升15.96%，GMV提升7.53%。



> 💡 该论文提出了一种端到端生成式检索框架，通过意图一致性的训练流程显著提升电商搜索的检索效果和业务指标，值得阅读以了解生成式检索在电商场景的落地实践。

### 2. RePair：将检索失败转化为反事实困难样本对
| 属性 | 内容 |
|------|------|
| **英文标题** | RePair: Turning Retrieval Failures into Counterfactual Hard Pairs |
| **分类** | 召回与排序 |
| **评分** | 6.9/10 ⭐⭐⭐ |
| **作者** | Siyi Liu, Xiaorong Zhu, Enjun Du et al. |
| **作者单位** | — |
| **arXiv** | [2608.29604](http://arxiv.org/abs/2608.29604v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.29604v1) |

针对CLIP式双编码器在视觉-语言检索中因局部语义差异导致的检索失败问题，本文提出RePair方法。该方法利用排名靠前的假阳性作为反事实支架，通过LLM引导的最小编辑修正失败残差，生成与真实匹配共享语义的困难正样本，并与未编辑版本构成跨越决策边界的困难负样本对，实现互补的推-拉监督。RePair遵循有效性、最小性和局部性三原则，在Flickr30K和COCO30K上仅用10.7万合成样本即超越对照增强基线，样本效率提升26%-75%。


**核心贡献**：

- 提出反事实困难样本对生成框架，将检索失败转化为训练信号，无需额外标注。

- LLM引导的最小编辑确保样本有效性和局部性，相比无条件增强更贴近决策边界。

- 在Flickr30K和COCO30K上，仅用10.7万合成样本实现SOTA，样本量减少26%-75%。



> 💡 该论文通过反事实编辑将检索失败转化为高效训练信号，为困难样本挖掘提供了新范式，值得推荐系统研究者借鉴。

### 5. TAAL：通过时间自回归对齐缓解生成式推荐中的早期束剪枝问题
| 属性 | 内容 |
|------|------|
| **英文标题** | TAAL: Mitigating Early Beam Pruning in Generative Recommendation via Temporal Autoregressive Alignment |
| **分类** | 序列推荐 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Lianjie Li, Zhiying Tu, Dianhui Chu et al. |
| **作者单位** | — |
| **arXiv** | [2608.29179](http://arxiv.org/abs/2608.29179v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.29179v1) |

生成式推荐将物品编码为层次化语义标识符（SIDs），并通过自回归解码检索下一物品。标准的下一个词预测未显式建模交互序列中的多模态转移，导致真实SID在早期束搜索分支中被不可逆剪枝。本文提出时间自回归对齐（TAAL）：训练时，利用历史转移构建联合(c1,c2)软目标，并通过前向KL散度对齐早期前缀分布；推理时，使用点互信息（PMI）校准候选分数，降低全局高频前缀的影响。在Amazon Beauty、Instruments和Yelp上，TAAL相比标准基线将NDCG@10分别提升39.5%、6.7%和28.6%，完整SID存活率提升3.9%–16.6%。束宽分析显示，束越窄相对存活增益越大，在B=5时达39.4%。


**核心贡献**：

- 首次系统分析生成式推荐中早期束剪枝问题，发现91.9%–96.6%的检索失败发生在前两个解码步骤。

- 提出TAAL方法，通过联合软目标和前向KL对齐训练，结合PMI推理校准，显著提升检索性能。

- 在三个公开基准上，NDCG@10提升6.7%–39.5%，完整SID存活率提升3.9%–16.6%。

- 束宽分析表明，束越窄相对存活增益越大，B=5时增益达39.4%，验证方法在严格约束下的有效性。



> 💡 该论文精准定位并解决了生成式推荐中的关键瓶颈（早期束剪枝），提出的TAAL方法简单有效，实验充分，对提升生成式推荐性能具有重要参考价值。

- 提出可复用的诊断协议，帮助实践者在部署前检测边谱问题，避免无效修复。



> 💡 本文通过揭示选择衍生图中的边谱现象，为协同过滤中的图构建提供了重要的诊断视角，值得图推荐研究者阅读。

### 10. 组织规则为何使AI失效：O-I-B-A-R与决策边界的外化
| 属性 | 内容 |
|------|------|
| **英文标题** | Why Organizational Rules Fail AI: O-I-B-A-R and the Externalization of Decision Boundaries |
| **分类** | 可解释性 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Chao Li, Chunyi Zhao |
| **作者单位** | — |
| **arXiv** | [2608.29055](http://arxiv.org/abs/2608.29055v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.29055v1) |

本文指出组织AI失败常源于社会技术接口处的知识表示问题：AI仅接收正式程序，而组织实际运作依赖程序之外的负边界、运行时判断、责任分配与学习历史。作者提出O-I-B-A-R框架（OPEN、IS、BUT、ACTION、RESULT），用于外化缺失的决策边界。IS记录判断成立的条件，BUT记录超越逻辑否定的具体失败案例，通过分解成功与失败案例提取最小充分变化变量作为价值决策维度，悬置状态明确需测量、询问或升级至人类的事项，RESULT确认边界、调整阈值或暴露新维度。文章还识别了社会技术张力：持久且可归因的失败历史可能抑制坦诚，因此外化需设计为有成本与激励的组织干预。


**核心贡献**：
