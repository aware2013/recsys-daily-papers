### 1. 廉价验证器，巨大盲区：衡量降本级联的可靠性代价
| 属性 | 内容 |
|------|------|
| **英文标题** | Cheap Verifiers, Large Blind Spots: Measuring the Reliability Cost of Cost-Saving Cascades |
| **分类** | 大模型推荐 |
| **评分** | 7.3/10 ⭐⭐⭐ |
| **作者** | Dushyant Rajput |
| **作者单位** | — |
| **arXiv** | [2609.01345](http://arxiv.org/abs/2609.01345v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.01345v1) |

推理级联通过廉价模型处理多数查询，仅将困难样本升级至前沿模型验证，以降低成本。闭环扩展为在验证器拒绝的样本上微调学生模型，逐轮降低升级率。在真实LLM上实验发现：验证器盲区（接受错误答案的比例）随学生能力增强而增大（0.5B至32B时β从0.12升至0.55），随验证器能力增强而减小；前沿验证器可将β降至0.05，但需升级46%的困难查询，成本高昂；朴素纠正微调导致学生模型性能下降甚至崩溃；级联内部指标始终显示3%错误率，而真实错误率高达32%，系统对自身退化盲目。理论推导出双总体守恒律ε∞≲q0β0，解释盲区机制。结论：自改进级联的可靠性无法通过自身验证器计算的任何指标评估。


**核心贡献**：

- 验证器盲区随学生能力增强而扩大（β从0.12升至0.55），随验证器能力增强而缩小，在廉价级联中最为严重。

- 前沿验证器可将盲区降至0.05，但需升级46%的困难查询，成本接近全量使用前沿模型。

- 朴素纠正微调导致学生模型性能下降甚至崩溃，跨教师家族均如此，自改进循环自我挫败。

- 级联内部指标恒定显示3%错误率，而真实错误率高达32%，系统对自身退化完全盲目。



> 💡 该论文揭示了级联推理系统中验证器盲区导致的可靠性陷阱，对设计可信赖的AI系统具有重要警示意义。

### 3. 故障定位是否优于全新尝试？测试引导代码修复的安慰剂对照研究
| 属性 | 内容 |
|------|------|
| **英文标题** | Does Fault Localization Beat a Fresh Attempt? A Placebo-Controlled Study of Test-Guided Code Repair |
| **分类** | 召回与排序 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Anik Jha |
| **作者单位** | — |
| **arXiv** | [2609.00854](http://arxiv.org/abs/2609.00854v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.00854v1) |

本研究通过三臂对照实验，分离故障定位在代码修复中的真实效果与混淆因素。实验覆盖三个冻结的26-32B模型、三个基准和488个失败候选，另加第三个家族的24B模型。结果显示：仅9.0%的失败候选具有可用频谱；在177个可定位候选中，定位修复在匹配尝试次数下以3:40惨败于盲重采样（p=3.0e-9），且该损失在第三家族中复现（-11.3点）；与随机跨度安慰剂相比，定位修复总体领先（11:1，调整后p=0.019），但未在单个模型中达到预设显著性，故定位效应仅为提示性。按token重定价后，定位尝试虽仅耗21.7个token，但16次定位尝试成功率6.8%，低于单次盲尝试的10.1%。结论限于24-32B模型。


**核心贡献**：

- 通过安慰剂对照设计，首次严格分离故障定位的因果效应与尝试次数、编辑大小等混淆因素，发现定位修复在匹配尝试次数下显著劣于盲重采样（3:40，p=3.0e-9）。

- 揭示故障定位可用性极低：仅9.0%的失败候选具有可用频谱，限制了其实际应用价值。

- 发现定位修复的领先主要源于编辑长度而非定位信息，且定位信息的效果在预设分析中未达显著（最佳Holm p=0.087），仅为提示性。

- 量化了token成本差异：定位尝试平均21.7 token vs 盲尝试371.1 token，但16次定位尝试成功率6.8%仍低于单次盲尝试的10.1%，证明预算增加无法弥补定位劣势。



> 💡 该研究以严谨的安慰剂对照实验颠覆了故障定位提升代码修复的直觉，为测试引导修复的评估与设计提供了关键方法论借鉴。

### 5. 自由生成，谨慎行动：递归LLM智能体树的渐进风险归属

| **分类** | 强化学习推荐 |
| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Molly Wang |

| **arXiv** | [2609.01035](http://arxiv.org/abs/2609.01035v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.01035v1) |

本文针对递归LLM智能体在生成子专家并请求工具（如发送数据或部署代码）时的风险控制问题，提出渐进风险归属（PRV）机制。该机制在托管账户中持有轨迹级风险预算，并在分支激活时扣减，同时证明了对自适应生成树的任意时间危害界。理论分析表明，当局部风险趋近零时，轨迹危害在临界状态（权威再生数R_A=1）下与p的平方根成正比，低于临界时与p成正比，高于临界时保持正下限。通过分支计算和分裂样本实验验证了结果，并提出了“在沙盒中广泛搜索，谨慎授予递归权限”的设计原则。


**核心贡献**：

- 提出PRV机制，通过轨迹级风险预算和延迟归属，在保持策略空间的同时实现风险控制，并证明任意时间危害界。

- 揭示权威再生数R_A对轨迹危害的临界效应：低于临界时危害与p成正比，临界时与√p成正比，高于临界时存在正下限。

- 在有限类型占用模型中推导出风险与计算影子价格，并证明在边际价值递减的嵌套扇出模式下产生阈值规则。

> 💡 该论文为递归LLM智能体的风险控制提供了严谨的理论框架和可操作的设计原则，对构建安全的自主智能体系统具有重要参考价值。
