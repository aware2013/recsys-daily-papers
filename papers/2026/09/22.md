### 3. 从提示到推荐：AI搜索中品牌可见度的拟合阶段模型
| 属性 | 内容 |
|------|------|
| **英文标题** | From Prompt to Recommendation: A Fitted Stage Model of Brand Visibility in AI Search |
| **分类** | 大模型推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Benjamin Tannenbaum |
| **作者单位** | — |
| **arXiv** | [2609.23162](http://arxiv.org/abs/2609.23162v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.23162v1) |

本文基于75个Aiso项目、34,960条无品牌提示-引擎观测数据（2026年6-9月，覆盖2,854个提示及GPT与Gemini重复运行），分析AI搜索中品牌提及率的影响因素。研究发现：当目标品牌及其域名均未出现在可观测检索路径中时，GPT与Gemini的提及率仅为2.8%和3.8%；仅出现自有域名引用时升至49.0%和58.4%；当自有域名曝光与品牌化fan-out同时出现时，提及率高达91.4%和100%。作者构建了融合历史运行记录与同期检索指标的时序诊断模型，在最新30%留出集上GPT和Gemini的AUC分别达0.963和0.942，优于仅用历史（0.937/0.917）或仅用实时信号（0.880/0.840）。


**核心贡献**：

- 揭示AI搜索中品牌可见度的两阶段机制：自有域名曝光与品牌化fan-out共同将提及率从约3%提升至91.4%（GPT）和100%（Gemini）

- 构建时序诊断模型融合历史与实时检索信号，在留出集上GPT AUC达0.963、Gemini达0.942，显著优于单一信号来源

- 发现提示-页面匹配对Gemini曝光预测（AUC 0.641）明显强于GPT（0.545），表明相关性处于引擎中介曝光效应的上游

- 在相同项目、提示和引擎的重复运行中验证效应稳健性：自有域名曝光带来GPT +40.2pp、Gemini +49.0pp的提及率提升



> 💡 该文首次系统量化了AI搜索引擎中品牌可见度的关键驱动因素，并提供了可预测品牌提及的实用诊断模型，对理解LLM时代品牌营销新范式具有重要参考价值。

### 4. MM-ContextFold：面向多模态智能体检索的上下文折叠方法

| **分类** | 大模型推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Yang Tian, Fan Liu, Jingyuan Zhang et al. |
| **作者单位** | — |
| **arXiv** | [2609.23121](http://arxiv.org/abs/2609.23121v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.23121v1) |

针对多模态智能体检索中原始图像与交互历史不断累积导致的上下文爆炸问题，本文通过约1万条轨迹的实证研究发现，随着视觉线索被工具提取并文本化，原始图像逐渐冗余，持续保留图像会提高输出熵并降低任务准确率。据此提出免训练框架MM-ContextFold：主上下文仅保留文本用于高层规划，按需为图像相关子任务创建临时分支上下文，加载图像完成子任务后将结果折叠为简洁文本摘要回写主上下文并丢弃图像与分支轨迹。在7个基准、5个骨干模型上平均准确率较ReAct提升6.3个百分点，工作上下文长度减少27.5%。


**核心贡献**：

- 通过约10,000条轨迹的实证研究揭示原始图像在多模态智能体检索中随文本化推进而逐渐冗余，持续保留会提高输出熵并损害准确率。

- 提出免训练的MM-ContextFold框架，以文本主上下文加临时图像分支上下文的折叠机制管理多模态上下文。

- 在7个MAR基准、5个骨干模型上平均准确率较ReAct提升6.3个百分点，同时工作上下文长度减少27.5%。



> 💡 该文以扎实的实证分析揭示多模态智能体检索中图像冗余规律，并给出免训练、即插即用的上下文折叠方案，对构建高效多模态检索与推荐智能体具有直接参考价值。

### 5. R-GEAN：基于用药方案的编辑动作网络用于住院期间用药变更预测

| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Regan Mahat, Mansu Kim |
| **作者单位** | — |
| **arXiv** | [2609.22959](http://arxiv.org/abs/2609.22959v1) |

本文研究住院期间用药类别的增减预测问题，指出现有基于完整出院用药方案的评估指标会因大量未变更药物而被虚高。为此提出泄漏控制的基准，仅用既往住院记录和入院24小时内信息预测ATC3类别的净增删，并设计R-GEAN非对称候选打分网络，分别建模新增与移除预测器。在82,286名患者的240,480次住院数据上，R-GEAN取得最高编辑综合分0.464，优于最强基线0.435，重实现的RETAIN、GAMENet、MICRON分别为0.428、0.420、0.288。优势主要来自正确识别出院时已停用的药物类别，而罕见新增与多次变更场景仍具挑战。


**核心贡献**：

- 揭示完整出院方案微F1与编辑综合分排序仅弱相关（Spearman r=0.20），延续基线在完整方案指标最高却未预测任何变更

- 重实现RETAIN、GAMENet、MICRON分别得0.428、0.420、0.288，验证方法在移除识别上的集中优势



> 💡 该文重新定义了住院用药变更预测的评估方式，并给出有效的非对称建模方案，对医疗推荐与序列决策研究具有方法论启发。

### 6. 算法合谋与无信息价值均衡的计算复杂性

| **分类** | 公平性与去偏 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Ioannis Anagnostides, Weiqiang Zheng |
| **作者单位** | — |
| **arXiv** | [2609.22757](http://arxiv.org/abs/2609.22757v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.22757v1) |

本文研究无信息价值相关均衡（IVFCE）与无信息价值粗相关均衡（IVFCCE）在简洁博弈中的计算复杂性，动机是算法合谋的监管问题。作者证明：在多玩家多矩阵博弈或双玩家贝叶斯博弈中，即使常数近似，计算IVFCE也是PPAD完全的，并给出无条件指数查询下界，从而排除了高效学习动态的存在。对于IVFCCE，无遗憾算法（如regret matching、FTRL）给出FPTAS；当近似精度指数小时，问题属于CLS，但至少与P-矩阵线性互补问题及简单随机博弈一样难。


**核心贡献**：

- 证明在多玩家多矩阵博弈和双玩家贝叶斯博弈中，即使常数近似，计算无信息价值相关均衡（IVFCE）也是PPAD完全的，并给出无条件指数查询下界。

- 证明无遗憾算法（如regret matching、FTRL）为无信息价值粗相关均衡（IVFCCE）提供FPTAS，且指数小近似下问题属于CLS = PPAD ∩ PLS。

- 证明IVFCCE至少与P-矩阵线性互补问题及简单随机博弈一样难，表明其不太可能存在多项式时间算法。

- 强化了Hartline、Wang和Zhang关于算法合谋监管的不可能性结果，从特定学习算法扩展到所有高效学习动态。



> 💡 本文从计算复杂性角度严格论证了算法合谋监管中无信息价值均衡的不可处理性，为平台算法治理提供了重要的理论边界。

### 8. 安全的代价：LLM智能体记忆投毒防御在良性场景下的效用损失与Token开销
| 属性 | 内容 |
|------|------|
| **英文标题** | The Price of Safety: Benign-Case Utility and Token Overhead of Memory-Poisoning Defenses in LLM Agents |
| **分类** | 大模型推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Pritom Bhowmik |
| **作者单位** | — |
| **arXiv** | [2609.22818](http://arxiv.org/abs/2609.22818v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.22818v1) |

该研究构建了控制记忆后端、检索流程与评判器一致性的测量框架，在纯良性流量下评估三类写入时防御（输入净化、来源验证、LLM异常检测）与一种读取时防御（重排序）。每种条件在5组对话上重复3次以区分真实效应与流水线噪声。结果显示写入时防御的效用损失置信区间约±4.5分且包含零，无法分辨出代价；而重排序防御使核心准确率下降4.4分（95% CI [-9.0,-0.05]），并在33.6%的裁决项上误隔离合法记忆，单次对话最多达106次误隔离，Token开销为2.7%。叠加全部四种防御并未加剧损失，表明写入时防御可能部分抵消重排序的丢弃。防御在流水线中的拦截位置而非是否使用LLM，决定了其良性场景代价。


**核心贡献**：

- 提出控制记忆后端、检索与评判器一致性的测量框架，在纯良性流量下量化四类记忆投毒防御的真实效用代价与Token开销。

- 写入时防御（输入净化、来源验证、LLM异常检测）未检测到可分辨的效用损失，95%置信区间约±4.5分且包含零。

- 读取时重排序防御使核心准确率下降4.4分（95% CI [-9.0,-0.05]），在33.6%的裁决项上误隔离合法记忆，单次对话最多106次误隔离，Token开销2.7%。

- 叠加全部四种防御未产生复合代价，组合条件准确率损失更小且置信区间包含零，表明写入时防御可部分抵消重排序的负面影响。



> 💡 该研究首次系统量化了LLM智能体记忆投毒防御在良性流量下的真实效用代价，揭示了防御拦截位置比是否使用LLM更决定其代价，为安全与效用的权衡提供了可复现的测量基准。

### 9. 成对排序优于单动作强化学习用于离线解释选择：一个实践教训
| 属性 | 内容 |
|------|------|
| **英文标题** | Pairwise Ranking Outperforms Single-Action RL for Offline Explanation Selection: A Practical Lesson |
| **分类** | 可解释性 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Tanay Chowdhury, Saeideh Shahrokh Esfahani |
| **作者单位** | — |
| **arXiv** | [2608.18531](http://arxiv.org/abs/2608.18531v2) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.18531v2) |

该研究将LLM解释生成与选择解耦：预先用六种提示风格和两个商用LLM构建冻结候选池，请求时由小型CPU选择器在100ms内挑选解释，无需GPU。在2,958对XRec Google Local子集上比较LambdaRank、PPO、GRPO、DPO、蒸馏及三种KG路径选择器，并以MovieLens-1M作跨数据集验证。LambdaRank取得F1=0.500，超过G-Refer和XRec，种子方差低于0.003；成对排序优于仅用单候选标签的单动作RL。KG路径选择器USR达1.000，避免模板坍缩。生成器更换仅引起0.001-0.006的F1波动，端到端构建成本约15美元。


**核心贡献**：
