### 1. 注意力索引模型的高维学习动力学
| 属性 | 内容 |
|------|------|
| **英文标题** | High-Dimensional Learning Dynamics of Attention-Indexed Models |
| **分类** | 大模型推荐 |
| **评分** | 7.0/10 ⭐⭐⭐ |
| **作者** | Yizhou Xu, Margarita Sagitova, Lenka Zdeborová et al. |
| **作者单位** | — |
| **arXiv** | [2609.03858](http://arxiv.org/abs/2609.03858v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.03858v1) |

本文研究注意力机制在多层多头的注意力索引模型中的训练动力学。在高维极限下，群体损失景观由有限个迹序参数刻画，而在线SGD由无限矩阵矩层级控制，并可用有限截断系统指数级逼近。研究发现注意力参数化本身具有隐式偏置：直接优化注意力矩阵S易陷入无信息状态；绑定注意力(S=WW^T)自动诱导对称破缺，在Θ(d²log d)样本下实现弱恢复；非绑定注意力(S=UV^T)呈现快慢机制，快动力学选态决定弱恢复。


**核心贡献**：

- 首次在高维极限下刻画注意力索引模型的损失景观，由有限迹序参数完整描述

- 证明在线SGD的无限矩层级可被有限截断系统指数级逼近，简化理论分析

- 揭示绑定注意力(S=WW^T)的自动对称破缺机制，实现Θ(d²log d)样本下的弱恢复

- 发现非绑定注意力(S=UV^T)的快慢动力学，快变量选态决定恢复性能



> 💡 该论文为理解注意力机制的训练动力学提供了严谨的理论框架，揭示了参数化对隐式偏置的影响，对设计高效注意力架构具有重要指导意义。

### 5. 从松弛可索引性到精确可索引性：部分可观测游荡多臂老虎机的t步方法
| 属性 | 内容 |
|------|------|
| **英文标题** | From Relaxed Indexability to Exact Indexability: A $t$-Step Approach for Partially Observable Restless Bandits |
| **分类** | 强化学习推荐 |
| **评分** | 6.4/10 ⭐⭐⭐ |
| **作者** | Qizhen Jia, Keqin Liu |
| **作者单位** | — |
| **arXiv** | [2608.24167](http://arxiv.org/abs/2608.24167v2) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.24167v2) |

本文针对部分可观测游荡多臂老虎机（Restless Bandits）中Whittle指数难以精确计算的问题，提出一种t步前瞻阈值策略。该方法通过t步有限时域值迭代定义活动-被动优势阈值，t=1时恢复Liu的线性阈值，t>1时阈值依赖补贴并更贴近精确决策边界。算法无需预先假设可索引性，并包含可索引性验证。理论证明在原始Whittle可索引性下，t步近似指数以几何速率收敛到精确值（误差O(β^t)）。数值实验验证了2715个三状态实例均可索引，P95指数误差从t=1的2.18e-2降至t=8的8.93e-4，t=2即可恢复精确排序，性能接近最优动态规划基准。


**核心贡献**：

- 提出t步前瞻阈值策略，将Whittle指数近似从单步扩展到多步，显著提升精度（P95误差从2.18e-2降至8.93e-4）

- 证明t步近似指数以O(β^t)几何收敛到精确Whittle指数，提供理论保证

- 算法内置可索引性验证，2715个实例全部通过，无需预设可索引性

- t=2即可在β=0.9999时恢复精确指数排序，且性能接近最优动态规划



> 💡 该文通过多步前瞻阈值策略显著提升部分可观测游荡老虎机中Whittle指数的近似精度，兼具理论收敛保证和实证效果，值得关注。

| **英文标题** | GRASP: Graph-Retrieval Automated Scoring Pipeline for Label-Free Multi-Topic Essay Grading |
| **分类** | 大模型推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Aafreen Husain, Samar Shailendra, Saad Sajid Hashmi |
| **作者单位** | — |
| **arXiv** | [2609.03857](http://arxiv.org/abs/2609.03857v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.03857v1) |

本文提出GRASP流水线，用于自动评阅无标签多主题科学考试短文。该方法将各题参考答案经Sentence-BERT编码为FAISS向量索引，并构建语义相似度图。评分时先用句子计数启发式结合大语言模型预测短文涵盖的主题数，再通过基于余弦相似度的RAG和图增强检索GRAG（从种子节点沿强边遍历）获取候选参考节点，最后用匈牙利算法将参考节点最优分配给各主题段落，并独立使用GPT-4.1-mini评分。实验验证了检索质量对评分准确性的影响，并展示了图增强检索在不同短文复杂度下优于纯余弦相似度方法。


**核心贡献**：

- 提出首个针对无标签多主题短文的自动评分流水线，无需训练数据或领域示例

- 设计GRAG图检索机制，通过图遍历补充RAG遗漏的参考节点，提升检索覆盖率

- 采用匈牙利算法实现参考节点与主题段落的最优匹配，避免重复分配

- 实验证明图增强检索在不同短文复杂度下均优于纯余弦相似度检索，提升评分准确性



> 💡 该论文将图检索与大语言模型结合，解决了多主题无标签短文自动评分的难题，对教育测评场景具有重要参考价值。

- 设计基于段落的溯因召回模块，利用LLM从段落推断可回答查询，提升低相似度但可回答段落的召回率。

- 在TopiOCQA、QReCC和TREC CAsT上，CLEAR一致提升顶部排序精度，尤其在主题噪声大的对话中增益最大。

- 将重排序器应用于LLM驱动的查询改写器之上，可进一步获得性能提升。



> 💡 该论文提出了一种新颖的蕴含蒸馏框架，有效解决了对话检索中主题相关性与可回答性错配的问题，值得阅读以借鉴其将LLM能力迁移至检索排序的思路。

### 10. ViSAR：面向视觉文档问答的无训练自适应-k检索方法
| 属性 | 内容 |
|------|------|
| **英文标题** | ViSAR: Training-Free Adaptive-$k$ Retrieval for Visual Document Question Answering |
| **分类** | 召回与排序 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Adrien Mialland, Marc Plantevit, Julien Gallois et al. |
| **作者单位** | — |
| **arXiv** | [2609.02486](http://arxiv.org/abs/2609.02486v2) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.02486v2) |

文档视觉问答（DocVQA）常借助检索增强生成（RAG），使用晚期交互编码器检索相关页面，再由大型视觉语言模型（LVLM）生成答案。现有方法固定检索k个页面，忽略查询复杂度，导致延迟增加和精度下降。本文提出ViSAR，一种无训练的自适应-k检索方法，直接在嵌入空间构建查询条件页面级相似度矩阵，突出查询相关语义并动态决定检索页面数。在多种编码器和LVLM上，ViSAR检索紧凑页面集，降低RAG延迟最高58.7%，同时保持或提升答案准确率。此外，相似度矩阵结构与准确率相关，为检索质量感知的文档理解提供方向。
