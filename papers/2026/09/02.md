### 3. SetMIR：将多兴趣检索视为集合预测问题
| 属性 | 内容 |
|------|------|
| **英文标题** | SetMIR: Multi-Interest Retrieval as Set Prediction |
| **分类** | 召回与排序 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Xiaodong Liu, Congfei Zhang, Hsiang-wei Chao et al. |
| **作者单位** | Snap Inc. |
| **arXiv** | [2608.30251](http://arxiv.org/abs/2608.30251v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.30251v1) |

SetMIR将多兴趣检索建模为集合预测任务，使用Transformer编码用户行为序列，并通过K个可学习查询解码出用户兴趣集合，每个兴趣对应一个检索嵌入和存在分数。训练时采用匈牙利匹配实现查询与目标的一一对应，避免兴趣坍缩，并学习存在头以判断查询是否激活。服务时结合存在分数和查询级非极大值抑制（NMS），仅发起活跃且不冗余的ANN查询。在Snap动态产品广告（DPA）数据上，SetMIR在所有指标上优于四种多兴趣检索方法，且每次请求的ANN查询数减少33%。部署后，整体CVR提升3.1%，相比item-to-item检索源，CTR提升44%，CVR提升51%。


**核心贡献**：

- 提出将多兴趣检索视为集合预测问题，通过匈牙利匹配和存在分数解决兴趣坍缩与静态调度问题。

- 在Snap DPA数据上，SetMIR在全部指标上优于四种基线，且查询数减少33%。

- 生产部署后，整体CVR提升3.1%，相比item-to-item检索源，CTR提升44%，CVR提升51%。



> 💡 该论文通过集合预测范式统一了多兴趣建模与动态检索调度，兼具理论创新和显著工业收益，值得推荐系统从业者精读。

### 4. 面向大规模电商的时序感知复购预测：多界面杂货推荐中的生存模型
| 属性 | 内容 |
|------|------|
| **英文标题** | Timing-Aware Repurchase Prediction for Web-Scale E-Commerce: Survival Models for Multi-Surface Grocery Recommendation |
| **分类** | 召回与排序 |
| **评分** | 6.7/10 ⭐⭐⭐ |
| **作者** | Akshay Kekuda, Shreeranjani Srirangamsridharan, Ishan Bhatt et al. |
| **作者单位** | — |
| **arXiv** | [2608.28393](http://arxiv.org/abs/2608.28393v2) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.28393v2) |

本文针对电商复购预测中需为每个时间窗口单独训练模型的问题，提出使用生存模型直接预测复购时间。基于大型杂货电商平台数百万用户和三十余种消融配置，发现边际风险呈轻微递减（k≈0.9），Log-Normal拟合最优（R²=0.998），而Weibull条件残差拟合最佳。单一AFT模型可替代三个分窗口二分类器，树数量减少约3倍，且特征重要性发生重构。四参数校准将生存CDF映射为各窗口概率，无跨窗口单调性违规，Exponential AFT的ECE约1e-4，比Log-Normal低10倍，但排序性能相近，揭示了校准与排序的权衡。


**核心贡献**：

- 首次在大型电商平台实证分析复购风险函数，发现边际风险递减（k≈0.9），颠覆了常见直觉。

- 单一AFT模型替代三个分窗口二分类器，性能相当或更优，且树数量减少约3倍。

- 提出四参数参数化校准方法，实现零跨窗口单调性违规，Exponential AFT的ECE低至1e-4，比Log-Normal低约10倍。

- 揭示AFT族内校准与排序的权衡，为不同业务场景选择模型提供原则性指导。



> 💡 该论文用生存模型统一了多时间窗口的复购预测，兼具理论洞见和工程实用性，是推荐系统时序建模的重要进展。

本文研究点式文档重排序中思维链（CoT）模型性能低于直接评分模型的现象。实验表明，该差距在高达32B参数的规模下稳定存在，排除了模型和数据容量干扰。通过强化学习、细粒度监督和架构解耦等压力测试修复分类、极化和校准偏差后，尽管分类准确率和绝对分数提升，相对排序差距仍持续存在。结论指出，在点式评分范式下，将连续相关性语义通过离散文本路由会限制排序信号分辨率，这是一个稳定且难以通过标准训练方法克服的瓶颈，而非简单的训练偏差。


**核心贡献**：

- 首次系统验证CoT在点式重排序中的性能差距在32B参数规模下稳定存在，排除容量混淆因素

- 通过强化学习、细粒度监督和架构解耦等干预，虽改善分类和绝对分数，但相对排序差距无法消除

- 揭示离散文本生成对连续相关性语义的固有约束，为理解CoT在排序任务中的局限性提供新视角



> 💡 该论文通过严谨实验揭示思维链在点式重排序中的固有瓶颈，对设计高效排序模型具有重要指导意义。

- HF-SID仅需3-token SID，不增加解码成本，在大规模工业数据集上验证了其有效性。



> 💡 本文针对LBS场景下生成式检索的语义ID信息丢失问题，提出了一种高保真表示方法，显著提升了检索精度，值得关注。

### 10. Hi-Q：面向多跳问答的层级证据引导查询精化
| 属性 | 内容 |
|------|------|
| **英文标题** | Hi-Q: Hierarchical Evidence-guided Query Refinement for Multi-Hop Question Answering |
| **分类** | 召回与排序 |
| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Jueun Kim, Sungho Park, Wook-Shin Han |
| **作者单位** | — |
| **arXiv** | [2608.30468](http://arxiv.org/abs/2608.30468v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2608.30468v1) |

多跳问答中，问题表达粒度与语料证据检索粒度常不匹配。现有方法依赖固定图结构或程序执行，未显式判断查询单元是否已被证据支持。本文提出Hi-Q，一种证据条件化的层级查询精化框架：每个查询节点通过解析算子检验证据支持性，已支持节点终止，未支持节点由依赖保持的二元算子展开，并由语义覆盖验证器检查。查询树拓扑由语料支持信号决定，而非固定模板。在三个多跳问答基准上，全语料检索下平均EM 52.3、F1 64.0，较IRCoT提升15.1 EM/18.2 F1，较PropRAG在MuSiQue-full上提升11.5 EM/12.0 F1，且无需构建全语料图。受限设置下亦达最优，平均EM 57.9、F1 69.3。


**核心贡献**：

- 提出证据条件化的层级查询精化框架，查询树拓扑由语料支持信号动态决定，无需固定分解模板或预建图结构。

- 在全语料检索下，三个基准平均EM 52.3、F1 64.0，较IRCoT提升15.1 EM/18.2 F1，较PropRAG在MuSiQue-full上提升11.5 EM/12.0 F1。

- 在受限支持/干扰设置下，平均EM 57.9、F1 69.3，较PropRAG提升5.6 EM/3.9 F1，较IRCoT提升13.7 EM/15.8 F1。
