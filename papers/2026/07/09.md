### 2. 驾驭效应：编排设计如何决定企业代理型AI的代币经济学
| 属性 | 内容 |
|------|------|
| **英文标题** | The Harness Effect: How Orchestration Design Sets the Token Economics of Enterprise Agentic AI |
| **分类** | 大模型推荐 |
| **评分** | 6.7/10 ⭐⭐⭐ |
| **作者** | Muayad Sayed Ali, Aliaksandra Novik, Anji Boddupally et al. |
| **作者单位** | Writer（Writer Agent Harness所属公司） |
| **arXiv** | [2607.06906](http://arxiv.org/abs/2607.06906v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.06906v1) |

本文提出“代币最大化”问题：代理型AI任务中代币消耗增长快于价值增长。通过控制变量实验（22个任务、6个基础模型），仅改变编排层（传统生产循环 vs. Writer Agent Harness），发现编排层可显著降低混合成本41%（$0.21→$0.12）、中位耗时44%（48s→27s）、每任务代币量38%（14.2k→8.8k），且任务完成质量持平（0.78→0.81）。质量提升与模型基线强度高度相关（r=0.99），称为“驾驭杠杆”。每美元质量提升82%，每百万代币完成任务数从54.9升至92.0。编排层对成本的影响超过模型选择本身。


**核心贡献**：

- 提出“驾驭效应”：通过优化编排层（而非模型），在6个模型上平均降低每任务成本41%、耗时44%、代币消耗38%，且质量持平。

- 发现“驾驭杠杆”现象：模型质量提升幅度与其基线能力几乎完美正相关（r=0.99），表明编排设计对强模型增效更显著。

- 每美元质量提升82%，每百万代币完成任务数从54.9增至92.0，编排层对成本的影响超过模型菜单的完整跨度。



> 💡 本文揭示了编排层设计是控制企业AI代币成本的关键杠杆，效果远超模型选择，对实际部署具有直接指导意义。

### 4. 强化学习能否高效发现价格操纵策略？
| 属性 | 内容 |
|------|------|
| **英文标题** | Can Reinforcement Learning Efficiently Discover Price Manipulation? |
| **分类** | 强化学习推荐 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Ioanna-Yvonni Tsaknaki, Andrea Macrì, Fabrizio Lillo |
| **作者单位** | — |
| **arXiv** | [2607.06121](http://arxiv.org/abs/2607.06121v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.06121v1) |

本文研究无模型强化学习（RL）能否比传统基于模型的方法更有效地发现和利用价格操纵机会。在Almgren-Chriss框架下，作者先证明离散时间中存在价格操纵策略，并用全信息下的序列最小二乘二次规划计算最优基准。随后比较两种有限样本学习方法：基于模型的方法（估计冲击参数）和基于深度确定性策略梯度（DDPG）的RL方法。结果表明，在中度波动下，RL无需模型先验即可发现盈利操纵策略，且训练数据有限时仍优于受采样误差影响的模型方法；低波动下模型方法更优，高波动下两者均无效。


**核心贡献**：

- 首次在Almgren-Chriss框架下证明离散时间价格操纵策略的存在性，并给出全信息最优基准。

- RL（DDPG）在中度波动下无需模型先验即可发现操纵策略，且训练数据有限时仍优于正确设定但参数有噪声的模型方法。

- 低波动下模型方法优于RL，高波动下两者均无法识别操纵机会，揭示了RL在复杂控制问题中的有效性及金融部署风险。



> 💡 本文通过严谨实验证明强化学习在中度波动下能比传统模型更高效地发现价格操纵策略，对金融推荐与智能交易系统设计具有重要参考价值。

- 相比多步提示策略，该方法在计算效率与可解释性上取得显著改进，支持用户端可解释工具设计。

### 7. 晚期交互检索模型的理论容量量化与扩展

| **分类** | 召回与排序 |

**核心贡献**：

- 首次从理论上证明MaxSim可精确复制任意非负k-稀疏向量内积，且表示效率优于标准内积。

- 提出Signed MaxSim扩展，使晚期交互模型能精确复制任意实值内积，弥补标准MaxSim的理论局限。

- 在否定查询检索任务中，Signed MaxSim将nDCG@10从0.008提升至0.788（仅否定查询）和从0.597提升至1.000（词汇偏移）。



> 💡 本文为晚期交互检索模型提供了首个理论容量证明，并提出了可处理否定查询的Signed MaxSim扩展，兼具理论深度与实用价值。
