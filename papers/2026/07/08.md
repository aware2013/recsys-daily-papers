| 属性 | 内容 |
|------|------|

| **分类** | 公平性与去偏 |
| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Xavier Lambin, Emil Palikot |
| **作者单位** | — |
| **arXiv** | [2607.05627](http://arxiv.org/abs/2607.05627v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.05627v1) |

本文基于法国大型拼车平台数据发现，新加入的少数族裔司机收入比相似的非少数族裔司机低11.6%，但随着评论积累，收入差距几乎消失。评论积累是驱动力：当铁路罢工外生地提高需求并加速评论积累时，少数族裔新司机获益最大。作者通过乘客选择与司机职业关注模型解释：乘客对少数族裔新司机持有过度悲观的先验预期（实际乘车后评价远高于事前预期），导致少数族裔司机降低初始价格并付出额外努力以快速扭转偏见。反事实分析表明，错误先验成本高昂，而声誉系统严格有利于少数族裔司机。


**核心贡献**：

- 发现新少数族裔司机收入比非少数族裔低11.6%，但评论积累使差距几乎消失。

- 利用铁路罢工外生冲击验证评论积累的因果效应，少数族裔新司机获益最大。

- 构建乘客选择与司机职业关注模型，揭示乘客过度悲观先验导致歧视，声誉系统可缓解。
