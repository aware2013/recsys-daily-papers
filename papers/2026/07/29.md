### 6. 落后驱动不安全发展：一项理想化AI竞赛实验
| 属性 | 内容 |
|------|------|
| **英文标题** | Falling Behind Drives Unsafe Development in an Idealised AI Race Experiment |
| **分类** | 强化学习推荐 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Elias Fernández Domingos, The Anh Han |
| **作者单位** | — |
| **arXiv** | [2607.26034](http://arxiv.org/abs/2607.26034v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.26034v1) |

本研究通过框架化行为实验模拟理想化AI竞赛，考察竞争压力如何影响安全与不安全开发选择。实验中，配对参与者在不确定时间范围内重复选择安全或不安全开发，不安全开发提供更快进度和更高即时收益，但累积私人风险（实验设置最大风险分别为10%、60%、90%）。结果显示，不安全行为更多受对手行为、领先/落后状态等动态战略因素影响，而非风险偏好。引入简化演化模型（含四种策略）复现了实验效应，表明不安全开发源于早期行为惯性、对手行为及落后恐惧，而非仅风险偏好。


**核心贡献**：

- 发现不安全开发决策主要由竞争动态驱动：落后时选择不安全概率显著增加，领先时减少，且对手的不安全选择会诱发自身不安全行为。

- 引入四策略演化模型（始终安全、始终不安全、条件安全、条件反社会安全）复现了实验效应，揭示了竞争动态如何偏好条件性不安全策略。

- 实验表明风险偏好对不安全行为解释力有限，而早期行为惯性（首轮选择预测后续行为）和对手行为是关键影响因素。



> 💡 通过实验与建模揭示AI竞赛中不安全开发主要源于竞争动态而非风险偏好，为政策干预提供新视角。

### 7. 用户提问，平台竞争：代理推荐市场如何形成
| 属性 | 内容 |
|------|------|
| **英文标题** | The User Asks, Platforms Compete: How Agentic Recommendation Markets Take Shape |
| **分类** | 大模型推荐 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Deyao Hong, Kehan Zheng, Qian Li et al. |
| **作者单位** | — |
| **arXiv** | [2607.25253](http://arxiv.org/abs/2607.25253v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.25253v1) |

本文提出一种基于LLM用户代理的新型推荐范式——代理推荐市场，其中用户先表达需求，平台再竞争用户注意力。通过三个产品领域的受控实验发现，用户中心推荐虽扩大了相关物品的参与机会，但平台策略性使用选择性正面解释（占首位73-78%）。当用户代理将平台行为与后续反馈关联时，该比例降至36-41%，用户购买相关物品的概率提升。研究表明，代理推荐需将访问、注意力和问责作为联合机制设计问题。


**核心贡献**：

- 提出代理推荐市场新范式，用户先表达需求，平台竞争注意力，区别于传统平台中心推荐。

- 发现平台策略性使用选择性正面解释占据首位73-78%，引入用户反馈机制后降至36-41%，用户购买概率提升。

- 揭示访问、注意力和问责的联合机制设计是代理推荐的核心挑战。



> 💡 本文开创性地将LLM用户代理引入推荐系统，揭示了平台竞争下的注意力分配机制，对下一代推荐系统设计具有重要启示。
