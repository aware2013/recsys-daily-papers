### 1. FAST：面向时序图神经网络训练中内存I/O、计算与采样的整体优化框架
| 属性 | 内容 |
|------|------|
| **英文标题** | FAST: A Holistic Framework for Optimizing Memory-I/O, Computation, and Sampling in Temporal GNN Training |
| **分类** | 图神经网络 |
| **评分** | 6.7/10 ⭐⭐⭐ |
| **作者** | Yushu Cai, Qingrui Zhu, Lei Liu et al. |
| **作者单位** | — |
| **arXiv** | [2607.05095](http://arxiv.org/abs/2607.05095v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.05095v1) |

本文提出FAST，一个整体加速时序图神经网络（TGNN）端到端训练的框架。针对内存I/O、不规则计算和时序邻居采样三个相互交织的瓶颈，FAST引入SlimCache，通过批内压缩和跨批缓存减少GPU内存限制下的主机-设备数据传输；设计针对稀疏时序子图的线程高效图算子，提升GPU缓存局部性并降低聚合与边softmax延迟；采用拓扑感知采样策略提升CPU缓存局部性。在真实大规模动态图上，FAST相比现有系统平均加速2.1倍（最高4.7倍），且不损失模型精度。


**核心贡献**：

- 提出SlimCache，利用批内压缩和跨批缓存机制，在有限GPU内存下减少主机-设备数据移动，实现最高4.7倍加速。

- 设计线程高效的稀疏时序子图算子，优化GPU缓存局部性，显著降低聚合和边softmax延迟。

- 采用拓扑感知的采样策略，提升CPU缓存局部性，加速时序邻居采样，整体平均加速2.1倍且不牺牲模型精度。



> 💡 本文通过联合优化采样、内存I/O和计算，为大规模时序图神经网络训练提供了首个系统性加速方案，工程价值显著。

### 2. 超越高斯假设的可辨识性：符号世界模型与近无限时间一致性

| **作者** | Seth Dobrin, Łukasz Chmiel |

| **arXiv** | [2606.12471](http://arxiv.org/abs/2606.12471v2) |
| **PDF** | [下载](https://arxiv.org/pdf/2606.12471v2) |

本文指出，Klindt等人证明联合嵌入预测架构（JEPA）仅当世界潜在动态服从高斯平稳过程时才能实现线性可辨识性，这导致非高斯系统中统计世界模型的时间一致性误差随时间单调增长。作者提出物理接地符号架构（PGSA），证明其能在所有物理场景下实现精确线性可辨识性，每步误差仅受数值精度限制，并实现近无限时间一致性。理论证明表明，统计世界模型在非高斯系统中无法达到该性质，而符号化因果生成器是充分必要条件。四个定理已在Lean 4中形式化验证。


**核心贡献**：

- 提出物理接地符号架构（PGSA），证明其在所有非高斯物理系统中实现精确线性可辨识性，突破统计模型的高斯边界限制。

- PGSA的每步误差仅受数值精度约束，实现近无限时间一致性，而统计模型在非高斯系统中无法达到该性质。

- 四个核心定理在Lean 4中形式化验证（零占位符），为符号世界模型提供严格数学基础。



> 💡 本文通过符号化因果建模突破统计世界模型的高斯可辨识性限制，为长期时序推荐与动态系统建模提供了理论完备的新范式。

TREK提出一种两阶段训练框架，解决GRPO在困难提示上因学生策略支持域外缺乏正确解而停滞的问题。第一阶段利用蒸馏（前向KL散度）从外部教师（黑盒/白盒/自上下文）获取验证过的候选解，扩展学生模型的支持域；第二阶段回归标准GRPO精炼。在数学推理上，TREK使用DeepSeek-V4教师将Qwen3-8B在AIME 2025上从36.9提升至40.3，AIME 2024从47.9提升至51.1（avg@16）；在智能体任务上，ALFWorld成功率从75.8提升至82.8，ScienceWorld从12.5提升至26.7。

> 💡 本文提出一种通用且高效的蒸馏-强化两阶段训练方法，显著提升大模型在困难推理和智能体任务上的性能，值得关注其解决探索-利用平衡的实用思路。

### 4. 公共AI信息服务中的策展检索与开放网络搜索：覆盖度与可信度的权衡
| 属性 | 内容 |
|------|------|
| **英文标题** | Curated retrieval versus open web search in public AI information services: a coverage-trust trade-off |
| **分类** | 召回与排序 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Hafsteinn Einarsson, Hafsteinn Birgir Einarsson, Jón Gunnar Ólafsson et al. |
| **作者单位** | University of Iceland |
| **arXiv** | [2607.05217](http://arxiv.org/abs/2607.05217v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.05217v1) |

本文对冰岛大学运营的政府资助AI问答服务Evrópuvefur进行预发布专家评估，比较策展本地语料库（RAG）与开放网络搜索两种检索路径。5位领域专家对449个AI生成答案进行551次评估，发现开放网络搜索中35%的答案（65/187）至少有一个被标记为不可信或不相关的引用来源，而策展来源仅因过时被标记。网络搜索覆盖更多问题但牺牲来源质量，策展语料库可信但覆盖有限。研究还发现流畅性和主题相关性无法预测来源可信度，提示词引导效果微弱（可信域名引用率仅从12%提升至21%）。


**核心贡献**：

- 揭示了公共AI服务中策展检索与开放网络搜索在覆盖度与可信度之间的根本权衡：开放搜索覆盖率高但35%答案包含不可信来源，策展检索可信但覆盖不足。

- 发现流畅性和主题相关性无法预测来源可信度，提示词引导效果微弱（可信域名引用率仅从12%提升至21%），表明来源可信度是独立于表面质量的可测量维度。

- 通过551次专家评估量化了两种检索路径的差异，并指出系统从未引用冰岛最广泛使用的新闻来源RÚV，凸显了检索策略的盲区。



> 💡 本文通过严谨的专家评估实证揭示了公共AI服务中检索策略的覆盖度-可信度权衡，为构建可信赖的AI信息检索系统提供了关键设计洞见。
