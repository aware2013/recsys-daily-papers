### 1. RAGuard：面向检索增强生成系统的分层数据投毒防御框架
| 属性 | 内容 |
|------|------|
| **英文标题** | RAGuard: A Layered Defense Framework for Retrieval-Augmented Generation Systems Against Data Poisoning |
| **分类** | 召回与排序 |
| **评分** | 7.2/10 ⭐⭐⭐ |
| **作者** | Pushkal Kumar, Tucker Nielson, Tanish Kolhe et al. |
| **作者单位** | — |
| **arXiv** | [2607.26339](http://arxiv.org/abs/2607.26339v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.26339v1) |

RAGuard针对RAG系统中的语料库投毒攻击（注入虚假事实、矛盾与推理陷阱）提出双层防御。第一层通过对抗微调密集检索器，使其在生成前降低恶意段落排名；第二层为零知识推理补丁（ZKIP），通过留一法解码比较语义偏移和输出熵变化，无需投毒标签或模型内部信息。在Natural Questions数据集上，5%-30%投毒比例下，ZKIP将攻击成功率降至0.000，Recall@5仅下降0.03。防御开销为每查询k+1次生成（k=5时约6倍），可通过批处理和早停优化。


**核心贡献**：

- 提出对抗微调检索器与零知识推理补丁（ZKIP）的双层防御框架，在5%-30%投毒比例下将攻击成功率降至0.000，同时保持Recall@5与干净基线差距小于0.03。

- ZKIP无需投毒标签、真实答案或模型内部信息，通过留一法解码的语义偏移和熵变化检测恶意文档，具备黑盒可部署性。

- 在Natural Questions和BEIR（NFCorpus）上验证了ZKIP依赖的反事实信号具有可学习的投毒结构，并分析了关键词保留投毒对BM25等词法检索器影响有限。



> 💡 针对RAG系统数据投毒攻击，提出一种无需标签、黑盒可用的高效分层防御方法，在几乎不影响检索质量的前提下彻底消除攻击成功率。

### 2. DenseOn与LateOn：面向多语言、长上下文和代码搜索的完全开放稠密与延迟交互模型
| 属性 | 内容 |
|------|------|
| **英文标题** | DenseOn with the LateOn: Fully Open Dense and Late-Interaction Models for Multilingual, Long-Context, and Code Search |
| **分类** | 召回与排序 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Raphaël Sourty, Antoine Chaffin, Paulo Roberto Moura Junior et al. |
| **作者单位** | — |
| **arXiv** | [2607.27178](http://arxiv.org/abs/2607.27178v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.27178v1) |

本文提出了一套完全开放的检索模型训练方案，并研究了英语监督如何通过翻译-训练迁移到多语言检索。作者从34个公开来源的14亿对比预训练对中重建并筛选出6.65亿对，并构建了188万对带困难负样本的监督微调对。训练得到两个1.49亿参数模型：单向量稠密模型DenseOn和ColBERT风格的延迟交互模型LateOn，在BEIR上分别取得56.20和57.22的平均nDCG@10，创下该参数量级的新纪录。随后将验证后的英语数据翻译为8种语言，得到28亿对跨语言样本，训练出基于mmBERT-base的3.07亿参数mDenseOn和mLateOn。实验发现，稠密模型在英语和翻译语言上表现强，但在翻译-训练支持范围外退化；而延迟交互模型能更好地泛化到未见语言和文字系统，表明token级匹配将翻译-训练从目标语言扩展策略转变为多语言泛化配方。所有模型、数据集和训练代码均已公开。


**核心贡献**：

- 构建了完全开放的大规模检索训练流程，从14亿对中筛选出6.65亿对比预训练对和188万对监督微调对，并公开所有数据与代码。

- DenseOn和LateOn在BEIR上分别达到56.20和57.22平均nDCG@10，创下1.49亿参数量级的新SOTA。

- 发现延迟交互模型（LateOn）通过token级匹配能更好地泛化到未见语言和文字系统，而稠密模型（DenseOn）仅在翻译-训练支持的语言上表现强。



> 💡 该论文提供了完全开放、可复现的多语言检索训练方案，并揭示了稠密与延迟交互模型在跨语言泛化上的本质差异，对工业级多语言搜索系统有重要指导意义。

### 5. 人类多样性驱动集体创造力，大型语言模型无法模拟或维持
| 属性 | 内容 |
|------|------|
| **英文标题** | Human diversity fuels collective creativity that large language models cannot simulate or sustain |
| **分类** | 大模型推荐 |
| **评分** | 5.9/10 ⭐⭐ |
| **作者** | Mengchen Dong, Hiromu Yakura |
| **作者单位** | — |
| **arXiv** | [2607.26899](http://arxiv.org/abs/2607.26899v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2607.26899v1) |

本研究通过预注册的创造性隐喻实验，对比了母语（L1）与非母语（L2）英语写作者在无AI、AI生成创意（AI ideation）及AI优化创意（AI refinement）三种条件下的表现。结果显示：L2写作者贡献了比L1写作者更高的集体多样性，而AI ideation压缩了所有人的集体多样性并消除了L2优势，但AI refinement保留了该优势。进一步使用基于真实背景构建的角色、三种模型家族、母语提示及高采样温度模拟整个写作者群体，所有模拟池的多样性均低于人类池，且过度推动模型仅产生退化文本。个体层面，AI ideation提升了写作者评分，但以牺牲集体利益为代价（L2写作者使用母语时例外）。结论：人类多样性是当前AI无法模拟或维持的宝贵创意资源，人机协作工作流的设计决定了其存续。


**核心贡献**：

- 发现L2写作者比L1写作者贡献更高集体多样性，但AI生成创意（AI ideation）压缩了所有人的多样性并消除L2优势，而AI优化创意（AI refinement）保留了该优势。

- 使用真实背景角色和多种模型模拟写作者群体，所有模拟池的多样性均低于人类池，且过度推动模型仅产生退化文本。

- 个体层面AI ideation提升评分但损害集体利益，仅L2写作者使用母语时实现双赢，揭示人机协作中个体激励与集体利益的矛盾。



> 💡 该研究以严谨实验揭示了AI在创意生成中压缩人类集体多样性的风险，为设计保护多样性的人机协作系统提供了关键实证。

WhisperRec提出一种隐式推理框架，解决显式思维链（CoT）在推荐中推理开销大、模板固定等问题。它通过多视角自适应CoT（MV-ACoT）从互补角度生成高质量推理监督，并自适应调整推理复杂度；基于预训练基础推荐模型（FRM），采用三阶段隐式推理对齐将教师CoT压缩为可学习的隐式推理令牌，实现“隐式推理-回答”范式。在快手工业级数据集和公开基准上，相比显式CoT方法，SID@64提升17.44%，在线推理吞吐量提升10倍以上。


**核心贡献**：

- 提出MV-ACoT机制，从多视角生成自适应推理监督，对简单案例轻量分析、对复杂案例进行多因素推理，提升推理质量与效率。

- 设计三阶段隐式推理对齐流程，将显式CoT压缩为隐式令牌，避免自回归生成瓶颈，相比显式CoT方法SID@64提升17.44%。

- 在工业级快手数据集上实现10倍以上在线推理吞吐量提升，同时保持或超越显式推理方法的推荐效果。



> 💡 将显式推理压缩为隐式令牌，在保持推理质量的同时大幅提升推荐系统推理效率，是基础推荐模型实用化的重要进展。
