### 1. 大语言模型从哪里学会推荐AI？
| 属性 | 内容 |
|------|------|
| **英文标题** | Where Do LLMs Learn to Recommend AI? |
| **分类** | 大模型推荐 |
| **评分** | 6.7/10 ⭐⭐⭐ |
| **作者** | Benaya Trabelsi, Jonathan Shaki, Sarit Kraus |
| **作者单位** | — |
| **arXiv** | [2610.29785](http://arxiv.org/abs/2610.29785v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.29785v1) |

本文探究大语言模型倾向推荐AI相关选项的来源。通过对比预训练与微调模型、变化提问方式发现：预训练模型已有27%的回答含明确AI/ML术语，指令微调版升至59%；但该倾向并非必然——通用指令微调不改变比例，移除7%涉及AI的指令样本可使其下降14个百分点至低于预训练基线；奖励有用性的数据使其上升9个百分点，而按多样模拟用户偏好排序的数据使其下降9个百分点；固定模型时，询问“最佳”选项或“现在”该做什么分别提升8和18个百分点，告知模型其为AI顾问则提升4个百分点。结论：该倾向源于预训练，后续学习与提问措辞共同决定其强度。


**核心贡献**：

- 预训练模型已有27%的回答含明确AI/ML术语，指令微调版升至59%，表明倾向始于预训练阶段。

- 移除仅7%涉及AI的指令样本可使AI推荐率下降14个百分点，甚至低于预训练基线，说明微调数据可显著调控该倾向。

- 奖励有用性的数据使AI推荐率提升9个百分点，而按多样模拟用户偏好排序的数据使其下降9个百分点。

- 固定模型时，询问“最佳”选项或“现在”该做什么分别提升8和18个百分点，告知模型其为AI顾问则提升4个百分点。



> 💡 该文首次系统拆解大模型推荐AI倾向的来源，揭示预训练、微调数据与提问措辞的联合作用，对理解并调控大模型推荐行为具有重要参考价值。

### 3. FairFRESH：面向公平与可解释家庭食物推荐的神经符号框架

| **作者** | Kodur Sai Vinay Sathvik, Kakoli Bora, Tejaswini R. M |

| **arXiv** | [2610.31506](http://arxiv.org/abs/2610.31506v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.31506v1) |

论文将家庭食物推荐建模为受限公平分配问题，提出神经符号框架FairFRESH：学习成员个体效用，在显式福利目标下分配食物，用确定性过滤器执行饮食规则，并用Shapley与Banzhaf归因解释推荐。理论上证明有限惩罚无法保证饮食规则阈值附近的合规性，给出贪心分配在功利与平滑Nash目标下的近似保证，并分析Nash福利的尺度不变性。在NHANES衍生数据上，效用模型Recall@20达0.293，优于五个学习型推荐器（最高0.244）；Nash分配较冲突消解降低Gini差异42%，Recall@20从0.180提升至0.197，距平滑Nash最优上界2%以内，所有推荐满足饮食规则，归因分数与组件移除后效用损失相关（r=0.76）。


**核心贡献**：

- 将家庭食物推荐形式化为受限公平分配问题，提出神经符号框架FairFRESH，统一学习效用、公平分配、规则过滤与可解释归因。

- 在NHANES衍生数据上，Nash分配较冲突消解降低Gini差异42%，同时将Recall@20从0.180提升至0.197，距平滑Nash最优上界2%以内。

- 理论证明有限惩罚无法保证饮食规则阈值附近的合规性，并给出贪心分配在功利与平滑Nash目标下的近似保证。

- 归因分数与组件移除后效用损失高度相关（r=0.76），模拟中共享餐食减少约三分之一食物储备使用，周轮换使最差成员效用提升38%。



> 💡 该论文将公平分配理论与神经符号方法引入家庭食物推荐，在公平性、规则合规与可解释性上均有量化提升，值得关注多用户约束推荐的研究者阅读。

### 6. 在关键处深度思考：面向序列推荐的物品级自适应递归
| 属性 | 内容 |
|------|------|
| **英文标题** | Think Harder Where It Matters: Item-Level Adaptive Recursion for Sequential Recommendation |
| **分类** | 序列推荐 |
| **评分** | 5.3/10 ⭐⭐ |
| **作者** | Zhanshuo Cao, Jiakai Tang, Yuqi Zhou et al. |
| **作者单位** | — |
| **arXiv** | [2610.30128](http://arxiv.org/abs/2610.30128v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.30128v1) |

论文指出现有序列推荐对所有历史物品分配固定计算预算存在两大问题：同一序列内物品计算需求差异巨大，且非均匀深度分配优于固定深度。为此提出LoopRec，通过权重共享块递归计算，并在每个递归边界引入轻量门控，为每个物品独立做出二值退出/继续决策，将固定全局深度转化为可学习的物品级属性，无需深度标签且适配多种骨干架构。在四个骨干家族的公开基准上，LoopRec一致优于匹配的固定深度基线，且学到的分配模式可解释：低频物品和近期交互获得更深计算。


**核心贡献**：

- 诊断发现同一序列内物品计算需求高度非均匀，多数物品浅层即收敛，少数关键物品需全深度才稳定。

- 提出LoopRec，用权重共享递归块加物品级二值门控实现自适应深度，无需辅助深度标签。

- 在四个骨干家族的公开基准上一致超越匹配固定深度基线，且学到的分配模式与oracle分析一致（低频物品与近期交互获更深计算）。



> 💡 该文将序列推荐中的固定深度计算转变为物品级自适应递归，方法简洁、适配性强且实验一致有效，值得关注计算效率与推荐质量平衡的研究者阅读。
