### 1. OneLatent：面向高效基础推荐模型的潜在推理方法
| 属性 | 内容 |
|------|------|
| **英文标题** | OneLatent: Latent Reasoning for Efficient Foundation Recommendation Models |
| **分类** | 大模型推荐 |

| **作者** | Hao Jiang, Peiru Du, Pengfei Yao et al. |
| **作者单位** | Kuaishou Technology |
| **arXiv** | [2610.30675](http://arxiv.org/abs/2610.30675v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.30675v1) |

针对显式思维链（CoT）推理在基础推荐模型中推理开销大、依赖人工模板的问题，提出OneLatent潜在推理框架。该方法首先通过多视角自适应CoT（MV-ACoT）从多角度生成多样化高质量教师监督信号并自适应调整推理复杂度；随后基于预训练FRM采用三阶段潜在token对齐范式，将CoT轨迹逐步内化为可学习潜在token；最后通过多阶段课程式后训练激活潜在token推理能力。在快手工业级数据集与公开LLM-Rec基准上，SID@64较Think与No-Think变体分别提升17.44%和9.33%，在线推理吞吐提升超17倍；快手本地服务广告场景A/B测试实现约9.6%收入增长。


**核心贡献**：

- 提出MV-ACoT多视角自适应思维链，自动生成多样化、复杂度自适应的教师监督信号，替代人工模板。

- 设计三阶段潜在token对齐范式与多阶段课程式后训练，将显式CoT推理压缩为少量可学习潜在token，实现Latent-Reason-then-Answer推理。

- 在快手工业数据集与公开基准上，SID@64较Think/No-Think变体分别提升17.44%/9.33%，在线推理吞吐提升超17倍。

- 构建生产级实时FRM服务系统，快手本地服务广告在线A/B测试实现约9.6%收入提升。



> 💡 该论文将显式CoT推理压缩为潜在token，在大幅降低推理开销的同时显著提升推荐效果，并完成工业级在线验证，对大模型推荐落地具有重要参考价值。

### 3. 融合税：混合检索何时有害的诊断分析
| 属性 | 内容 |
|------|------|
| **英文标题** | The Fusion Tax: A Diagnostic Analysis of When Hybrid Retrieval Hurts |
| **分类** | 召回与排序 |
| **评分** | 7.0/10 ⭐⭐⭐ |
| **作者** | Aaditya Chauhan, Arun Agarwal |
| **作者单位** | — |
| **arXiv** | [2610.30612](http://arxiv.org/abs/2610.30612v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.30612v1) |

本文系统诊断混合检索（BM25稀疏检索与稠密神经检索融合）在单查询层面的代价，提出"融合税"概念。在7个BEIR数据集上，使用Anserini BM25、5种稠密编码器（22M-596M参数、三代模型）、SPLADE及交叉编码器重排，比较3种融合函数。发现即使最优的稠密加权分数插值方法，也在13-48%的查询上把相关文档排在两个组件中较优者之下，8-21%的查询上劣于可部署的纯稠密检索器；在7个语料中的6个上，损失厌恶的风险敏感评估下损失显著。融合税主要是排序效应，最易出现在仅一个检索器覆盖的查询上，且跨编码器规模与SPLADE替换持续存在。RRF在稠密检索明显更强时税负更高。融合失败在语料内弱可预测但跨语料迁移不可靠。交叉编码器仅在其自身可靠时能挽回部分税负。最终给出按目标语料稀疏-稠密平衡决定是否融合的指导。


**核心贡献**：

- 提出"融合税"概念，量化混合检索在单查询层面的性能损失：最优融合方法在13-48%查询上劣于其较优组件，8-21%查询上劣于纯稠密检索器。

- 发现融合税主要是排序效应而非召回损失，最易出现在仅单一检索器覆盖的查询上，且在5种编码器与SPLADE替换下持续存在。

- 揭示RRF在稠密检索明显更强时税负更高，仅在两组件均衡时优于纯稠密检索；融合失败特征跨语料符号翻转导致迁移不可靠。

- 提出按目标语料实测稀疏-稠密平衡来决定是否融合的实用指导原则。



> 💡 该文首次系统量化混合检索在单查询层面的"融合税"，为是否融合提供了基于语料稀疏-稠密平衡的可操作诊断框架，对检索系统选型有直接指导价值。

### 5. 当智能体检索静默失败时：框架与创意AI助手的生产证据
| 属性 | 内容 |
|------|------|
| **英文标题** | When Agentic Retrieval Fails Silently: Framework and Production Evidence from a Creative AI Assistant |
| **分类** | 大模型推荐 |
| **评分** | 6.9/10 ⭐⭐⭐ |
| **作者** |  Yan,  Liang, Anuj Agarwal et al. |
| **作者单位** | Adobe |
| **arXiv** | [2610.30423](http://arxiv.org/abs/2610.30423v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.30423v1) |

论文指出在智能体助手场景中，传统检索指标（CTR、MRR、NDCG）因生成层先于用户消费结果、用户行为跨会话延迟、以及检索内容与模型知识混合而失效，提出“归因鸿沟”概念。作者设计分层智能体检索评估框架LARA，将检索质量、参与度和结果、产品成功作为三个独立层，通过四字段血缘模式连接，无需新建模。在Adobe Express上验证：同一检索基础设施服务画廊搜索和智能体助手（会话量约为前者1/8），聊天用户重述率44.4%高于画廊用户33.1%，LARA恢复了检索归因能力。


**核心贡献**：

- 提出“归因鸿沟”概念，揭示智能体场景下传统检索指标失效的三种机制（谁先读、何时行动、何因导致）。

- 设计LARA三层评估框架，通过四字段血缘模式连接检索质量、参与结果与产品成功，无需额外建模。

- 在Adobe Express生产环境验证：聊天用户重述率44.4% vs 画廊用户33.1%，LARA有效恢复检索归因。



> 💡 该论文首次系统性地揭示并解决了智能体检索中的归因鸿沟问题，为LLM智能体场景下的检索评估提供了可落地的生产级框架。

### 6. 偏好不等于授权：智能体商务中自动购买线的个性化
| 属性 | 内容 |
|------|------|
| **英文标题** | Preference Is Not Permission: Personalizing the Auto-Purchase Line in Agentic Commerce |
| **分类** | 大模型推荐 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Ryotaro Shimizu, Sai HtaungKham, Mo Fan |
| **作者单位** | — |
| **arXiv** | [2610.29216](http://arxiv.org/abs/2610.29216v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.29216v1) |

论文将个性化购物从“推荐什么”推进到“智能体可自主承诺到何种程度”，提出学习个体“自动购买线”的任务。该边界由证据条件决定且为三值（不买、先确认、自动购买），取决于产品信息充分性、可逆性、价格与用户常态及紧迫性。基于16个指令微调模型与15名标注者（扮演委托主体）的授权参考对比，发现模型存在过度承诺：即使匹配度低或自身证据标志显示依据缺失仍会自主购买。个体边界差异结构化且可由个人其他标签部分预测；仅用30-40个个人标签的浅层学习器即可在留出集上达到中位0.79的预测精度，优于所有提示×模型配置（含80种配置下的逐标注者oracle），且学到的边界不跨域迁移。


**核心贡献**：

- 提出“自动购买线”个性化任务，将智能体承诺边界建模为证据条件化的三值决策（不买/先确认/自动购买），而非仅匹配度。

- 在16个指令微调模型上发现系统性过度承诺：模型在匹配度低或自身证据标志缺失时仍自主购买，与人类授权参考错位。

- 仅用个人30-40个标签的浅层学习器即可预测其留出自动购买线，中位精度0.79，超越所有提示×模型配置及80配置下的逐标注者oracle。

- 揭示学到的购买边界不跨域迁移，强调个体化与领域特定的授权建模必要性。



> 💡 该文首次将智能体商务的自主承诺边界作为可学习的个性化对象，并用量化实验证明轻量个体化学习优于大模型提示，值得关注AI代理授权与个性化决策的研究者阅读。
