### 1. 面向学习型稀疏检索的紧凑高效索引
| 属性 | 内容 |
|------|------|
| **英文标题** | Compact and Efficient Indexes for Learned Sparse Retrieval |
| **分类** | 召回与排序 |
| **评分** | 7.3/10 ⭐⭐⭐ |
| **作者** | Franco Maria Nardini, Luca Rizzo, Cosimo Rulli et al. |
| **作者单位** | — |
| **arXiv** | [2610.12300](http://arxiv.org/abs/2610.12300v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.12300v1) |

本文基于SEISMIC研究如何在不牺牲检索效率的前提下大幅降低学习型稀疏检索索引的内存占用。在倒排索引层面，用medoid（现有文档作为块代表）替代稀疏向量块摘要，将每块元数据压缩为单个文档ID；在前向索引层面，重排词表使共现分量相邻，用SIMD友好的DOTPACKING8编码Δ-gap并融合解压与点积计算，同时用每分量4比特码本量化取值，并提出面向少非零查询的JUMPDOT分块点积核。该前向索引压缩可独立集成到KANNOLO等系统。在MS MARCO上使用三种先进稀疏编码器的实验表明：同等精度下查询速度最高提升5.3倍、内存减少约3倍；极端内存受限下仍快1.9倍、内存少3.9倍。


**核心贡献**：

- 用medoid替代倒排索引块摘要，将每块元数据从稀疏向量压缩为单个文档ID，显著降低索引内存

- 提出DOTPACKING8位打包方案与4比特分量码本量化，将解压与点积融合，实现前向索引的高效压缩

- 设计JUMPDOT分块点积核，针对少非零查询优化计算，在MS MARCO上同等精度下查询速度最高提升5.3倍、内存减少约3倍

- 前向索引压缩方案与SEISMIC解耦，可即插即用地集成到KANNOLO等其他检索系统



> 💡 该论文为学习型稀疏检索提供了可即插即用的索引压缩方案，在同等精度下实现数倍速度提升与内存节省，对大规模检索系统落地极具参考价值。

### 2. 迁移验证：精确信息前沿及其调用代价
| 属性 | 内容 |
|------|------|
| **英文标题** | Verification with Transfer: Exact Information Frontiers and Their Price in Calls |
| **分类** | 强化学习推荐 |
| **评分** | 7.3/10 ⭐⭐⭐ |
| **作者** | Hazar Yueksel |
| **作者单位** | — |
| **arXiv** | [2610.12211](http://arxiv.org/abs/2610.12211v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.12211v1) |

论文研究验证器仅接受或拒绝整体答案时，如何借助相关源任务降低验证调用次数。作者以列表率失真函数刻画交错调用源任务与n次验证所需的最小因果信息，证明该下界可由首次验证前的一次观测达到，并给出期望二元源调用数的下界：设计良好的源在唯一答案情形下可控制在1+log₂5次调用内。进一步分析精确与噪声验证器下源优先与交错协议的代价差异，并针对F₂上的线性库给出最优准确率闭式解及预算剖面的多项式时间归约算法，复杂度为2^{O(h²)}poly(J,k+h)。所有编号结果均在Lean 4中机器验证。


**核心贡献**：

- 提出列表率失真函数作为交错源调用与验证所需最小因果信息的精确刻画，并证明首次验证前一次观测即可达到该前沿。

- 证明设计良好的源可将期望二元源调用数控制在1+log₂5次内（唯一答案情形），且一般情形仅差对数项。

- 对F₂上的线性库给出最优准确率闭式解，并在2^{O(h²)}poly(J,k+h)时间内计算预算剖面。

- 实验表明小型Transformer在潜在维度5时使用全部传递比特，而在维度11时完全不使用，且低XOR度不足以解释比特使用。



> 💡 该论文为迁移验证中的信息-调用权衡提供了精确理论前沿与可计算算法，并附Lean 4机器验证，对理解推荐系统中源任务与验证的交互具有重要参考价值。

- 在金融、科学、客服三类基准上，答案准确率超越vanilla、图结构和agentic基线，取得最高表现。

- 构建EntQABench新基准（284万技术文档网页），在三个LLM上相较最强基线准确率提升6.8至11.4个百分点。

- 结合逐步对比监督微调与强化学习（以最终倒数排名为奖励）优化反馈物品选择，并设计查询侧适配器支持固定物品索引下的优化。

### 6. 超越分辨率：实例检索中的目标-图像比例失配问题
| 属性 | 内容 |
|------|------|
| **英文标题** | Beyond Resolution: Object-to-Image Ratio Mismatch in Instance Retrieval |
| **分类** | 召回与排序 |
| **评分** | 6.7/10 ⭐⭐⭐ |
| **作者** | Boaz Meivar, Ofir Kedem, Amit Edenzon et al. |
| **作者单位** | — |
| **arXiv** | [2610.11489](http://arxiv.org/abs/2610.11489v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.11489v1) |

论文指出视觉实例检索中跨尺度性能下降的主因并非分辨率损失，而是目标在查询图与图库图中所占比例不一致（O2I失配）。作者在Objaverse 3021个物体、五种相机距离的受控基准上发现，12个预训练骨干中有9个的跨距离退化超过80%源于O2I失配；多尺度架构虽将纯分辨率影响降至个位数，却仍同样脆弱，且失配具有不对称性（紧致查询检索宽图库更可靠）。基于此，作者提出查询端尺度增强与OWLv2裁剪重排器，在ILIAS 100M上无需训练或改动图库索引即达SOTA（重排前29.2 mAP@1000，重排后42.0），LoRA微调亦可在单次前向中复现该增益，证明O2I鲁棒性可学习。


**核心贡献**：

- 在3021个Objaverse物体、五种相机距离的受控基准上证明，12个预训练骨干中有9个的跨距离退化超过80%由O2I比例失配而非分辨率损失导致。

- 揭示O2I失配的不对称性：紧致查询对宽图库的检索比反向更可靠，且多尺度架构虽消除分辨率效应却仍无法缓解该失配。

- 提出查询端尺度增强加OWLv2裁剪重排器，在ILIAS 100M上无需训练或修改图库索引即达29.2 mAP@1000（重排后42.0）的SOTA。

- LoRA微调在单次前向中即可匹配查询端增强的增益，表明O2I鲁棒性可通过学习获得。



> 💡 该文重新定义了实例检索跨尺度失败的主因，并给出无需改动图库索引即可落地的SOTA方案，对视觉检索系统的尺度鲁棒性设计具有直接指导价值。

### 9. 为LLM智能体策划常驻上下文：一种带删失反馈的容量约束选品模型

| **分类** | 大模型推荐 |
| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Zexuan Liu, Yuning Yang, Tiancheng Zhao |
| **作者单位** | — |
| **arXiv** | [2610.11007](http://arxiv.org/abs/2610.11007v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.11007v1) |

论文将LLM智能体常驻上下文文件（如AGENTS.md）的维护建模为容量约束的选品问题：指令消耗有限注意力预算，新增指令不会提升其他指令的遵从度，保留指令产生每会话成本。作者证明最优文件规模上界与候选指令数无关，且“全部追加”策略可能远劣于最优子集；反馈存在删失——未加载指令仅在缺失造成损害时才产生信号。研究给出删除被忽略指令的代价、添加指令所需证据量及有限人工审查下的遗憾界，实验表明真实上下文文件中的无关规则会降低模型遵从度。
