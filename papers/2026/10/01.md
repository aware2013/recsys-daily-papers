### 1. 在生成式与协同用户画像之间路由：一种面向可控新颖性的服务时门控机制
| 属性 | 内容 |
|------|------|
| **英文标题** | Routing Between Generative and Collaborative User Profiles: A Serving-Time Gate for Controllable Novelty |
| **分类** | 大模型推荐 |
| **评分** | 7.1/10 ⭐⭐⭐ |
| **作者** | Milad Sabouri, Neeraj Sharma, Sardar Hamidian et al. |
| **作者单位** | — |
| **arXiv** | [2609.39043](http://arxiv.org/abs/2609.39043v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.39043v1) |

本文研究在生产推荐系统中选择性调用LLM生成的用户画像。基于涵盖电影、电视和体育内容的真实流媒体数据集，训练了一个服务时路由门控，将每个用户分配给协同序列推荐模型或LLM画像驱动的推荐模型。门控仅使用服务时特征，学习识别哪些用户通过画像路由可提升Novelty@10同时保持排序相关性。路由阈值可控制新颖性-相关性权衡。在整体NDCG损失预算为5%时，学习到的门控将Novelty@10提升6.5%，路由12.5%的用户，优于简单启发式和随机路由策略。


**核心贡献**：

- 提出服务时路由门控，在协同序列推荐与LLM画像驱动推荐之间动态选择，仅使用服务时特征即可实现用户级路由。

- 在5% NDCG损失预算下，Novelty@10提升6.5%，仅路由12.5%用户，显著优于启发式和随机路由基线。

- 通过非生成式语义画像的对比实验证明，收益来源于选择性路由而非LLM生成本身。

- 路由阈值提供可调的新颖性-相关性权衡，使LLM画像成为协同推荐的可控补充。



> 💡 该论文提出了一种实用的服务时路由机制，让LLM生成画像仅在能提升新颖性的用户上选择性生效，为生产推荐系统低成本引入生成式信号提供了可落地的方案。

> 💡 该论文将智能体列表式选择引入补丁检索，以极低推理成本显著超越逐点分类与CoT基线，为漏洞管理中的检索式推荐提供了可迁移的新范式。

### 5. 面向算法公平性的排序毕业度量

| **作者** | Dalia Atif, Paolo Giudici |
| **作者单位** | — |
| **arXiv** | [2609.39025](http://arxiv.org/abs/2609.39025v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.39025v1) |

本文提出基于排序的公平性评估框架，通过模型预测误差分布将公平性与预测精度、可解释性关联，包含排序毕业公平性（RGF）、积分度量AURGF、中心化Cramér–von Mises置换检验及特征移除解释方法。在逻辑回归、随机森林、梯度提升和多层感知机上评估，模拟显示受保护群体不平衡会逆转描述性公平比较，而所提推断程序能正确区分公平与不公平机制。HMDA抵押贷款数据应用中，模型排名与经典公平准则不同，树模型在精度与排序公平性上表现最佳，四个模型均拒绝公平性零假设，特征移除结果表明不公平性与贷款数据中的群体差异相关。


**核心贡献**：

- 提出排序毕业公平性（RGF）及积分度量AURGF，将公平性评估与预测误差分布和可解释性统一关联

- 设计中心化Cramér–von Mises置换检验，模拟中能正确区分公平与不公平机制，而描述性比较在群体不平衡时可能反转

- 在HMDA抵押贷款数据上，树模型（随机森林、梯度提升）比逻辑回归提供更强的精度与排序公平性组合，四个模型均拒绝公平性零假设

- 特征移除程序揭示不公平性并非特定算法或预测变量所致，而是与贷款数据中嵌入的群体差异相关



> 💡 该论文将公平性评估从群体级奇偶校验推进到基于排序误差分布的推断框架，为构建兼顾精度、公平与可解释性的可信AI提供了可操作的新工具。

> 💡 该工作将MoE路由从隐式学习转向显式行为驱动，为序列推荐提供了一种可解释且有效的条件计算范式，实验覆盖广、提升显著，值得一读。

### 7. LLM推断用户上下文在生产级流媒体推荐中的价值条件

|------|------|
| **英文标题** | When LLM-Inferred User Context Adds Value in Production Streaming Recommendation |
| **分类** | 大模型推荐 |
| **评分** | 6.7/10 ⭐⭐⭐ |
| **作者** | Milad Sabouri, Neeraj Sharma, Sardar Hamidian et al. |
| **作者单位** | — |
| **arXiv** | [2609.38999](http://arxiv.org/abs/2609.38999v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2609.38999v1) |

论文在生产流媒体平台上评估了语义用户画像策略，采用2×2设计空间，交叉表示类型（聚合画像 vs LLM生成画像）与上下文范围（整体历史 vs 注意力融合的短期与长期上下文），在全目录排序场景下进行实验。核心发现：表示类型的优劣取决于用户消费模式——约五分之四的习惯性消费用户中聚合画像持续更优，而探索性用户中LLM生成画像更强。此外，LLM生成画像存在流行度吸引效应，略微提升列表内多样性，但显著降低目录覆盖率和新颖性。结果表明上下文感知系统应根据推断的消费模式自适应选择画像策略。


**核心贡献**：

- 通过2×2设计空间系统对比聚合画像与LLM生成画像，发现表示类型的优劣条件依赖于用户消费模式而非全域统一

- 约80%的习惯性消费用户中聚合画像持续优于LLM生成画像，而探索性用户中LLM生成画像更有效

- 揭示LLM生成画像的流行度吸引效应：略微提升列表内多样性，但显著降低目录覆盖率和新颖性

- 提出上下文感知系统应根据推断的消费模式自适应选择画像策略，而非对所有用户使用统一表示



> 💡 该论文首次在生产流媒体环境中系统刻画了LLM生成用户画像相对传统聚合画像的适用边界，为推荐系统按用户消费模式动态选择画像策略提供了实证依据。
