### 1. 偏好的可验证、可表述与隐性成分
| 属性 | 内容 |
|------|------|
| **英文标题** | Verifiable, Articulable, and Tacit Components of Preference |
| **分类** | 大模型推荐 |
| **评分** | 6.6/10 ⭐⭐⭐ |
| **作者** | Alexander Spangher, Sheldon Huang, Andreas Haupt et al. |
| **作者单位** | — |
| **arXiv** | [2610.03025](http://arxiv.org/abs/2610.03025v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.03025v1) |

该论文构建了CreativePreferences数据集，包含7个创意领域、2.8M文本和317M人类偏好判断，涵盖42个基准任务。作者用可执行程序、评分规则库和密集训练模型分别建模偏好，发现普遍存在可表述性差距（VAT-VA）和可验证性差距（VAT-V），并提出基于捕获-再捕获的新测量方法估计差距上下界。实验表明，这些差距在所有领域均存在，包括数学、软件工程等传统可验证领域，且在同行评审和创意写作中最大；参与判断人数越多，差距越大，符合Collins集体隐性知识理论。研究还发现完整模型更贴近人类偏好，但常与显式标准冲突，且显式表述偏好会使其偏离隐性维度，类似Goodhart定律。


**核心贡献**：

- 构建了包含2.8M文本、317M人类偏好判断、覆盖7个创意领域和42个基准任务的大规模偏好数据集CreativePreferences。

- 提出可表述性差距（VAT-VA）和可验证性差距（VAT-V）的测量方法，并利用捕获-再捕获估计差距上下界。

- 发现差距在所有领域普遍存在，同行评审和创意写作中最大，且随判断人数增加而扩大。

- 揭示显式表述偏好会使其偏离隐性维度，类似Goodhart定律，并给出何时依赖人类判断的建议。



> 💡 该研究首次系统量化了人类偏好中隐性、可表述与可验证成分之间的差距，对推荐系统和AI对齐中过度依赖显式规则的风险提出了重要警示。

### 2. 学习查询编码器可能很难，即使向量检索在几何上很容易
| 属性 | 内容 |
|------|------|
| **英文标题** | Learning Query Encoders Can Be Hard Even When Vector Retrieval Is Geometrically Easy |
| **分类** | 召回与排序 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Anders Wikum, Nina Mishra, Amin Saberi et al. |
| **作者单位** | — |
| **arXiv** | [2610.02749](http://arxiv.org/abs/2610.02749v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.02749v1) |

本文研究冻结文档索引下查询编码器的最大可达召回率（几何容量），发现在多个真实检索基准上，单向量查询编码器的检索质量远低于文档索引所能支持的上限。作者进一步构造理论案例：存在一个由小型单隐层ReLU网络表示的完美召回查询编码器，但任何统计查询学习器要获得优于随机基线k/n的非平凡召回优势，都需要指数级数量的统计查询。结果表明检索基准中存在大量未实现的几何容量，查询编码器的可学习性可能是基于嵌入检索的瓶颈。


**核心贡献**：

- 在多个真实检索基准上发现单向量查询编码器的召回率远低于冻结文档索引的几何容量上限

- 构造理论任务证明：完美召回查询编码器可由小型单隐层ReLU网络表示，但统计查询学习器需指数级查询才能超越随机基线k/n

- 提出查询编码器可学习性可能是嵌入检索性能的主要瓶颈，而非文档索引几何结构



> 💡 该文从理论与实验双重角度揭示了向量检索中查询编码器学习困难这一被忽视的瓶颈，对检索系统优化方向有重要启示。

### 4. 柏拉图式任务算术
| 属性 | 内容 |
|------|------|
| **英文标题** | Platonic Task Arithmetic |
| **分类** | 跨域推荐 |
| **评分** | 6.1/10 ⭐⭐⭐ |
| **作者** | Junghwan Park, Woojin Cho |
| **作者单位** | — |
| **arXiv** | [2610.00929](http://arxiv.org/abs/2610.00929v2) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.00929v2) |

论文提出不同预训练模型针对同一任务的行为趋同，但其参数更新缺乏共享坐标系，导致权重空间任务算术局限于单一模型。受柏拉图洞穴寓言启发，作者假设存在一个模型无关的“柏拉图任务向量”，并引入通用任务描述符（UTD）——形状与架构和嵌入维度无关的矩阵，记录任务功能效应并支持矩阵加减。通过最小二乘求解将描述符折叠进目标模型最后一层，或训练低秩适配器实现迁移。实验覆盖六个模型家族、八个任务及音频文本模型，跨模型迁移保留目标自身描述符74%-80%的增益。


**核心贡献**：

- 提出通用任务描述符（UTD），形状与模型架构和嵌入维度无关，支持矩阵加减操作实现任务组合。

- 设计两种迁移方式：最小二乘求解线性算子折叠进最后一层，或训练低秩适配器，后者每次编辑需一次优化。

- 跨模型迁移保留目标模型自身描述符74%-80%的增益，在六个模型家族、八个任务及音频文本模型上验证有效。



> 💡 该论文为跨模型任务迁移提供了架构无关的通用描述符框架，实验验证了其有效性，对推荐系统跨域迁移和模型复用具有重要启发。

### 5. TPBench：面向对话压缩的转折点基准
| 属性 | 内容 |
|------|------|
| **英文标题** | TPBench: A Turning-Point Benchmark for Dialogue Compression |
| **分类** | 大模型推荐 |
| **评分** | 5.9/10 ⭐⭐ |
| **作者** | Minji Park, Seunghyun Yoon, Hyuk Lim |
| **作者单位** | — |
| **arXiv** | [2610.02736](http://arxiv.org/abs/2610.02736v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2610.02736v1) |

论文提出对话压缩中的"转折点驱逐"失效模式：压缩器保留事实却丢弃改变事实的关键轮次（如用户修正价格、反转选择、追加约束），而单一整体保留分数会掩盖该问题。为此提出TPBench，在相同名义保留预算下评估三类互补目标：P1初始目标、P2被修订槽位的当前值、P3二者联合（含晚期槽位更新标注）。当前值答案取自MultiWOZ与SGD的人工对话状态标注，初始目标取首轮首句，无需新众包。实验表明不同探针下压缩方法排序不同；在保留比例0.30的联合探针上，所有压缩方法均低于全上下文；删除携带更新的轮次会显著降低当前值准确率，而删除匹配的无关轮次则无影响。Mistral读者复现了P2/P3排序与联合探针差距，并在LongMemEval-KU与中文RiSAWOZ上验证当前值恢复。


**核心贡献**：

- 提出"转折点驱逐"失效模式，揭示整体保留分数会掩盖对话中关键更新轮次被压缩丢弃的问题

- 构建TPBench基准，在共享保留预算下用P1/P2/P3三类探针评估压缩方法，无需新增众包标注

- 在保留比例0.30的联合探针上，所有被测压缩方法均低于全上下文，删除更新轮次显著降低当前值准确率而删除无关轮次无影响

- 在Mistral读者、LongMemEval-KU及中文RiSAWOZ上复现了P2/P3排序与联合探针差距



> 💡 该论文精准刻画了对话压缩中"保留事实却丢失转折"的隐蔽失效，并提供了低成本、可复现的评估基准，对构建长对话记忆系统具有直接参考价值。

### 9. 面向快速随机扩散采样的自适应二阶求解器
