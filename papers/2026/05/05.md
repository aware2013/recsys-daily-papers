### 10. 因果描述差距：珀尔层级中信息论意义上的分离
| 属性 | 内容 |
|------|------|
| **英文标题** | The Causal Description Gap: Information-Theoretic Separations Across Pearl's Hierarchy |
| **分类** | 可解释性 |
| **评分** | 6.2/10 ⭐⭐⭐ |
| **作者** | Seyed Morteza Emadi |
| **作者单位** | — |
| **arXiv** | [2605.02177](http://arxiv.org/abs/2605.02177v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2605.02177v1) |

本文量化了珀尔因果层级中不同层级（观测、干预、反事实）之间的信息差距。通过定义查询类描述长度（基于Kolmogorov复杂度），作者构造了二元无环结构因果模型（SCM），其观测分布描述长度为常数，而单变量干预答案描述长度达到Θ(n²)。对于有界入度的有限门模式SCM，观测-干预差距至多为O(nd log(en/d) + n log n)，表明二次构造在密集情况下是阶最优的。该差距在ε-精确总变差描述下（ε<1/4）依然保持。在反事实层级，完整干预描述仍可留下Θ(n)的反事实描述差距。


**核心贡献**：

- 首次从信息论角度量化了珀尔因果层级中观测、干预、反事实之间的描述长度差距，构造了观测分布为常数而干预描述长度为Θ(n²)的二元SCM。

- 证明了有界入度SCM的观测-干预差距上界为O(nd log(en/d) + n log n)，并验证了二次构造在密集情况下的阶最优性。

- 揭示了反事实层级相对于干预层级的额外描述差距为Θ(n)，并通过模糊-比特定理将差距等价于残余高阶模糊度的对数。



> 💡 本文为因果推理的层级差异提供了严谨的信息论刻画，对理解因果模型的可解释性与复杂度有重要理论价值。
