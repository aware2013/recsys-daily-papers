### 1. FLUID：从临时ID到多模态语义编码的工业级直播推荐系统
| 属性 | 内容 |
|------|------|
| **英文标题** | FLUID: From Ephemeral IDs to Multimodal Semantic Codes for Industrial-Scale Livestreaming Recommendation |
| **分类** | 冷启动 |
| **评分** | 7.0/10 ⭐⭐⭐ |
| **作者** | Xinhang Yuan, Zexi Huang, Anjia Cao et al. |
| **作者单位** | — |
| **arXiv** | [2605.21832](http://arxiv.org/abs/2605.21832v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2605.21832v1) |

针对直播推荐中物品ID因直播时长短暂而持续冷启动的问题，本文提出FLUID框架，首次在生产级直播排序器中完全移除候选侧物品ID。FLUID结合跨域多模态编码器（在短视频和直播上联合训练生成离散层次化编码LUCID）与无ID的晚期融合设计，将切片级和房间级LUCID作为独立token注入，并通过在线增量训练下的分阶段预热稳定模型。在覆盖全球超十亿用户的工业直播推荐系统中部署后，FLUID实现了质量观看时长+0.55%、冷启动房间观看量+2.05%和活跃小时数+0.05%的线上收益。


**核心贡献**：

- 首次在工业级直播排序器中完全移除候选侧物品ID，解决直播ID持续冷启动问题。

- 提出跨域多模态编码器联合训练短视频与直播，生成离散层次化语义编码LUCID替代ID。

- 在超十亿用户规模的工业系统上取得线上收益：冷启动房间观看量+2.05%，质量观看时长+0.55%。



> 💡 本文开创性地在工业直播推荐中彻底抛弃物品ID，用多模态语义编码解决冷启动难题，效果显著且可落地。

### 2. 一个提示不够：指令敏感性削弱了嵌入模型评估
| 属性 | 内容 |
|------|------|
| **英文标题** | One prompt is not enough: Instruction Sensitivity Undermines Embedding Model Evaluation |
| **分类** | 大模型推荐 |
| **评分** | 6.8/10 ⭐⭐⭐ |
| **作者** | Yevhen Kostiuk, Kenneth Enevoldsen |
| **作者单位** | — |
| **arXiv** | [2605.22544](http://arxiv.org/abs/2605.22544v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2605.22544v1) |

本文针对指令嵌入模型在单提示评估中的缺陷展开实证研究。通过6个嵌入模型、11个数据集、每个数据集15个任务特定提示（共990个实验），发现单点评估结果严重偏离真实性能分布：默认提示可能系统性高估或低估模型表现，且排行榜排名对提示选择不鲁棒——通过挑选有利提示，任何模型均可升至第一。建议基准测试应引入多提示评估或报告敏感性指标。


**核心贡献**：

- 揭示了指令嵌入模型在单提示评估下存在严重性能偏差，默认提示可导致系统性高估或低估。

- 通过990次实验证明，通过选择有利提示可使任意模型在排行榜中升至第一，表明排名不鲁棒。

- 提出评估基准应纳入提示鲁棒性指标，如多提示平均性能或敏感性报告。



> 💡 本文以严谨实验揭示了指令嵌入模型评估中的关键漏洞，对构建可信的大模型评估体系具有重要警示意义。

### 3. 不要相信拍卖者：在反馈被操纵的拍卖中学习出价

本文研究重复第一价格拍卖中，对手通过虚假出价（shilling）操纵学习者的反馈（仅影响观察到的输后价格，不影响实际分配）时的出价学习问题。假设虚假出价分布已知，算法结合鲁棒的区间消除分支（忽略被操纵报告，达到动态定价率O~(T^{2/3})）和乐观分支（对输后报告去偏，利用可靠后缀信息，达到一价拍卖率O~(√T)），并通过验证与竞赛机制自适应选择分支。理论证明上下界匹配（单活跃区域情形），表明仅反馈操纵即可显著改变重复出价的统计难度。

> 💡 本文为反馈操纵场景下的在线出价学习提供了首个理论完备的算法与下界，对广告竞价中的反欺诈与鲁棒出价策略设计具有重要指导意义。

### 7. 超越温度：超拟合作为后期阶段的几何扩展

| **PDF** | [下载](https://arxiv.org/pdf/2605.22579v1) |

本文揭示了“超拟合”现象——在小型数据集上将大语言模型微调至接近零训练损失，反而能提升开放生成质量并减少贪婪解码中的重复。通过熵匹配对照实验，证明该现象与温度缩放本质不同，且非静态词汇重加权。层分析表明，其机制在于最终Transformer块的“终端扩展”，特征空间维度增加约80.8，促进深尾词生成。作者提出Late-Stage LoRA，仅更新最后5层即可实现稳健生成。


**核心贡献**：

- 通过熵匹配实验证明超拟合与温度缩放本质不同，温度缩放无法复现其多样性增益。

- 发现超拟合依赖于动态、上下文相关的排序重排机制，而非静态词汇重加权。

- 定位到最终Transformer块的“终端扩展”，特征空间维度增加约80.8，促进深尾词生成。

- 提出Late-Stage LoRA，仅更新最后5层即可实现稳健生成，大幅减少参数更新量。



> 💡 本文揭示了超拟合现象背后的几何扩展机制，为大语言模型在推荐场景中的可控生成提供了新思路。
