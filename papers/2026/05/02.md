### 1. 对象图：从文档注入到知识遍历——面向智能体时代的原生文件格式
| 属性 | 内容 |
|------|------|
| **英文标题** | ObjectGraph: From Document Injection to Knowledge Traversal -- A Native File Format for the Agentic Era |
| **分类** | 大模型推荐 |
| **评分** | 6.9/10 ⭐⭐⭐ |
| **作者** | Mohit Dubey, Open Gigantic |
| **作者单位** | — |
| **arXiv** | [2604.27820](http://arxiv.org/abs/2604.27820v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2604.27820v1) |

本文指出当前文档格式（如Markdown）是为人类线性阅读设计的，而自主LLM智能体需要检索而非阅读，导致大量token浪费和状态混淆。作者提出ObjectGraph (.og)格式，将文档重新构想为带类型的、有向的知识图谱，支持遍历而非注入。该格式是Markdown的严格超集，无需额外基础设施，仅需两个原语的查询协议。实验表明，在五种文档类别和八类智能体任务中，token减少最高达95.3%，且任务准确率无显著下降（p>0.05），转译器保真度达98.7%。


**核心贡献**：

- 提出ObjectGraph文件格式，将文档建模为有向知识图谱，实现智能体高效遍历而非全文注入。

- 形式化文档消费问题，证明ObjectGraph同时满足现有格式无法兼顾的六项结构属性。

- 在五种文档类别和八类智能体任务中，token消耗减少最高95.3%，任务准确率无统计显著下降（p>0.05）。



> 💡 本文从文件格式根源解决LLM智能体文档消费效率问题，是智能体时代信息交互的基础性突破。

### 4. 弥合差距：偏好学习中的结构感知一致性
| 属性 | 内容 |
|------|------|
| **英文标题** | Mind the Gap: Structure-Aware Consistency in Preference Learning |
| **分类** | 大模型推荐 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Mehryar Mohri, Yutao Zhong |
| **作者单位** | — |
| **arXiv** | [2604.27733](http://arxiv.org/abs/2604.27733v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2604.27733v1) |

本文指出直接偏好优化（DPO）等主流大模型对齐方法使用的替代损失函数在等连续假设集上理论上不一致，导致泛化保证失效。为解决此问题，作者将大模型对齐建模为间隔偏移排序框架，推导出依赖于分离间隔γ的严格H-一致性界，并进一步提出结构感知一致性目标（SA-DPO），根据响应间的语义距离自适应调整间隔以处理同义词和困难样本。最后通过间隔-容量轮廓分析证明，对于容量受限模型，多项式铰链族等重尾替代损失比DPO使用的逻辑损失具有更优的一致性保证。


**核心贡献**：

- 首次证明DPO等标准替代损失在神经网络等连续假设集上理论不一致，导致泛化界失效。

- 提出结构感知一致性目标SA-DPO，通过语义距离自适应调整间隔，在理论一致性和实际对齐效果间取得平衡。

- 通过间隔-容量轮廓分析证明多项式铰链族损失在容量受限模型上比逻辑损失提供更优的一致性保证。



> 💡 本文从理论层面揭示了DPO的潜在不一致性问题，并提出了结构感知的改进方案，对偏好学习领域具有重要的理论指导意义。
