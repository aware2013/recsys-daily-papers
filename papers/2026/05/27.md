| **arXiv** | [2605.25701](http://arxiv.org/abs/2605.25701v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2605.25701v1) |

本文提出将大语言模型作为内容发布/订阅代理的语义匹配引擎，用于边缘-云连续体中的智能体AI，以弥合关键词和嵌入过滤器无法处理的词汇与模态鸿沟。在社交媒体、法律和智能家居三个公开数据集上，以离线多标签检索为框架，评估了六种LLM和七种基线。核心贡献是双交叉点的成本-精度表征：分析性上下文窗口交叉点（低于此点CoverAndMerge压缩管道可减少LLM调用）和经验性判别能力交叉点（高于此点匹配精度独立于上下文预算而崩溃，取决于模型参数和训练代际）。关键发现：高于判别交叉点时压缩无法恢复精度，仅前沿模型能处理大型订阅集；后端选择主导配置选择，模型选择是主要操作杠杆。附带三种可组合算法和每集群体验质量框架用于自主LLM层级选择。


**核心贡献**：

- 提出双交叉点成本-精度表征：分析性上下文窗口交叉点（低于此点压缩可减少LLM调用）和经验性判别能力交叉点（高于此点匹配精度独立于上下文预算而崩溃）。

- 发现高于判别交叉点时压缩无法恢复精度，仅前沿模型能处理大型订阅集，且后端选择主导配置选择。

- 在三个跨领域数据集上评估六种LLM和七种基线，验证了模型参数和训练代际对匹配精度的决定性影响。



> 💡 本文系统刻画了LLM在语义内容匹配中的成本-精度边界，为智能体AI的模型选择提供了实用指导。

### 8. 覆盖幻觉：生产级RAG系统中从检索前路由失败到检索后级联效应
| 属性 | 内容 |
|------|------|
| **英文标题** | The Coverage Illusion: From Pre-retrieval Routing Failure to Post-retrieval Cascades in a Production RAG System |
| **分类** | 召回与排序 |
| **评分** | 5.7/10 ⭐⭐ |
| **作者** | Zafar Hussain, Kristoffer Nielbo |
| **作者单位** | — |
| **arXiv** | [2605.27220](http://arxiv.org/abs/2605.27220v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2605.27220v1) |

本文以丹麦国家百科全书为案例，评估了五种检索工作流在20000个查询-工作流对上的表现。研究发现，合成查询建议90%以上查询需要LLM增强才能实现高检索覆盖，但实际生产流量中仅27.8%需要LLM增强，这种差异被称为“覆盖幻觉”，源于合成与真实查询分布的结构性不匹配。检索前路由无法解决该问题，因为LLM增强需求仅在索引搜索后显现。为此，作者提出一种检索后级联策略，按成本递增顺序执行工作流，仅在无结果时升级到LLM增强。该方法无需训练开销或辅助服务，相比Always-HyDE质量提升0.140综合得分，延迟降低31.8%，且72.2%真实查询无需LLM增强。


**核心贡献**：

- 揭示合成查询与真实查询分布的结构性不匹配导致的“覆盖幻觉”，仅27.8%真实查询需LLM增强。

- 提出检索后级联策略，按成本递增顺序执行工作流，质量提升0.140综合得分，延迟降低31.8%。

- 无需训练开销或辅助服务，72.2%真实查询无需LLM增强，显著降低推理成本。



> 💡 本文通过生产级RAG系统案例，揭示了合成查询与真实查询的覆盖幻觉，并提出一种低成本、高效的检索后级联策略，显著提升质量并降低延迟。
