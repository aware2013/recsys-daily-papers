### 7. 科学机器学习中的跨样本预测波动问题
| 属性 | 内容 |
|------|------|
| **英文标题** | Reducing cross-sample prediction churn in scientific machine learning |
| **分类** | 召回与排序 |
| **评分** | 6.5/10 ⭐⭐⭐ |
| **作者** | Gordan Prastalo, Kevin Maik Jablonka |
| **作者单位** | — |
| **arXiv** | [2605.13826](http://arxiv.org/abs/2605.13826v1) |
| **PDF** | [下载](https://arxiv.org/pdf/2605.13826v1) |

本文发现科学机器学习中，不同训练数据样本会导致预测结果不一致。在9个化学基准上，两个独立训练的模型在平均准确率上仅差1.3-4.2个百分点，但对8.0-21.8%的测试分子预测标签不同，称为“跨样本预测波动”。标准参数侧方法（深度集成、MC Dropout、随机权重平均）无法降低该波动，而两种数据侧方法有效：K-bootstrap bagging在无精度损失下降低波动40-54%；本文提出的twin-bootstrap方法在2倍ERM计算下，比bagging-K=2进一步降低中位数45%的波动。建议在科学ML基准报告中增加该指标。


**核心贡献**：

- 首次系统定义并量化科学机器学习中的跨样本预测波动问题，在9个化学基准上发现模型间预测不一致率达8.0-21.8%。

- 提出twin-bootstrap方法，通过联合训练两个网络并加入sym-KL一致性损失，在2倍计算下比bagging-K=2进一步降低中位数45%的波动。

- 揭示标准参数侧方法（深度集成、MC Dropout等）无法降低该波动，而数据侧方法（K-bootstrap bagging）可降低40-54%且无精度损失。



> 💡 本文揭示了科学机器学习中一个被忽视的关键问题——跨样本预测波动，并提供了简单有效的数据侧解决方案，值得所有关注模型鲁棒性的研究者阅读。
